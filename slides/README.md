# 講演スライド ― PPG 波形の SI・RI を麻酔中の循環動態モニターにする

`PPG_SI_RI_reflected_wave_slides.pptx`（16:9・44 枚・川副式書式）

## 何のスライドか

SpO₂ モニタの脈波（PPG）から得られる **SI（stiffness index：スティフネス指数）**と
**RI（reflection index：反射指数）**を、麻酔中の循環動態モニターとして使えるかを問う講演資料。
中心に据えたのは、両指標に共通する前提 ――「**拡張期ピーク（反射波）を同定できること**」――
が、周術期でいちばん評価したい高スティフネス例で崩れる、という構造的な問題である。

その突破口として、波形上の「点」を探すのをやめ、波形を**前進波と反射波の重ね合わせとして
モデル化して当てはめる**（多ガウス分解）という数学的推定を、高校卒業レベルで理解できる
粒度に分解して説明している。

**重要な位置づけ** ―― この手法自体は新規ではない。事前技術調査（`../PPG_wave_decomposition_prior_art.html`）
のとおり、分解由来の SI・RI は Rubins 2008・Goswami 2010・Couceiro 2015 で既出であり、
血圧・総末梢血管抵抗との対比まで終わっている。デックはこの事実を第 5 章で明示し
（「既に試されている」「新規性はどこか」）、残る新規性が**指標の定義ではなく検証の条件**
（周術期・実機・退化波形）の側にあることを述べる構成になっている。

## 書式（川副式）

- タイトル 44pt 太字・金 `BF9000`・黒縁取り 2.25pt・直下に全幅の金下線（8pt, y = 1.52"）
- 右上に 6 章の章ナビ帯（現在章のみティール `00A8AA`）
- 本文はすべて 22pt 以上（出典 16pt・章ナビ 10.5pt・ページ番号 12pt のみ例外）
- 配色は役割固定・色覚セーフ：**ブルー `0072B2` ＝ 時間の軸／前進波**、
  **バーミリオン `D55E00` ＝ 高さの軸／反射波**、**ティール `00A8AA` ＝ 数学モデル・推定**、
  **レッド `C00000` ＝ 注意・限界**。ゴールドは構造色として予約し対比には使わない
- 図と文字を重ねない／1 段落 1 行（単語の途中で改行しない）
- 削った詳述は全 44 枚のスピーカーノートに全文（計 約 16,000 字）

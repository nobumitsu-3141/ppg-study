# 和文の文体規約（川副式・既発表論文から抽出）

**出典**: `pdph_ver8.1.docx`（硬膜穿刺後頭痛・症例報告）、
`paracervical_block_ver3.14.docx`（傍頸管ブロック・症例報告）
**用途**: 和文原稿・和文抄録・スライドの本文を書くときの正本。

---

## 1. 文書の骨格

書誌事項は `【】`、本文の節は `〈〉` で示す。

```
【表題】【著者】【所属機関】【著者連絡先】【原稿の字数】【図と表の点数】
【利益相反】【発表した学会名と年】【和文要旨】【キーワード】【本文】
【文献】【英文要旨】
```

本文の節は `〈はじめに〉〈症例〉または〈方法〉〈結果〉〈考察〉〈結語〉`。

和文要旨は **目的／方法／結果／結論** のラベル付き（新しい方の書式）。

末尾に3行を置く。

```
本論文の要旨は、〔学会名〕（〔年〕）で発表した。
本症例報告に際し、所属施設の承認および書面による患者の同意を得た。
開示すべき利益相反はない。
```

---

## 2. 文体

- **常体（である体）**。敬体は一切使わない
- **箇条書きを本文で使わない**。すべて地の文で書く
- **太字・傍点などの強調を使わない**
- **ダッシュ（――）を使わない**。「すなわち」「つまり」「したがって」で繋ぐ
- 修辞疑問を使わない

### 語尾の型（署名的な言い回し）

| 型 | 用途 |
|---|---|
| 〜とされている | 定説・教科書的事実 |
| 〜と考えられる | 自分の解釈 |
| 〜しうる／〜となりうる | 可能性の提示。断定を避けたい主張の中心 |
| 〜が知られている | 既報の事実 |
| 〜と整合する／〜と一致した | 自分の結果と既報の関係 |
| 〜を経験したので報告する | 症例報告の導入 |

### 文の作り

- 1文に1つの主張。支える節を「〜が、〜」「〜ため、〜」で1つだけ付ける
- 段落は「一般的な事実 → 機序や既報 → 本症例（本研究）では」の順で閉じる
- 段落の最後は必ず自分の症例・研究に引き戻す

## 3. 表記

### 略語の導入

和文名を先に置き、全角括弧の中に英語名・全角コロン・略語を入れる。

```
脈波伝播時間（pulse wave transit time：PWTT）
遠隔式後装填法（remote afterloading system：RALS）
傍頸管ブロック（paracervical block：PCB）
```

2回目以降は略語のみ。

### 数値と単位

- 数字は半角。ラテン文字の単位は **半角スペースを空ける**（`660 ms`、`500 Hz`、`2 mL`、`125 μg`）
- 「例」「点」「回」など和語の助数詞はスペースを空けない（`862例`、`図1点`）
- パーセントは半角で詰める（`98.1%`）
- 範囲は波ダッシュ（`25〜30%`、`182–338` は表内のみ）
- 桁区切りのカンマは半角（`1,224例`、`161,737ウィンドウ`）

### 引用

全角の閉じ括弧を使う。連続は読点、範囲はハイフン。

```
…と報告されている1）。
…に用いられてきた1,2）。
…とされ6-8）、良好な鎮痛が…
```

---

## 4. 考察の書き方

既発表2本に共通する運び。

1. **一般論から入る**（標準治療・機序・疫学）。ここで既報を厚く引く
2. **数値を地の文に織り込む**。表に逃がさない
   例:「1,224例の解析では治療中断が25〜30%に生じ、OTTの延長により骨盤内制御率は
   1日あたり0.85%低下し、IB期の10年骨盤内再発率はOTT7週以内の7%から
   7.1〜9週で22%、9週超で36%へと有意に上昇した7）」
3. **代替手段との比較を1段落使って行う**（なぜ他ではなくこれか）
4. **本症例（本研究）に引き戻して閉じる**
5. 限界は「第一に、第二に、…最後に」で列挙するが、**箇条書きにはしない**

---

## 5. 結語

3文前後。新しい情報を入れない。

```
今回、〜した症例を経験した。〜により〜できた。〜は〜として有効だった。
```

原著の場合は「〜と考えられた。」で締める。

## 7. Word 成果物の体裁（2026-08-30 指示）

**原則: できるだけ簡素に。装飾を足さない。**

| 禁止 | 代わりに |
|---|---|
| 文字色（黒以外） | すべて黒 |
| 網掛け・塗りつぶし | 何も敷かない |
| 見出しの下線・囲み罫 | 太字とサイズ差だけで階層を示す |
| タイトルの飾り罫 | 中央揃えの太字のみ |
| 本文を囲む箱（要旨枠など） | 見出し＋地の文 |

**表は三線表**にする。上端・見出し下・下端の3本のみで、縦罫と行間の横罫は引かない。
網掛けの見出し行を作らない（見出しは太字で示す）。

フォントは本文を游明朝、見出しを游ゴシック Medium とする。
ページ番号はフッタ中央に黒で入れる。

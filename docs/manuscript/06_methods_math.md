# 数式仕様（Methods の数理部分）

**作成**: 2026-08-30 ／ **出典**: 凍結済みコードから直接起こしたもの
（`analysis/src/pda.py`・`beats.py`・`indices.py`・`models.py`・`scripts/11_variants_extract.py`・`scripts/15_art_indices.py`）

> 記号: 1拍の標本を `x[0..N-1]`、標本化周波数 `fs = 500 Hz`、拍長 `T = (N-1)/fs`。
> 主解析のウィンドウ長は 60 s。

---

## 1. 基底関数 — skewed Gaussian（Azzalini型）

```
g(t; a, μ, σ, α) = a · exp(−z²/2) · [ 1 + erf( α z / √2 ) ] ,    z = (t − μ)/σ
```

- `α = 0` で通常のガウス関数（`erf(0)=1` より係数2は `a` に吸収される）
- 正規化係数を持たせず `a` を自由な振幅パラメータにしている
- **`α ≠ 0` ではピークが `μ` に一致しない**。よってピーク時刻・高さは
  区間 `[t₀, t₁]` を 4000 点に離散化して数値的に求める（`component_peak`）

**なぜ歪んだガウスか**: 前進波・反射波はいずれも立ち上がりが急で下降が緩い。
対称ガウスだと立ち上がりを合わせると下降が余り、下降を合わせると立ち上がりが鈍る。
（Basso 2024）

---

## 2. カーネル数

### 主解析: 2カーネル（事前指定）

```
ŷ(t; p) = g(t; a₁, μ₁, σ₁, α₁) + g(t; a₂, μ₁ + Δμ, σ₂, α₂)

p = (a₁, μ₁, σ₁, α₁, a₂, Δμ, σ₂, α₂) ∈ ℝ⁸
```

第2カーネルの位置を **絶対時刻 μ₂ ではなく第1カーネルからのオフセット Δμ** で
持たせている。これにより (i) `Δμ` に直接境界を課せる、(ii) 順序 `μ₁ < μ₂` が
`Δμ > 0` として自動的に保証される。

### 感度解析: 3カーネル（SAP §7.5・探索的）

```
ŷ₃(t; q) = Σ_{k=1..3} g(t; a_k, μ_k, σ_k, α_k)
μ₁ ,  μ₂ = μ₁ + Δμ₂ ,  μ₃ = μ₁ + Δμ₂ + Δμ₃      （12パラメータ）
```

ΔT・RI は**第1↔第2成分**から取る（第3成分は使わない）。
主解析の `fit_beat` とは実装が同一ではない（多スタート数・検算が簡略）ため、
**論文にその旨を明記する**。

## 3. 前処理と正規化（当てはめ前）

```
y₀ = x − min(x)                  モデルに定数項が無いので床を0に合わせる
y_s = y₀ / max(y₀)               振幅正規化
t   = (0, 1, …, N−1)/fs          拍頭を 0 とする
```

**この正規化から直接出る性質**: 当てはめは振幅について不変。したがって
**RI は一様な利得変化に対して不変**である（機構実験で一様ゲインが RI を
変えなかったのはこのため。壊すのは拍**内**で時間変化する利得だけ）。
高さは事後に `ymax` を掛けて元のスケールへ戻す。

---

## 4. 目的関数

```
p̂ = argmin_p  Σ_{i=0}^{N−1} [ ŷ(t_i; p) − y_s(t_i) ]²      s.t.  lo ≤ p ≤ hi
```

- 解法: Trust Region Reflective（`scipy.optimize.least_squares`, `method="trf"`）
- 反復上限 `max_nfev = 4000`
- 報告する当てはまり: `RSS = 2·cost`、
  `NRMSE = √(mean(残差²)) / (max y_s − min y_s)`

---

## 5. パラメータ境界

`t_pk` = 正規化拍 `y_s` の最大値の時刻、`T` = 拍長。

| パラメータ | 下限 | 上限 | 単位 |
|---|---|---|---|
| `a₁` | 0.05 | 2.50 | 正規化振幅 |
| `μ₁` | 0.02 | `max(0.60·T, t_pk + 0.05)` | s |
| `σ₁` | 0.015 | 0.30 | s |
| `α₁` | 0 | 8 | — |
| `a₂` | 0.02 | 2.00 | 正規化振幅 |
| `Δμ` | **0.08** | `min(0.60, 0.85·T)` | s |
| `σ₂` | 0.015 | 0.35 | s |
| `α₂` | 0 | 8 | — |

**`α ≥ 0`（正の歪みのみ）に制限する理由**: 前進波・反射波はどちらも急峻な
立ち上がりを持つ。負の歪みを許すと DN-less 波形で**振幅比の同定性が悪化する**。

**`Δμ ∈ [0.08, 0.60] s` の理由**: 生理的な反射波の到達時間帯。下限は2成分が
実質的に縮退するのを防ぎ、上限は次拍を拾うのを防ぐ。

---

## 6. 初期値

### (a) ランドマーク（スライド 5.3-a）

反射波の位置の初期値を、主ピーク後の**平滑2階微分の最小点**から取る。

```
d²[i] = 2階数値微分( y_s )[i]
j₀ = i_pk + max( ⌊0.06 N⌋ , 3 )        主ピーク直後は除外
j₁ = ⌊0.85 N⌋                          次拍側は除外
j* = argmin_{ j ∈ [j₀, j₁) } d²[j]

Δμ₀ = clip( t[j*] − t_pk + 0.02 ,  0.09 ,  0.59 )
```

`j₀ ≥ j₁`（探索区間が空）のときは `Δμ₀ = 0.22 s`。

### (b) 基準初期点

```
base⁰ = ( 1.0 ,  max(t_pk − 0.02, 0.05) ,  0.06 ,  2.0 ,
          0.45 ,  Δμ₀ ,  0.09 ,  1.0 )        （その後 lo/hi 内へクリップ）
```

### (c) 多スタート集合（`n_starts = 8`）

| # | 内容 |
|---|---|
| 1 | `base⁰` |
| 2–6 | `base⁰` の `Δμ` を格子 **{0.12, 0.18, 0.26, 0.36, 0.48} s** に置換 |
| 7–8 | ジッタ版（下式） |

```
x₀ = clip(  base⁰ ⊙ U(0.7, 1.3)⁸
          + (0, 0.02, 0, 0.5, 0, 0.05, 0, 0.5) ⊙ N(0,1)⁸ ,  lo, hi )
```

乱数種は `seed = 0` 固定 ＝ **同じ入力から必ず同じ解が出る**（再現性のため）。
格子は「別の盆地」を**意図的に**踏ませるためのもので、後段の再現性検算の材料になる。

## 7. 解の選択（ランドマークを事前情報として使う）

収束解の集合を `S`、RSS最小解を `g` とする。

```
N = { r ∈ S :  |Δμ(r) − Δμ₀| ≤ 0.06  ∧  cost(r) ≤ 1.10 · cost(g) }

p̂ = argmin_{r ∈ N} cost(r)      （N ≠ ∅ のとき）
p̂ = g                            （N = ∅ のとき）
```

つまり **RSS最小を基本としつつ、RSSが1.10倍以内でランドマークから60 ms以内の解が
あればそちらを採る**。純粋なRSS最小だと、DN-less 波形で「反射波を主ピークに当てる」
別解が僅差で勝つことがある。

---

## 8. 収束の検算（採用条件）

許容差 `tol = 1e-3`。

```
boundary_stick = ∃j :  |p̂_j − lo_j| < tol   ( j ∈ {3,7} すなわち α の下限は除外 )
              ∨  ∃j :  |p̂_j − hi_j| < tol

amp_zero       = min(h₁, h₂) < 0.02          （正規化スケールでの高さ）

競合解  C = { r ∈ S : cost(r) ≤ 1.15·cost(p̂)  ∧  |Δμ(r) − Δμ(p̂)| > 0.03 }
ambiguous      = ∃ r ∈ C :  |RI(r) − RI(p̂)| > 0.08
reproducible   = ¬ ambiguous

ok = ¬boundary_stick ∧ ¬amp_zero ∧ reproducible
```

`α` の下限 `0` を境界判定から外すのは、**対称ガウスは正当な解**だから
（張り付きではない）。

### 谷幅は採否に使わない（重要・論文に書く）

`Δμ` を固定して他を再当てはめた `RSS(Δμ)` の谷幅を診断値として計算できるが、
**採否条件には入れていない**。合成データで、別解に落ちた拍と正しい解の拍で
`谷幅/ΔT` がともに中央値 0.21 と重なり、**どこに閾値を置いても弁別できない**ことを
確認したため（閾値 0.40–0.60 で正しい解 23/23 を保持する一方、誤った解も 16/17 が通過）。
既定では計算もしない（当てはめ回数がおよそ3倍になる）。

**誤った解に対する唯一の防壁は前処理側の実効ノイズ管理**（下記 §11）である。

## 9. 指標の定義

```
t_peak,k = argmax_{t ∈ [t₀,t₁]} g(t; a_k, μ_k, σ_k, α_k)      （4000点グリッドで数値的に）
h_k      = g(t_peak,k; …) · ymax                              （元スケールへ戻す）

ΔT = t_peak,2 − t_peak,1            [s]
RI = h₂ / h₁                        [無次元・スケール不変]
SI = H / ΔT                         [m/s]   H = 身長 [m]
```

### SI と ΔT の厳密な関係（論文で明示する）

症例内で `H` は定数なので

```
1 + ΔSI%  =  1 / ( 1 + ΔT% )
```

**線形ではなく逆数関係**。したがって SI で回した回帰と ΔT で回した回帰は
一致しない（実測 r² = 0.0412 vs 0.0449）。順位相関では単調変換なので
**符号が反転するだけ**で大きさは同じ。

### 代替定義（SAP §7.5・感度解析）

```
立ち上がり間ΔT :  on_k = min{ t ≤ t_peak,k :  g(t) ≥ 0.20 · h_k }
                  ΔT_onset = on₂ − on₁

振幅パラメータ比 :  a₂ / a₁                     （ピーク高さ比ではない）
面積比           :  ∫g₂ dt / ∫g₁ dt            （[t₀,t₁] 上・台形則2000点）
```

## 10. 拍の切り出しと品質

### 平滑化

窓長 `max(⌊0.02·fs⌋, 3)` の移動平均。**端は端値で延長する**（ゼロ埋めしない）。
ゼロ埋めだとDCオフセットの大きい実データで窓端に人工的な段差ができ、
2階微分の最大が常に探索窓の先頭に張り付く。

### 立ち上がり点（foot）

収縮期ピーク `p` の手前 `0.45 s` の区間で

```
foot = argmax_j  d²/dt² [ smooth(x) ]_j
```

単純な極小値だと拍頭付近が平坦なため位置が定まらず、合成データで
中央値 +63 ms（最大 +132 ms）ずれた。ずれたままアンサンブル平均すると
狭い前進波が強く平滑化され **RI が +26% 系統的に大きく出る**。

### 拍の採否

```
60/180 s  ≤  拍長  ≤  60/30 s          （心拍数 30–180 /分に相当）
```

### SQI（信号品質）

```
amp          = max(x) − min(x)
n_nan        = NaN の個数
max_flat_run = 同一値が連続する最大長

ok  ⟺  amp > 0  ∧  n_nan = 0  ∧  max_flat_run < 0.1 · N
```

ウィンドウ採用には **SQI通過拍が8拍以上**必要。

## 11. ノイズ推定とアンサンブル拍数（誤った解への唯一の防壁）

### 相対ノイズ

白色ノイズなら2階差分の分散が `6σ²` になることを使う（脈波本体は滑らかで
2階差分にほとんど寄与しない）。

```
d²_i     = x_{i+2} − 2 x_{i+1} + x_i
σ̂        = 1.4826 · MAD(d²) / √6            MAD = 中央絶対偏差
σ̂_rel    = σ̂ / ( max(x) − min(x) )
```

### 必要拍数

n拍平均でノイズは `1/√n` になるので

```
n_need     = ⌈ ( σ̂_rel / 0.003 )² ⌉
n          = clip( n_need , 4 , 16 )
reachable  = ( n_need ≤ 16 )
```

**ウィンドウの採否**: `reachable = False`（16拍でも目標に届かない）または
SQI通過拍が `2n` 未満なら、そのウィンドウは棄却する。

### 目標ノイズ 0.003 の根拠（合成データ実測）

| 相対ノイズ | 平均拍数 | 実効ノイズ | 結果 |
|---|---|---|---|
| 0.0059 | 4 | 0.0030 | DN-less でも正しい解に収束 |
| 0.0116 | 4 | 0.0058 | 40拍中17拍が別解。**うち16拍は収束検算を通過** |
| 0.0116 | 16 | 0.0029 | ΔT −1.1 ms / RI +0.5% に回復 |

「検算をすり抜ける誤解」が実在するため、**平均後の実効ノイズを 0.003 以下に
保つこと**を拍数決定の規準に据えた。

### アンサンブル平均

```
既定 :  拍頭で揃えて最短長に切り、単純平均
```

**拍長で正規化して伸縮させない**。ΔT は絶対時間、RI は高さ比を見るため、
正規化するとRR変動の分だけ波形がぼけ、狭い前進波が反射波より強く平滑化されて
**RI が系統的に大きく出る**。

## 12. PWTT と装置遅延

### R波検出（Pan-Tompkins 型）

```
x   ← x − median(x)
d   = 一次差分
E   = ( d² ) を窓長 0.10·fs の移動平均で平滑
thr = 0.30 × percentile₉₈(E)
候補 = find_peaks(E, height = thr, distance = (60/200)·fs)
各候補を ±0.05 s 内の |x| 最大点へ寄せる
```

閾値を**分位点ベース**にしているのは、単発のアーチファクトで閾値が跳ね上がるのを
防ぐため（旧実装「全体最大 × 0.6」では実症例で真の約576拍に対し245個＝42%しか
検出できなかった）。

### 装置遅延 L の同定（折り返し展開）

脈波チャネルはモニタ内部処理で数百 ms 遅れる。遅延がRR間隔を超えると
`R → 次のfoot` の生値は **RR を法として折り返す**。各R波 n について
生値 `v_n` と直後のRR `RR_n` を取り、候補枝を作る。

```
枝_k(n) = v_n + k · RR_n ,   k ∈ {0, 1, 2}

被覆率(c) = ( min_k | 枝_k(n) − c | < 0.08 s となる n の割合 )

L = median{ 候補 : |候補 − c*| < 0.10 }      c* = 被覆率を最大にするビン中心
```

判定基準を「クラスタの締まり」ではなく **被覆率**にしたのは、締まりだけで選ぶと
R直近の偽 foot が作る少数の鋭いクラスタを拾ってしまうため。
推定は**症例全体**で行う（60秒窓内ではRRがほぼ一定で枝を区別できない）。

### 拍ごとの PWTT

```
PWTT_n = argmin_{k ∈ {0,1,2}} | v_n + k·RR_n − L |     を満たす枝の値
採用条件 :  | PWTT_n − L | < 0.15 s
```

装置遅延が加算されたままなので**絶対値は症例間比較に使えない**。本研究のモデルは
症例内のΔのみ使うため、固定遅延は差分で消える。

## 13. モデル（前提検証・補正）

### 相対変化の定義

```
Δx%(t) = ( x(t) − x(1) ) / max( |x(1)| , 0.05 · median|x| , 1e−9 )
```

分母に「系列の中央絶対値の5%」の床を敷いているのは、初回値が極端に小さい症例で
比が発散するのを防ぐため（実データで初回 RI ≈ 0 の症例が overflow を起こした）。

### 前提検証（SAP §7.1）— **切片なし**

```
ΔPWTT%(t) = β_SI · ΔSI%(t) + β_RI · ΔRI%(t) [ + β_MAP · ΔMAP%(t) ] + ε

r²_vasc = 1 − SSE / SST ,    SST = Σ ( y − ȳ )²
```

**設計行列に定数列を含めない（原点を通す）**。一方 `SST` は平均まわりで定義して
いるため、この `r²` は 0 近傍や負にもなりうる。事前指定した統計量はこの値である。

> この点は論文で明記が要る。切片を入れると同じデータで r² = 0.044 になる
> （原点通過では 0.000）。両方を報告している。

### 対照モデル（PWTT型推定器の再現）

```
b = Σ ΔPWTT(t)·y(t) / Σ ΔPWTT(t)²          y(t) = CO_ref(t)/CO_ref(1) − 1

ĈO_ctrl(t) = CO_ref(1) · ( 1 + b · ΔPWTT(t) )
```

### 提案モデル（K の乗算補正）

```
相対残差   r(t) = CO_ref(t) / ĈO_ctrl(t) − 1
補正係数   c    = argmin_c Σ ( r − Σ_k c_k · Δx_k% )²        （切片なし）

ĈO_prop(t) = ĈO_ctrl(t) · clip( 1 + Σ_k c_k · Δx_k%(t) ,  0.3 ,  3.0 )
```

説明変数の組は3通り: `(ΔSI%, ΔRI%)`＝提案、`(ΔMAP%)`＝血圧のみ、
`(ΔSI%, ΔRI%, ΔMAP%)`＝両方。係数は導出fold（症例単位 5-fold）で推定する。

### 評価量

```
percentage error :  PE = 1.96 · SD(ĈO − CO_ref) / mean(CO_ref)     症例ごと
ΔPE = median PE(提案) − median PE(対照)      95%CI は症例単位ブートストラップ
```

## 14. 動脈圧波形由来の指標（研究1b・`15_art_indices.py`）

### T1（R波 → 動脈圧立ち上がり）

```
T1 = median_n ( foot_ART(n) − R(n) ) / fs        採用範囲 0.04 < T1 < 0.40 s
```

`foot_ART` は §10 と同じ2階微分法。**動脈圧チャネルには装置遅延が無い前提**
（SNUADCが変換器出力を直接デジタル化）。合成データでオフセットは真値に対し
完全に一定（140/180/240 ms でばらつき 0.0 ms）＝**症例内Δでは相殺される**。

### 拡張期下降時定数 τ = RC

拡張期の切り出しは拍長の固定割合 `[0.55N, 0.90N]`（切痕検出は動脈硬化例で
破綻するため使わない ＝ DN-less の問題そのもの）。

```
P(t) = P_inf + ( P₀ − P_inf ) · exp( −t / τ )

f* = argmax_{ f ∈ linspace(0, 0.95, 20) }  r²[ ln( y − f·min(y) )  ~  t ]
τ  = −1 / slope(f*)        採用条件 r² ≥ 0.90
```

`P_inf` を **格子探索**するのが要点。0 に固定すると拡張期圧の床のぶん τ が
大きく出るうえ真の τ への感度が潰れる（合成データで真値 1000/1800/3000 ms が
4095/4500/5538 ms に圧縮された。格子探索で 943/1463/2314 ms に回復）。

### 最大上昇速度

```
d[i]   = ( x[i+1] − x[i] ) · fs
d̃      = d を窓長 0.010·fs の移動平均で平滑
dP/dt_max = max over d̃ ,  ただし前後 0.020·fs 標本は除外
```

生の1サンプル差分は拍の切り出し境界で非生理的な尖りを拾う
（合成データで 20,057 mmHg/s の偽値を確認。平滑＋境界除外で 805 mmHg/s）。

### 動脈圧への2カーネルPDA — **現時点では使えない**

凍結済みの `fit_beat` を動脈圧波形に当てると `σ₂` が上限（0.35 s）に張り付き、
`boundary_stick = True` で全滅する。貯留槽（Windkessel）成分をカーネルが
吸収しようとするため。両端を通す指数

```
P_res(t) = A·exp(−t/τ) + C ,    P_res(0) = y[0] ,  P_res(T) = y[N−1]
```

を差し引く簡易な excess pressure 分離では足りなかった（生・分離後で当てはめが
ほぼ同一）。**駆出中に立ち上がる貯留槽成分まで含めた分離**を設計・検証してから
使うこと。それまで B-2 は τ と dP/dt_max で代替する。

## 15. 論文に必ず書くべき数理上の注意点

1. **前提検証は原点通過**である。切片ありでは r² = 0.044（原点通過 0.000）。両方報告する
2. **SI と ΔT は逆数関係**であり線形ではない。回帰の r² が一致しないのはこのため
3. **RI は振幅正規化により一様利得に不変**。壊れるのは拍内で時間変化する利得のみ
4. **谷幅は採否に使っていない**。合成データで弁別能が無いことを確認済み
5. **誤った解への防壁は実効ノイズ 0.003 の管理のみ**。収束検算は誤解を弾けない
6. **PWTT の絶対値は症例間比較に使えない**（装置遅延が加算されている）
7. 乱数種は固定（`seed = 0`）で、同じ入力から必ず同じ解が出る

## 作った経緯

和文要旨の読み合わせで、次の指摘を受けた。(1) 初出で定義のない語（6層、確認的解析、要因配置、
特徴点法、早期振幅比、前駆出期）が多い。(2) 意味の取りにくい文がある。(3) 断定が強すぎる箇所がある
（「血管性の成分は実在する」「RIは年齢と関連せず妥当性を確立できなかった」「約2桁小さい」）。
(4) 「60秒ごとに拍単位で測定」は実態（4〜16拍の平均拍ごとに求め、60秒ウィンドウで代表）と違う。

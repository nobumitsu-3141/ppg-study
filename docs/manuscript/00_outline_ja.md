## 0. 最重要の決定：どちらの論文として書くか

同じデータで、書き方が2通りある。**これが採否を分ける最大の分岐点**なので最初に決める。

### 案A（当初の発想のまま書く）— 推奨しない

> 「esCCOの較正定数Kを血管指標で動的補正したら精度が上がるかを検証した。上がらなかった。」

- 主要評価は参照COとの一致度。しかし**参照COの98%はFloTrac系（動脈圧由来）で真値ではない**
- 査読者の第一撃：「参照が真値でないのだから、この論文は何も測っていない」
- 反論できない。**結果が陰性なので「それでも一致度が上がった」という逃げ道もない**
- 陰性 × 参照が弱い × 単一データベース → 高い確率でリジェクト

### 案B（フレーミングを変える）— **推奨**

> 「PWTTの拍ごとの変動は、PPG由来の血管指標（ΔT・RI）でどれだけ説明できるのか。
> 参照COを一切使わずに874例で検証したところ、ほとんど説明できなかった。
> これはPWTT型CO推定を血管情報で補正するという設計方針そのものの上限を示す。」

- 主結果が **§7.1の前提検証**（参照COを使わない）になる
- **参照CO非独立という弱点が、主結果には一切かからなくなる**。最大の攻撃点が消える
- 精度評価（案Aの主結果）は**副次**に降格し、「参照が弱いので確認的に見た」と正直に書く
  → 弱点を自分から限界として提示する形になり、査読者の攻撃材料ではなくなる
- 陰性結果が**情報を持つ**：「この方向の補正は筋が悪い」と後続に伝える価値。
  esCCOの誤差がSVR・Eaと相関するという既報（Yamada 2012, Biais 2015, Magliocca 2018）に対し、
  「では血管指標で直せるのか」に**否定的な答え**を与える最初の報告になりうる
- 生理学的に説明がつく：PWTTには前駆出期（PEP）など心臓側の成分が含まれる。
  先生自身のスライド6.3の指摘と一致する

**判断**: 案Bで書く。案Aの内容は捨てず、副次結果として全部載せる。

> **874例の結果が前提を支持した場合（r²が明確に正）**はフレーミングを反転させる。
> 「前提は成立する。ただし今回の補正の形では精度は改善しなかった（モデル形の問題）」
> という §7.6 の既定路線になる。骨子の章立ては共通で使えるよう作ってある。

## 2. 章立てと各章の中身

### Introduction（約600語）

1. 非侵襲連続CO推定の臨床的必要性。esCCO＝PWTTからCOを推定する実用化された方法
2. その誤差はランダムではなく血管側の状態（SVR・Ea）と相関することが繰り返し報告されている
   （Yamada 2012 / Biais 2015 / Magliocca 2018）。一方、較正定数Kは年齢・身長・体重から決まり、
   **血管情報を含まず、較正後は固定される**
3. → 自然な発想：血管情報でKを動的に補正できないか。PPGからはSI・RIという血管指標が得られる
4. **ただしこの発想は、ひとつの検証されていない前提の上に立つ**：
   「PWTTの変動が、これらの血管指標で捉えられる血管状態の変化を反映している」
   PWTTには心臓側の成分（PEP）も含まれるため、これは自明ではない
5. 本研究の問い：**その前提は成り立つのか**。公開データベース874例で、
   参照COを使わずに事前登録した解析で検証した

> Introの最後の2段落が案Bの肝。「補正がうまくいくか」ではなく
> 「補正という発想が乗っている前提が正しいか」を問う論文だと明示する。

### Methods（約1,200語 — **凍結済みSAPからすでに全部書ける**）

`01_draft_en.md` に英文で完成させてある。構成:

- データ源（VitalDB / Lee 2022を引用）、倫理（審査不要の回答を得た旨）、事前登録（SAP v0.3の凍結）
- コホート（6,388 → 874のフロー図。装置内訳と、参照の98%がFloTrac系である事実を**Methodsで先に明示**）
- 信号処理：R波検出 → **脈波チャネルの装置遅延（約670ms）の推定と補正** → 拍切り出し →
  SQI → 適応アンサンブル平均 → PDA（skewed-Gaussian 2カーネル・収束検算）
- 指標定義：ΔT（成分波ピーク間隔）・RI（成分波**ピーク高さ**比）・SI。
  **定義が文献間で不統一である事実を書き、合成データで事前に選定したと述べる**
- 品質ゲート（全閾値）と採用規準
- 主解析（参照フリー）：症例内で ΔPWTT を ΔΔT%・ΔRI% に回帰。r²と係数
- 診断：自己相関による「測定ノイズによる希釈」との切り分け ← **陰性結果の説得力の要**
- 副次解析（参照CO使用）：対照 vs 提案の percentage error、Bland-Altman、4象限一致率
- 感度解析：代替指標定義、非FloTrac部分集合、パイロット15例除外

### Discussion（約1,000語）

1. **主所見**: PWTT変動のうち血管指標で説明される成分はわずか
2. **測定の問題ではない証拠**: 自己相関は高く（信号は再現している）、PDA収束率も高い。
   それでも説明されない
3. **生理学的解釈**: PWTTはPEPを含む。PEPは前負荷・後負荷・収縮性で変動し、
   術中はこれが支配的でありうる。文献での裏づけ
4. **含意**: 較正定数を血管指標で補正する方向は、少なくともこの指標セットでは見込みが薄い。
   有望なのはむしろ（a）PEPを分離する方向（心音・インピーダンス）、
   （b）補正ではなく再較正の頻度を上げる方向
5. **方法論上の副産物**: 公開データベースの脈波チャネルに約670msの装置遅延が存在し、
   これを無視するとPWTTが破綻する。**VitalDBを使う後続研究への実用的警告**として価値がある
6. **限界**: 参照CO非独立（副次解析にのみ影響）、単一データベース・韓国単施設、後ろ向き、
   2カーネルPDAの成分帰属は保証されない、術中の急性変化への安静時指標の外挿、
   実機esCCOの係数は非公開のため「PWTT型推定器の再現」であること

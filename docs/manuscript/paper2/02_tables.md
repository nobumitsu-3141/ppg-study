| 同 | 4 | 31.6% | 8 | 0.0047 | 99% | 0.38（3/4） |

読みは 4 点ある。

1. **歪みガウスの失敗は歪みの符号によるものではない。**左歪みを許した Basso 式の行は、
   2成分で凍結版と完全に同じ、3成分でもほぼ同じである（最適解が左歪みを選ばない）。
2. **歪みを外した素朴な 2 ガウスが 0.54（4/4層）で最も追う一方、当てはまりは最も悪い**
   （NRMSE 4.9%、Wang 通過 0%）。歪みという自由度は当てはまりを 0.049 から 0.021 へ改善する一方で、
   成分のピークを特徴点から切り離す。
3. **成分を増やすと当てはまりは上がり、真値への追従は下がる**（ガンマ 3→4 で 0.56→0.35、
   ガウス 2→4 で 0.54→0.28）。当てはめの採択率を上げる方向と真値を追う方向は逆である。
4. **どの基底も、同じ被験者の特徴点由来 ΔT（決定試験の全例 0.710・6層）に届かない。**
   分解の中で最良は 0.56 である。成分のピークが特徴点そのものに近いほど追従が良いという構造であり、
   特徴点を直接測るほうがよい。

**母数が境界にある割合について。**ガンマ経路では探索範囲を広げても 89〜99% で変わらない。
したがって「探索範囲が解を決めている」というより、**この族の母数がこれらの拍で同定されていない**
と読むのが正確である。決定試験で報告した「範囲を広げると 0.119」は**採択された拍**についての値であり
（624名の 3.5%、約 22 名）、全例では範囲によらず 0.55 であった。この区別を落とさない。

## 表4　公表された条件をそのまま当てた結果（探索・事後）

**判定には用いない。**対象は系統的に選んだ 624 名（subj_no を 7 で割った剰余が 0）。

| Couceiro 2015 | 0.500（6/6） | **R1_d 0.585（6/6）** |

**ΔT については、どの条件も特徴点由来に届かない。**最良は Tigges 推奨の Gamma M=3 で 0.578 であり、
第2版のガンマ経路の全例 0.556 および表3 の 0.56 と同じ水準にある。すなわち我々の実装が劣っていたのではなく、
文献の条件で出る上限がこの水準である。

**RI については Couceiro の R1_d のみが特徴点由来を上回る**（0.585 対 0.501）。
事前に定めた規準の下でこの行は判定に採らない。留保は 3 つある。本モデルでは末梢血管抵抗が拡張期の減衰を
決めるため関連の一部が内蔵されていること、実測波形では拡張期ピークが得られないことが多いこと、
および我々の再現に逸脱が残ることである。

### 記述

- Tigges の補正赤池情報量規準は Gamma M=3 が 42%・M=4 が 32% で最良となり、
  Tigges 2017 の実測（Gamma M=3 が 28.1% で最頻）を再現した。
  Normal と Rayleigh は本データベースでは一度も最良にならない（拡張期の減衰が指数的であるため）。
- Wang の条件では 99% の拍が 5 ガウスに増え、採択率は 5.9% であった。
  選ばれた重みの中央値は上限の 100 である。採用分は 1 層しかなく判定できない。
- 自前の特徴点実装（`pda2.find_landmarks`）は ΔT 0.513・RI 0.236 で、Charlton 同梱値に劣る。
  変曲点のみの型が 78% を占め、そこで下降脚の変曲点を拡張期ピークの代用としているためである。
  **同梱値が何を拡張期ピークとしているかは原著者の算出によるので、我々の実装の限界として記録する。**
- 切痕のある拍のみでは Couceiro 0.440（6/6）と特徴点 0.433（4/6）が同程度であり、表3 の像と整合する。

## 表5　波形の型で分けた年齢層内 Spearman 順位相関（探索・事後）

波形の型は `pda2.find_landmarks` による（型1 ＝ 重複切痕と拡張期ピークが極値として現れる、

**A 段** ＝ その手法が自分で「当てはめに成功した」と判定した被験者だけ（分解法・凍結版では `ok_v1 == 1`）。

欠陥ではないが、**型を固定した中での関連は全例の値より弱い**。

**第二に、分解法・凍結版 ΔT の陰性は型に依らない。**切痕が極値として残る型1 でも 0.224（4/6）であり、
第2成分のピークは同梱の拡張期ピークより中央値 36.9 ms 遅い（型3 では 98.5 ms）。第2成分は拡張期ピークに載っていない。

**第三に、分解由来の RI は型1 では末梢血管抵抗を追う。**凍結版 0.554（6/6）は特徴点法の 0.481 を上回る。

第2版の歪みガウスでも型1 の RI は 0.553（6/6）だが、型3 では高齢層で符号が反転する（+0.53 → −0.49）。
**切痕が極値として残らない型では、第2成分の振幅を決める基準が波形の中に無い。**

早期振幅比の全例 25 歳層がほぼ 0 であったのは、型1（+0.74）と型3（−0.47）で符号が逆で打ち消し合うためである。

## 表6　拡張期の下降の扱いを変えたときの型3 の関連（探索・事後・4,374 名）

**この解析は決定試験の判定の後に回した探索であり、判定には用いない。**本稿の主解析（表1）は凍結版の実装で確定しており、
以下は「なぜ分解法が特徴点法に劣ったのか」を診断するために、同じ 4,374 名の同じ拍に当てはめ直したものである。
2 カーネル模型には拡張期の下降を受ける項が無い。そこで下降の扱いだけを変えた版を、**下降を説明する項を足す案**と、
**下降を当てはめの対象から外す、または残差の中で小さくする案**に分けて並べる。

すなわち A 段に残る割合である。

**下降を説明する項を足す 5 つの案はいずれも失敗し、下降を当てはめの対象から外す（打ち切り）か、
残差の中で小さくする（1 次微分の領域）案だけが働いた。**
打ち切った版では型3 の ΔT × 大動脈脈波伝播速度が 0.220 から 0.596（C 段・6/6）に上がり、
同梱の特徴点法（0.430）を上回る。
**打ち切る割合を 0.55〜0.75 倍で振っても C 段は 0.545〜0.596・6/6 で変わらず、絶対時間 0.45 s で切っても 0.724・6/6 である。**
拍長の割合で切ると切る位置が心拍数の関数になるが、絶対時間で切っても同じ向き・同じ水準なので、
打ち切りの効果は切る位置が心拍数に依存することの産物ではない。
主とする割合 0.65 は本解析の前に決めた値であり、これらの数値を見て選び直していない。
切る範囲を狭くするほど ΔT の相関は上がるが、第2成分の形を決める情報が減るので通過率は下がる
（0.75 倍 0.726 → 0.65 倍 0.413 → 0.55 倍 0.156。絶対時間 0.45 s は 0.187）。

**出力側の畳み込みは、波形には最もよく合う版でありながら関連を失った。**通過率 0.728 は凍結版に次いで高く、
時定数が下限に達した拍は無い（表6b）。それでも ΔT × 大動脈脈波伝播速度は A 段 0.042 で、凍結版より悪い。
下降を説明する自由度を模型に与えると、第2成分をどこに置いても残差を小さくできるようになり、
第2成分の位置が残差から決まらなくなる。**波形に合うことと、指標が硬さを追うことは別である。**
2 段階の逆畳み込みは、戻した波形に当てた第2成分の幅が上限に達し（表6b）、通過率 0.086 にとどまった。

**1 次微分の領域で残差を取る版だけが、ΔT と RI の両方で C 段の規準を満たす**（0.687・0.416、いずれも 6/6）。
ゆっくり下がる拡張期は微分すると小さくなり、残差は収縮期ピークと変曲点の周りで決まる。
ただし競合解を持つ拍が 0.331 と多く、通過率は 0.510 である。

**第2成分が同梱の特徴点の位置に戻ることは、関連の条件ではない。**拍長の 0.65 倍で打ち切った版は特徴点との差が
+98.5 → +25.8 ms に縮んだが、1 次微分の版は +88.8 ms のままで、後者の C 段（0.687）は前者（0.596）より高い。

**RI については、打ち切った版は A 段でしか規準を満たさない**（3 つの割合と絶対時間のすべてで C 段は 0.107〜0.182）。
これが当てはめの良さによるのか採用の仕方によるのかは、同じ被験者の上で比べる B 段
（比べる手法すべてが採用した共通例）で分かれる（次の実行で計算する）。
1 次微分の版は C 段でも満たす（0.416）が、同梱の特徴点法（0.550）には届かない。

**第2成分の位置の下限は原因ではない。**下限を 0.08 s から 0.01 s に緩めても値はほとんど動かず、
凍結版では 4,374 名のいずれの型でも下限に張り付いた拍は 1 つも無かった。

## 表6b　当てはめが探索範囲の端に達した母数（型3・C 段・上位 2 つ）

表6 の各案がなぜ失敗し、なぜ働いたかは、どの母数が探索範囲の端に達したかで説明できる。
母数の名は a1・μ1・σ1・α1 が第1成分の高さ・位置・幅・歪度、a2・Δμ・σ2・α2 が第2成分の同じもの、
g・τ が貯留槽の大きさと時定数である。`:lo` は下限、`:hi` は上限に達したことを表し、
1 つの拍が複数の母数で端に達しうるので割合の合計は 1 にならない。

| 拡張期の下降の扱い | 端に達した拍の割合 | 内訳 |
|---|---|---|
| 凍結版（項を持たない） | 0.072 | α1:hi 0.04・σ1:hi 0.03 |
| 貯留槽の項（時定数の下限 0.05 s） | 0.903 | **g:hi 0.61**・**τ:lo 0.21** |
| 貯留槽の項（同 0.15 s） | 0.932 | **τ:lo 0.88**・g:hi 0.56 |
| 自由な指数減衰 | 0.372 | **τ:lo 0.33** |
| 出力側の畳み込み | 0.254 | α1:hi 0.25・μ1:lo 0.02（τ:lo 0.00） |
| 2 段階（逆畳み込み） | 0.914 | **σ2:hi 0.70**・μ1:lo 0.35 |
| 拍長の 0.65 倍で打ち切る | 0.562 | σ2:hi 0.30・α2:hi 0.23 |
| 絶対時間 0.45 s で打ち切る | 0.803 | σ2:hi 0.39・α2:hi 0.39 |
| 残差を 1 次微分の領域で取る | 0.319 | σ2:hi 0.23・Δμ:lo 0.11 |

貯留槽の項は `res(t) = g·∫g1(s)·e^{−(t−s)/τ}ds/τ` で核を単位面積に規格化してあるため、
**時定数 τ を 0 に近づけると核はデルタ関数に近づき、この項は第1成分の定数倍に一致する。**
当てはめは拡張期の下降を説明する代わりに、この縮退した向き（g を上限へ、τ を下限へ）に進む。
**時定数の下限を 0.05 s から 0.15 s に引き上げても、端に達する拍の割合は 0.21 から 0.88 に増えただけで、
縮退は解消しない。**すなわちこの失敗は下限の選び方の問題ではなく、2 カーネル模型に貯留槽の項を加えたときの
同定性の問題である。自由な指数減衰も同じ向きに縮退する。

出力側の畳み込みは核を 2 成分の和の全体に掛けて置き換えるので、時定数を 0 に近づけると凍結版そのものに一致し、
縮退する向きが無い。実際に時定数が下限に達した拍は無く、端に達するのは第1成分の歪度である。
**この版の失敗は同定性の問題ではなく、下降を説明できるようになった分だけ第2成分の位置が残差から決まらなくなったことによる**（表6）。
2 段階の逆畳み込みは、推定した時定数で戻した波形の拡張期が持ち上がり、第2成分の幅が上限に達する。

これに対し、**打ち切った版と 1 次微分の版で端に達するのは第2成分の幅と歪度であって、位置ではない**
（1 次微分の版で位置の下限に達した拍は 0.11）。
拡張期を当てはめの対象から外すと第2成分の形を決める情報が減るため通過率は下がるが、
ΔT が用いるのは位置であり、A 段と C 段の双方で関連が保たれることがその裏づけである。

## 表7　指尖の圧と流速から線形に分離した後進波との照合と、同じ分解を圧波形に当てた結果（探索・事後・4,374 名）

**この解析も決定試験の判定の後に回した探索であり、判定には用いない。**PWDB は指尖の圧 P と流速 U を同じ拍で与えるので、
線形の波分離 P_f = (ΔP + ρc·ΔU)/2、P_b = (ΔP − ρc·ΔU)/2（ρc は収縮期初期の P–U ループの傾き、基線は拍内の最小値）で
**線形分離の後進波**を作り、その到達時間 ΔT_true（P_b と P_f のピーク時刻の差）と振幅比 RI_true を真の値として、
分解法の第2成分と同梱の特徴点がそれに載っているかを見た（表7a）。あわせて凍結版の分解を PPG ではなく指尖の**圧波形**に当て、
PPG という量への変換がどれだけ効いているかを見た（表7b）。段の定義は表5 と同じ。

**型1・型3 では、分解法も特徴点法も線形分離の後進波のピークより 110〜260 ms 遅い位置を捉えており、順位相関はほぼ 0 である。**
両手法が測っているのは線形分離が返す後進波ではない。さらに真値どうしの関係（どの分解も超えられない上限）を見ると、
ΔT_true × 大動脈脈波伝播速度は型3 で |ρ| の中央値 0.371 だが向きの合う層は 0/6（25 歳層 +0.18 → 75 歳層 +0.74。
硬いほど**遅く**到達する）、全例でも 0.512・0/6 であり、**線形分離の後進波の到達時間は指尖では硬さの指標にならない。**
一方 RI_true × 末梢血管抵抗は 0.84〜0.93（6/6）で、後進波の振幅比は末梢の反射係数を表す。
指尖で線形に分離した後進波は末端からの局所の反射が支配しており（到達の中央値 86〜138 ms）、
両手法が捉える拡張期の波（同梱の特徴点では収縮期ピーク後 226〜304 ms）はそれとは別の現象で、そちらが硬さと関連する。
**したがって分解法の弱点は「反射波を捉え損ねている」ことではなく、特徴点法と同じ拡張期の波を、
拡張期の下降に引かれて取り損ねていることである**（表6）。型4（変曲点の無い 105 名）だけは、分解の第2成分が
線形分離の後進波のピークに近い（差 +13.1 ms・ρ +0.500）。

本稿では「反射波」の語を、線形分離の後進波と区別せずには使わない。分解法・特徴点法が与える ΔT は
「拡張期の波の到達時間」であり、それが硬さと関連する理由は reservoir-wave の議論
（Wang ら 2003・Mynard と Smolich 2014・Westerhof ら 2015。書誌は投稿前に照合する）の論点と重なるので、考察で限定して述べる。

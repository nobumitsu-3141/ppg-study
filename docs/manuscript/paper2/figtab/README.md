## 投稿先の規定に合わせた点（Physiological Measurement, IOP 共通）

幅 85 mm（単段）または 150 mm（二段）、図の中の文字は最終寸法で 8 pt 以上、PDF（ベクタ）・SVG・PNG（600 dpi）を出す。
文字は編集可能なテキストとして埋め込む。配色は色覚多様性に配慮した Okabe–Ito の色で、白黒でも記号の形・塗りつぶしの有無・
線種で見分けられるようにした。カラー図を CMYK にする変換と、書体（和文 IPAPGothic、英文 Liberation Sans）は投稿時に
組版側で合わせる。図の中に判定（成立・不成立）は書かず、規準線だけを引く。

## 読むときの注意

- 改良版の数値は 14 型から事後に選んだものなので楽観側にある。B 段は分解に有利な部分集合である
  （凍結版の ΔT でさえ B 段で 0.510。特徴点法は B 段のほうが C 段より低い）。
- 雑音を足した列の特徴点法の参照は、雑音を足していない同梱値のままである（同じ条件の比較ではない）。
- 分解由来の RI は、どの版も特徴点法（0.550）に届かず、雑音に残らない。
- 型1 の ΔT × 大動脈PWV が手法によらず低いのは範囲の制限（層内の大動脈PWV の四分位範囲の幅が型3 の 1/12）であって、
  手法の失敗と読まない。
- 書かないこと（`gate0_rules_v2.md`）: 「ΔT は大動脈の硬さを測る」「第2成分は反射波である」「PDA は壊れている」
  「in silico で不成立だから in vivo でも無意味」「in silico で成立（回復）したから実機でも使える」。

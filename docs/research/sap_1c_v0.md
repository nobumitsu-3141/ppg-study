# 統計解析計画 SAP-1c v0（研究1c・改題版）

**対象**: 昇圧薬の用量ステップを自然実験として用いる、PWTT 構成要素の応答検証
**状態**: 起草（2026-09-03）。**未凍結**。凍結してタグ付け・Zenodo 登録するまで解析を実行しない
**前提となる判定**: Gate 0（研究0・PWDB 4,374名、2026-09-03）で PDA 由来 SI・RI の構成概念妥当性が
不成立となり、roadmap §8 に従って C-1 の問いを差し替えた

---

## 1. なぜ問いを差し替えたか

当初の C-1 は「PDA 由来の SI・RI は急性の血管トーヌス変化を捉えるか」であった。
しかし研究0 で、理想波形・真値既知の集団においてすら ΔT は大動脈脈波伝播速度を
（年齢層内 |ρ| 中央値 0.22）、RI は末梢血管抵抗を（同 0.21）事前規準に足る強さで
反映しないことが示された。指標が標的を測っていない以上、昇圧薬に対して陽性が出ても
「何に反応したのか」を言えない。この問いは解釈不能であり、実施しない。

代わりに、研究1b B-1 が残した問いを主解析に据える。

研究1b B-1 では、術中 ΔPWTT の症例内分散の 53% が T2−T1（橈骨→指尖）に、7% が
T1（前駆出期＋中枢）にあった。ところが研究0 の真値では、橈骨→指尖の生理的な伝播時間は
**8 ms（5〜95パーセンタイル 4〜16 ms）**しかない。年齢6段階と6因子を ±1 SD 振った
4,374 名でこの幅である。一方 VitalDB の T2−T1 の症例内標準偏差は約 18 ms で、
生理的にとりうる全幅を超えている。したがって T2−T1 の変動の大半は動脈の伝播時間ではない。
候補は2つある。

  (i) **形態依存の検出ずれ**  指尖の血管トーヌスが変わると脈波の立ち上がりの形が変わり、
      検出される立ち上がり時刻が動く。これは**生理に駆動された系統的なずれ**であり、
      血管情報を（伝播時間としてではなく）担っている
  (ii) **装置側の揺らぎ**  処理遅延そのものが一定でない、あるいは検出アルゴリズムの
      不安定性。血管情報を担わない

(i) と (ii) の区別は、esCCO 改善という目的にとって決定的である。(i) なら、補正すべき
入力は SI・RI ではなく立ち上がり時刻そのものであり、経路が残る。(ii) なら、
残る道は測定精度の改善か再較正頻度の増加である。

外因性の介入でこれを分ける。フェニレフリンは α₁ 選択的で直接の変力作用がほぼなく、
指尖の血管を確実に収縮させる。**(i) なら T2−T1 は用量ステップに対して一貫した向きに動き、
(ii) なら動かない。**

## 2. 主要な問いと事前予測

| | 問い | 事前予測 | 根拠 |
|---|---|---|---|
| **主** | フェニレフリンの増量に対し Δ(T2−T1) は一貫した向きに動くか | **短縮**（指尖の血管収縮 → 立ち上がりが鋭くなり早く検出される、かつ末梢伝播がわずかに速くなる） | 予測の向きは事前に固定する。向きが逆でも「一貫して動く」なら (i) を支持するが、**主要判定は事前指定の向きで行う** |
| 副次1 | ΔT1（前駆出期＋中枢）は動くか | 延長（後負荷上昇 → 前駆出期延長） | Pilz 2023 ほか |
| 副次2 | ΔPWTT（＝ΔT2）は動くか | 上記2つの和 | 記述 |
| 副次3 | ΔT・ΔRI は動くか | 予測を置かない（**記述のみ**） | 研究0 で妥当性が否定されたため、有意でも解釈しない |

副次3を残す理由は、C-2 で RI×SVR に弱い正の関連（中央値 +0.098）が出ており、
その由来を記述として残す価値があるためである。**これを指標の妥当性の証拠として用いない**
ことを事前に明記する。

## 3. 対象と解析単位

- 母集団: VitalDB で PLETH・ECG・ART が揃う 3,458例のうち `Orchestra/PHEN_RATE` を持つ症例
  （在庫調査で 103例。参照CO は不要）
- **解析単位は用量ステップ**とする。実測で on/off 遷移 73 回に対し用量ステップ 236 回であり、
  二値の on/off では材料を大きく取りこぼす
- 用量ステップの定義: 投与レート `r(t)` が直前の定常値に対し **±30% 以上**変化し、
  変化後に **120 秒以上**その水準（±10%）を保つ点。増量と減量を分けて扱う
- ステップ前後の窓: 直前 120 秒（ベースライン）と、ウォッシュイン 60 秒を挟んだ直後 120 秒
- 除外: 前後の窓に他の血管作動薬（ノルアドレナリン・エフェドリン・ニカルジピン等）の
  レート変化が入るステップ、体位変換・遮断解除の記録があるステップ、
  品質ゲート（主解析と同一）を通る窓が前後いずれかで 1 未満のステップ

## 4. 統計

- 各ステップについて、前後の窓中央値の相対変化 Δ = (後 − 前) / 前 を計算する
- 症例内で複数ステップを持つため、**症例をランダム効果とする混合効果モデル**で
  Δ の平均を推定する（症例数が 30 未満なら症例ごとの中央値を取り符号検定に切り替える）
- 増量ステップと減量ステップで**向きが反転すること**を要求する。反転しない場合は
  時間依存の交絡（手術進行に伴うドリフト）を疑い、陽性と判定しない
- 効果量は ms 単位でも併記する（相対変化だけでは 8 ms の生理幅との比較ができないため）
- MAP・HR を共変量に加えた解析を併記する（昇圧薬は血圧・心拍も同時に動かすため）

### 最小効果量（事前指定）

主要判定は Δ(T2−T1) について、**増量で 3 ms 以上の短縮**（かつ減量で反転、95%信頼区間が 0 を含まない）
を成立とする。3 ms とした根拠は、研究0 の真値で橈骨→指尖の伝播時間の全幅が 4〜16 ms であり、
その 1/4 程度の変化なら生理的にとりうる範囲を超えないためである。
これ未満は「動かない」と判定する。

---

## 5. 陰性対照（事前指定）

- **レミフェンタニル**のレート変化: 血管作用はあるが機序も向きも異なる
- **プロポフォール**のレート変化
- **非投与期間のランダム時点**: 各症例で昇圧薬を投与していない区間から、
  用量ステップと同数の擬似ステップを無作為に取る。ここで有意な変化が出れば、
  解析手順そのものがドリフトを拾っていることになる

## 6. 判定と帰結（事前指定・事後に緩めない）

| 結果 | 意味 | 帰結 |
|---|---|---|
| Δ(T2−T1) が予測どおり動き、陰性対照は動かない | **(i) 形態依存の検出ずれ**。立ち上がり時刻が血管トーヌス情報を担っている | esCCO 改善の入力を「立ち上がり時刻の変化」に置き換えて研究3 を設計する。**目的が生き残る経路** |
| Δ(T2−T1) が動かない | **(ii) 装置側の揺らぎ**。血管情報を担わない | PWTT の測定精度改善（立ち上がり検出・装置遅延の補正）か再較正頻度の増加に絞る。血管補正の路線は完全に終了 |
| Δ(T2−T1) は動くが陰性対照でも動く | 手順がドリフトを拾っている | 解析手順を作り直す。判定は保留 |
| ΔT1 のみ動く | 前駆出期は反応するが術中の分散への寄与は小さい（B-1 で 7%） | 記述に留める。研究3 の一次仮説には昇格させない |

---

## 7. 限界（先に書く）

- Orchestra は輸液ポンプの記録であり、手押しのボーラスは記録されない。したがって
  「非投与期間」に未記録の血管収縮が混入する。これは**帰無仮説の側にバイアスする**
- フェニレフリンは反射性徐脈を伴う。心拍数は ΔT にも T2−T1 にも影響しうるため、
  HR 調整解析を併記し、調整で消える効果は陽性と判定しない
- 指尖のプローブ装着部位・圧迫の程度は記録されていない
- 本解析は研究1 の SAP 凍結後に新設したものであり、研究1 の結論には影響しない

# 研究用データのご提供のお願い（大学ご担当者さま）

**2026-09-08　長崎県五島中央病院麻酔科　川副靖晃**

麻酔中に記録されている心電図と光電容積脈波（SpO₂波形）から血管の状態を表す指標を作り、
脈波伝播時間による心拍出量推定の精度を改善できるかを検討します。既存の記録からの
後ろ向き抽出のみで、患者さんへの新たな検査や処置は生じません。

---

## 1. 対象と症例数

**条件**　成人（20歳以上）・全身麻酔・**動脈ライン留置あり**・記録60分以上。
心房細動など脈が不整な症例は除外します。

| 群 | 症例数 | 内容 |
|---|---|---|
| **A群** | **100例** | 心拍出量が FloTrac／EV1000（動脈圧波形由来）で記録されている症例 |
| **B群** | **30例**（最低15例） | 肺動脈カテーテル（ガンツ）で心拍出量を測定した症例。**本研究の中核** |

- **B群が少なければ、有る分だけで結構です。**A群と重複していても構いません。
- B群は**ボーラス熱希釈の測定が1症例あたり3回以上**あり、**その実施時刻が分かる**症例を
  優先してください（理由は下記のとおり、B群の価値はここに集約されます）。
- 血管の硬さや年齢に幅が出るよう、特定の術式に偏らないほうが望ましいです。

**なぜ2群に分けるか**　主たる解析は心拍出量を使わないため、A群だけで実施できます。
B群が要るのは次の二つの理由からで、**いずれも FloTrac では代替できません**。

第一に、精度が改善したかの判定には動脈圧波形と独立した心拍出量が要ります。FloTrac の値は
血圧と連動するため、これだけでは「精度が上がった」のか「血圧に一緒に反応しただけ」なのかを
区別できません。

第二に、**本研究の中心的な仮説である「反射係数は末梢血管抵抗（SVR）を反映する」の検証に、
独立した SVR が要ります。**SVR は (平均血圧 − 中心静脈圧) × 80 ÷ 心拍出量 で算出されるため、
心拍出量が動脈圧波形由来だと、算出された SVR は分子の平均血圧と分母の両方が同じ波形に
由来することになり、指標との関連を血圧との関連から切り分けられません。**熱希釈由来の
心拍出量であれば、この循環がなくなります。**

したがって B群では、**心拍出量に加えて中心静脈圧が必須**です。

そして **B群でいちばん重要なのは、間欠のボーラス熱希釈の実施時刻と測定値**です。
連続心拍出量（CCO）ではありません。当初は CCO のほうが点数を稼げるため望ましいと
考えていましたが、公開データベース（VitalDB）の肺動脈カテーテル症例で確かめたところ、
**CCO は数分の移動平均であるため 60 秒の解析区間ではほとんど動かず、算出した SVR が
平均血圧のほぼ定数倍になってしまいました**（SVR と平均血圧の相対変化の症例内順位相関が
+0.79）。これでは「熱希釈由来」と名がついていても、独立した血管抵抗になっていません。

**ボーラス熱希釈の時刻に合わせて解析すれば、その時点の心拍出量は動脈圧波形と完全に
独立です。**1症例あたり3〜5点でも、30例あれば 90〜150 の独立した対応点になります。
**点数の多さより独立性を優先します。**

そのため、**熱希釈は「何時何分に測って値がいくつだったか」が分かる形**でお願いします
（実施時刻が秒単位で分かるのが理想ですが、分単位でも構いません）。CCO の時系列も
併せていただければ補助的に使いますが、無くても解析は成立します。

## 2. ご提供いただきたいもの

### 2-1. 波形（3つ）

| | 信号 |
|---|---|
| 1 | 心電図（II誘導） |
| 2 | **光電容積脈波（SpO₂の脈波）** |
| 3 | 観血的動脈圧（Aライン） |

麻酔導入前から抜管まで連続したもの。**心拍数と平均血圧は不要です**（この3つから計算します）。

### 2-2. 心拍出量

| | 項目 |
|---|---|
| 4 | 心拍出量の記録（連続値でも間欠値でも可） |
| 5 | **その測定装置名**（FloTrac／EV1000／Vigilance／熱希釈 など） |
| 6 | B群：**ボーラス熱希釈の実施時刻と測定値**（1症例あたり3回以上）。**B群で最も重要な項目です** |
| 7 | B群：連続心拍出量（CCO）の時系列（**あれば。無くても解析は成立します**） |
| 8 | B群：**中心静脈圧の時系列**（SVR の算出に必須） |
| 9 | 装置が SVR を算出している場合はその値と、**算出に用いた心拍出量の由来** |
| 10 | **esCCO の値と、その較正の記録**（貴学のモニタは日本光電製と伺っており、esCCO は同社の機能のため取得できる想定です） |
| 11 | モニタが算出している **PWTT** の値（出力できる場合） |

### 2-3. 血管作動薬の投与記録（**必須**）

本研究の中心的な仮説「反射係数は末梢血管抵抗を反映する」を検証できるのは、**血管の状態が
薬剤で動いた場面**です。観察しているだけでは血管抵抗と血圧が一緒にしか動かず、両者を
切り分けられません。フェニレフリンのボーラスは全身血管抵抗を選択的に上げ、心拍出量を
下げるため、この切り分けができる数少ない場面です。

| | 項目 |
|---|---|
| 12 | **昇圧薬・血管拡張薬の投与時刻と用量**（フェニレフリン、エフェドリン、ノルアドレナリン、ニカルジピン、ニトログリセリンなど） |
| 13 | 同上について、**シリンジポンプの動作記録**（開始・流量変更・停止の時刻と流量） |
| 14 | 麻酔導入・気管挿管・執刀・閉創・抜管の時刻、体位変換の時刻 |

**時刻は秒単位でお願いします。**麻酔記録上の5分刻みに丸めた時刻では解析に使えません。
丸めがある場合はその旨をお知らせください。13 のポンプ記録が取り出せれば、丸めの問題は
回避できます。

**前向きに取得できる場合のお願い**　B群において、**昇圧薬ボーラスの直前と投与後2分・5分に
熱希釈を測定**していただけると、本研究の価値が大きく上がります。連続心拍出量は数分の
移動平均であるため、数分で終わる血管収縮を追えないためです。

## 3. 一緒に出していただけると助かるもの（任意）

いずれも既存の記録から1項目ずつです。無くても解析は成立します。

| 項目 | 理由 |
|---|---|
| SpO₂プローブの**装着部位と左右**、Aラインの**留置部位と左右** | 脈波の伝わる時間に直接影響します |
| **術前の baPWV または CAVI**（測定日つき） | 生理機能検査に既にあれば流用できます。**指標が本当に血管の硬さを反映しているかを確かめられる唯一の項目**です |
（昇圧薬の投与記録は 2-3 に移し、必須といたしました）

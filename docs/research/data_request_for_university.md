# 研究用データのご提供のお願い（大学ご担当者さま）

**2026-09-08　長崎県五島中央病院麻酔科　川副靖晃**

麻酔中に記録されている心電図と光電容積脈波（SpO₂波形）から血管の状態を表す指標を作り、
脈波伝播時間による心拍出量推定の精度を改善できるかを検討します。既存の記録からの
後ろ向き抽出のみで、患者さんへの新たな検査や処置は生じません。

---

## 1. 対象と症例数

**条件**　成人（20歳以上）・全身麻酔・**動脈ライン留置あり**・記録60分以上。
心房細動など脈が不整な症例は除外します。

| 群 | 症例数 | 内容 |
|---|---|---|
| **A群** | **100例** | 心拍出量が FloTrac／EV1000（動脈圧波形由来）で記録されている症例 |
| **B群** | **30例**（最低15例） | 肺動脈カテーテル（ガンツ）で心拍出量を測定した症例 |

- **B群が少なければ、有る分だけで結構です。**A群と重複していても構いません。
- B群は**熱希釈の測定が1症例あたり3回以上**ある症例を優先してください。
- 血管の硬さや年齢に幅が出るよう、特定の術式に偏らないほうが望ましいです。

**なぜ2群に分けるか**　主たる解析は心拍出量を使わないため、A群だけで実施できます。
一方、精度が改善したかの判定には、動脈圧波形と独立した心拍出量が要ります。
FloTrac の値は血圧と連動するため、これだけでは「精度が上がった」のか
「血圧に一緒に反応しただけ」なのかを区別できません。**B群はそのための少数例**です。

## 3. 一緒に出していただけると助かるもの（任意）

いずれも既存の記録から1項目ずつです。無くても解析は成立します。

| 項目 | 理由 |
|---|---|
| SpO₂プローブの**装着部位と左右**、Aラインの**留置部位と左右** | 脈波の伝わる時間に直接影響します |
| **術前の baPWV または CAVI**（測定日つき） | 生理機能検査に既にあれば流用できます。**指標が本当に血管の硬さを反映しているかを確かめられる唯一の項目**です |
| 昇圧薬・血管拡張薬の投与時刻と用量 | 血管の状態が動いた前後で指標を比べられます |

## 4. 取り扱い

- **連結可能匿名化**でお願いします。対応表は貴学で保持していただき、当方には通し番号のみ。
- 氏名・カルテ番号・生年月日・手術日は不要です（年齢と相対日数のみ）。
- 受け渡しは暗号化した媒体または貴学の認証つきストレージで。個人の電子メールは用いません。
- 保管期間・廃棄方法・公表時の記載は、データ利用契約で事前に取り決めます。
- 抽出の技術的な仕様は、別紙「業者さま向け」に記載しています。

**調べて採らなかったもの**: 条件数による門番。心拍 130 で Wald SE が 709 ms に膨らむ
（ブートストラップ 15 ms）が、条件数は採用例でも 1e5 に達し、良否を分けない（実測）。
Wald SE は**較正された不確かさではなく選別のための量**である。高心拍で成分が重なる拍は
SE の規準で理由つきで落ちる（T9）。

## 凍結した値

### (a) 文献から借りたもの

| 定数 | 値 | 出典 | 注意 |
|---|---|---|---|
| `NRMSE_MAX` | 0.02 | Wang 2013 | Wang の標本化周波数・前処理は同一ではない |
| `ERRX_MS` | 6.0 | Wang 2013 | 鍵点3点（収縮期ピーク・切痕・拡張期ピーク）の時間誤差の総和。Wang の点数は未確認。500 Hz の格子 2 ms が鍵点3つで 6 ms になるので放物線補間で副標本精度にする |
| `ERRY` | 0.01 | Wang 2013 | 同上の振幅版 |
| `LOWPASS_HZ` | 18.0 | Tigges 2017・Basso 2024 | 4次 Butterworth 零位相 |
| 基底関数とピーク母数化 | 歪みガウス (a, m, σ, α) | Basso 2024 | 同一。独立に同じ設計に到達していた |
| 不等式制約 | 第1成分の振幅最大・ピーク時刻の単調増加 | Basso 2024・Couceiro 2015 | 罰則で実装 |
| 幅の尺度化 | 拍長 T に比例 | Basso 2024 | HR 70 を基準（`T_REF`） |
| 汎用初期値を主とする | あり | Fleischhauer 2020 | 微分依存の初期化は雑音を増幅する |
| 規準を満たさなければ成分を1つ増やす | あり | Wang 2013（4→5） | 増やすと ΔT が約 2 ms 遠ざかるので層別する |

### (b) 自分のデータ・生理で理由づけたもの

| 定数 | 値 | 理由 |
|---|---|---|
| `SE_DT_MAX_MS` | 20.0 | 研究1の症例内 ΔPWTT の SD 18 ms より大きい誤差の拍は寄与しない。文献に前例なし。**一意性の検査の許容差（絶対 20 ms）もこの値に結ぶ** |
| `FOOT_SEARCH_FRAC` | 0.08 | 基線の足を両端それぞれ拍の 8% の範囲で探す。Basso 2024 の onset 補正に相当。切り出しのずれに対する RI の感度を 3 分の 2 に減らした |
| `ALPHA_MIN` | 0.0 | 伝播する脈波は右歪み。Basso は境界を置かないが前進波には事前知識がある。B層で −8 を検定 |
| `NOTCH_MIN_FRAC` | 0.05T | 収縮期ピーク自身の曲率を切痕代用として拾わないための最小距離 |
| `NOTCH_MAX_FRAC` | 0.65T | 駆出時間は心拍 50〜120 で 0.30〜0.55T。切痕がこれより後に来ることは生理的にない |
| `DIA_MAX_FRAC` | 0.85T | 拡張期ピークは切痕から 0.25T 以内 |
| 減衰成分の判定 | 拡張期ピーク +80 ms かつ 0.60T より後 | 3成分以上のとき最も遅い成分が減衰を担っているかの判定。両経路に同じ規則 |

## 判定の読み方（先に決めておく）

- どの閾値でも判定が同じ → 結論は閾値の産物ではない
- 閾値によって割れる → 論文に割れる範囲を書き、「成立」とは書かない
- 「すべて外す」の行が凍結値と大きく違う → 採否そのものが選択になっている

## 指標

| 指標 | 定義 | 出典 | 26番での扱い |
|---|---|---|---|
| ΔT | 反射波ピーク時刻 − 前進波ピーク時刻 | Goswami 2010 と同一 | 主要（× 大動脈PWV、符号 −） |
| ΔT の標準誤差 | Wald（線形化）。**選別のための量で、較正された不確かさではない** | 独自 | 採否（≤ 20 ms） |
| 競合解の広がり | 多点起動の競合解の ΔT の最大差 | 独自 | 記録（一意性の検査に使用） |
| RI | 反射波ピーク高さ / 前進波ピーク高さ | 同上 | 主要（× 末梢血管抵抗、符号 +） |
| DPS | σ_reflected − σ_forward | Goswami 2010 | 記述（符号を事前指定しない） |
| Am_b/Am_p1 | 2次微分 b 波の振幅 / p1 の振幅 | Hellqvist 2024 | 第4の手法（× 大動脈PWV、符号 −） |
| p1 基準 ΔT | 拡張期代用点 − p1 | Hellqvist 2024 | 切痕なし波形の検討用 |

## 既知の限界（閾値では解決しない。先に書いておく）

- **ΔT_PDA と ΔT_landmark は別の量**（Goswami）。ΔT_PDA の絶対値を他研究と比べない
- **ΔT が測るのは導管動脈全体の硬さ**（Epstein）。「大動脈の硬さ」とは書かない
- **第2成分は末梢反射ではない**（Epstein・Hellqvist）。慣例上「反射波」と呼ぶが注記する
- ガンマ経路の心拍交絡 34 ms（歪みガウス 12.6 ms）。形状母数ひとつで立ち上がりと減衰の両方を決める構造による
- 成分を増やすと当てはまりは良くなるが ΔT は約 2 ms 遠ざかる。層別して読む
- 切痕なし波形のランドマーク代用点（肩）は真のピークより約 30 ms 遅れる。PDA の ΔT はその錨から +3 ms

## 判定の読み方（先に決めておく）

- どの閾値でも判定が同じ → 結論は閾値の産物ではない
- 閾値によって割れる → 論文に割れる範囲を書き、「成立」とは書かない
- 「すべて外す」の行が凍結値と大きく違う → 採否そのものが選択になっている

## 既知の限界（閾値では解決しない。先に書いておく）

- **ΔT_PDA と ΔT_landmark は別の量**（Goswami）。ΔT_PDA の絶対値を他研究と比べない
- **ΔT が測るのは導管動脈全体の硬さ**（Epstein）。「大動脈の硬さ」とは書かない
- **第2成分は末梢反射ではない**（Epstein・Hellqvist）。慣例上「反射波」と呼ぶが注記する
- ガンマ経路の心拍交絡 18.8 ms（歪みガウス 12.6 ms・凍結版 14.6 ms）。形状母数ひとつで立ち上がりと減衰の両方を決める構造による
- 成分を増やすと当てはまりは良くなるが ΔT は約 2 ms 遠ざかる。層別して読む
- 切痕なし波形（型3）のランドマーク代用点（肩）は真のピークより約 30 ms 遅れる
- **採用した拍でも ΔT が 20 ms 以上ずれることがある。** 合成波 150 拍（全域）で採用の 1 割、PWDB の条件（心拍 50〜100・雑音 ≤ 0.01・RI ≥ 0.3）の 150 拍では歪みガウス経路 3/55（5%）・ガンマ経路 7/75（9%）。すべて幅広い反射波（σ 90 ms）の拍で、貯留槽と形で区別できない。成分数を変えても同じ解に落ちる（3 成分既定は誤り 6 と悪化）。Wald SE と競合解の広がりは模型の誤りを見ない。28番は歪みガウスの誤採用率 ≤ 10% を退行の門番にする
- **切痕なし波形（型3）では PDA 第2版の ΔT は得られない**（規則で採用しない。理由 `proxy_landmarks`）。
  分解が同定できず、規準をすべて通った当てはめでも ΔT が +23 ms、規準を外すと +50 ms ずれる。
  型3 の拍はランドマーク・p1・早期振幅比で読む（26番の表 2 で型ごとの n を必ず見る）。
  含めた場合の結論は 27番 A 層の「型3 を含める」の行で見る
- 型の割り当てには閾値（肩の顕著さ 5%・極値の高低差 1%）があり、その近傍の拍がどれだけあるかは
  26番の表 2c で監視する

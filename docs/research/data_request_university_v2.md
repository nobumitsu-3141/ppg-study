# 大学の実データを用いたパイロット研究 ― データ取得依頼（第2.0版）

**作成**: 2026-09-08　**作成者**: 川副靖晃（長崎県五島中央病院麻酔科）
**位置づけ**: **全項目版。実際に業者へ出すのは簡易版（`data_request_university_min.md`）とし、
本版は結果が良好で規模を広げる段階になったときの取得仕様として保留する（2026-09-08 決定）。**
本研究の当初の2つの問いを実測データで一から検証するパイロット研究のためのもの。
第1.0版（`data_request_university_v1.md`）は公開データベースの解析で残った論点に絞った限定版である。

## 0. 問いと、このパイロットで決めること

### 0.1 二つの問い

**問い1（構成概念妥当性）**　光電容積脈波を成分波に分解して得た血管指標 ―
成分波のピーク間隔 ΔT、これと身長から定まるスティフネス指標 SI、成分波のピーク高さの比である
反射係数 RI ― は、実際に測定した血管の量（動脈スティフネス、全身血管抵抗）と関連するか。

**問い2（有用性）**　これらの指標で脈波伝播時間法による心拍出量推定（esCCO）の較正定数を
動的に補正すると、独立した参照心拍出量に対する精度が改善するか。

較正定数は年齢・性別・身長・体重から決まり、較正後は症例中固定される。したがって血管状態の
情報を持たない。連続的に得られる血管指標でこれを補正するというのが当初からの着想であり、
問い1はその前提、問い2はその帰結にあたる。**両方に答えられるデータを一度に取る。**

### 0.2 パイロットで決めること

1. **実行可能性** ― 実機の波形から指標が安定して取り出せる割合、参照心拍出量のペア点が
   症例あたり何点得られるか、チャネル間の時刻同期が確定できるか。
2. **効果量の推定** ― 問い1の相関、問い2の誤差率の差の点推定と信頼区間。
3. **次相に進むかの判断** ― 判定規準は §2 に置き、**データを見る前に確定する**。
4. **次相の症例数** ― 2 で得た効果量と分散から算出する。今は決めない。

## 1. 必要なデータ 一覧

チャネル名・項目名は機種と施設のシステムに依存するため、**求める情報の中身**で記す。

### A. 波形（必須。これが無ければ研究が成立しない）

| # | 信号 | 標本化周波数 | 必須度 | 何に使うか |
|---|---|---|---|---|
| A-1 | 心電図（R波が最も明瞭な誘導。II誘導を推奨） | 500 Hz以上、可能なら1,000 Hz | **必須** | 脈波伝播時間の起点 |
| A-2 | 光電容積脈波（SpO₂プローブ）。**表示用ではなく生波形を最優先** | 500 Hz以上 | **必須** | 成分波分解の対象。ΔT・SI・RI はすべてここから作る |
| A-3 | 観血的動脈圧（橈骨動脈） | 500 Hz以上 | **必須** | 脈波伝播時間を中枢区間と末梢区間に分ける。血圧の連続値。実効動脈エラスタンスの算出 |
| A-4 | 光電容積脈波の直流成分（可能なら赤色光・赤外光それぞれの生強度） | 500 Hz以上 | 強く推奨 | 振幅の正規化に依存しない解析。反射係数の解釈に直結する |
| A-5 | カプノグラム、気道内圧 | 100 Hz以上 | 強く推奨 | 呼吸性変動の除去。換気設定の変更点の同定 |
| A-6 | 中心静脈圧の波形 | 100 Hz以上 | あれば | 全身血管抵抗の算出。数値トレンドで代用可 |

**共通の要件**

- **無圧縮・無間引き。**表示のためのダウンサンプル、スパイク除去、欠測の前値保持を
  していないこと。加工している場合は内容を明記すること。
- **欠測はNaNまたは欠測フラグで残す。**ゼロ埋め・前値保持・内挿をしない。
- **全チャネルが同一の時間軸**にあること。ずれている場合は B-4 を必ず開示すること。
- 記録は麻酔導入前（可能なら入室時）から抜管まで**連続**。切り出したものは不可。

### B. 信号処理の仕様（データではないが、無いと A-2 の解析ができない）

反射係数 RI は光電容積脈波の**振幅**から作る指標である。モニタが自動利得制御をかけていると、
振幅の情報は解析に到達する前に失われる。しかも失われたことは波形からは分からない。
**このため、仕様の開示は波形そのものと同等に重要である。**

| # | 開示を求める項目 | 何に効くか |
|---|---|---|
| B-1 | 光電容積脈波チャネルは**表示用か、生波形か** | 表示用なら RI の解釈が原理的に制限される |
| B-2 | **フィルタの種類・次数・遮断周波数**（高域・低域とも） | 帯域制限は成分波の当てはめが依拠する波形上の目印を動かす |
| B-3 | **自動利得制御の有無。あれば時定数と正規化の単位**（拍ごと／固定時間窓／記録全体） | RI が測れるかどうかがここで決まる |
| B-4 | **心電図と光電容積脈波の相対遅延。**値、固定か可変か、機種・モジュール依存か | 遅延が心周期を超えると、通過時間が心周期を法として折り返す |
| B-5 | 各チャネルの**実効標本化周波数**（内部で間引いていないか） | 見かけの周波数と実効値が違う機種がある |
| B-6 | 欠測・アーチファクト区間の扱い（NaN／前値保持／内挿） | 内挿区間を実測として解析すると偽の相関が出る |
| B-7 | **モニタの機種名とソフトウェア版数**、SpO₂モジュールの型番 | 上記すべてが機種依存であるため |
| B-8 | esCCO の**更新周期と平滑化の窓**、および内部で用いている PWTT の定義 | 補正の効果を評価する対象そのものの仕様 |

**追加の提案（費用が小さく、効果が大きい）**

- **利得固定または自動利得制御を切った記録を1例でも取れないか。**同一患者で通常記録と
  比べれば、B-3 の影響を直接測れる。
- **チャネル間の遅延を測る校正信号を1回だけ流せないか。**心電図入力と SpO₂ 入力に
  同時に既知の信号を入れて記録すれば、B-4 が実測値として確定する。
  仕様が非開示でも、これができれば同じ目的を達せられる。

仕様の一部が非開示である場合は、**非開示である旨を明記していただければ十分**である。
推定値や「おそらく」の回答は解析に使えないため不要。

### C. 心拍出量 ― 推定する側と、参照する側（問い2の中核）

| # | 項目 | 必須度 | 備考 |
|---|---|---|---|
| C-1 | **esCCO の出力（時系列）** | **必須** | 評価の対象そのもの |
| C-2 | **esCCO の較正の記録** ― 較正の実施時刻、外部の心拍出量で較正した場合はその値、較正モード | **必須** | 較正定数がいつ・何で決まったかが分からないと補正を評価できない |
| C-3 | **モニタに入力された年齢・性別・身長・体重**（実際の値ではなく、入力された値） | **必須** | 較正定数はこの4つから決まる。入力ミスがあれば esCCO 側の誤差になる |
| C-4 | モニタが表示している **PWTT の値**（時系列） | 強く推奨 | メーカーの計算と我々の計算を照合できる。安価で情報量が大きい |
| C-5 | **肺動脈カテーテルによる熱希釈心拍出量（間欠法）** ― 実施時刻と値 | **必須（中核群）** | 独立した参照。**1症例あたり5点以上**、血行動態が変わった前後を含むこと |
| C-6 | 同カテーテルによる**連続心拍出量**の時系列 | 強く推奨 | 熱希釈ベースで動脈圧と独立 |
| C-7 | **中心静脈圧**の時系列 | **必須（中核群）** | 全身血管抵抗の算出に要る |
| C-8 | 混合静脈血酸素飽和度（連続または間欠） | 強く推奨 | 参照心拍出量の妥当性の傍証 |
| C-9 | 動脈圧波形由来の心拍出量（FloTrac／EV1000等） | あれば | 比較用。**これのみでは独立した参照にならない**（出力が血圧と連動するため） |
| C-10 | 経食道心エコーの左室流出路血流速度時間積分 | あれば | 測定時刻とペアで |

**C-5 の点数について。**方法比較研究では、症例あたり3点以上のペア測定が慣行である。
本研究は血管状態が変化したときの挙動を問うため、**血行動態が動いた前後を含めて5点以上**を
求める。定時の測定だけを5点並べても、変化の無い区間の繰り返しになり情報が増えない。

### D. 血管の量の参照（問い1の中核）

指標が「測っていると称する量」の実測値。**症例間の硬さ**と**症例内のトーヌス**は別物なので、
両方を取る。

| # | 項目 | 必須度 | 備考 |
|---|---|---|---|
| D-1 | **術前の上腕-足首脈波伝播速度（baPWV）または心臓足首血管指数（CAVI）** | **必須** | 術前の生理機能検査から流用できる。**測定日を必ず添える**。症例間の動脈スティフネスの参照 |
| D-2 | 頸動脈-大腿動脈脈波伝播速度（cfPWV） | あれば | 動脈スティフネスの参照標準。実施施設は限られる |
| D-3 | 足関節上腕血圧比（ABI） | 強く推奨 | 末梢動脈疾患の除外。指尖の灌流に直接効く |
| D-4 | **全身血管抵抗** ― C-5〜C-7 から算出。装置が算出しているならその値と**算出式、算出に用いた心拍出量の由来** | **必須（中核群）** | 症例内の血管トーヌスの参照。算出元が動脈圧波形由来の心拍出量だと部分的に循環する |
| D-5 | **灌流指数（perfusion index）の時系列** | **強く推奨** | モニタが既に算出している。末梢血管トーヌスの連続指標として最も安価に得られる。症例内の参照として D-4 を補う |
| D-6 | 実効動脈エラスタンスの算出に必要な要素（PAC の1回拍出量、動脈圧波形） | 強く推奨 | A-3 と C-5／C-6 があれば算出可能。既報で esCCO の誤差と関連が報告されている量 |
| D-7 | **中枢温の時系列** | **必須** | 体温は末梢血管トーヌスを直接動かす。交絡としても、変化を作る因子としても要る |
| D-8 | 術前心エコー（左室駆出率、左室流出路径、E/e'、弁膜症） | 強く推奨 | 前駆出期と1回拍出量に効く |

**D-1 は術前に一度でよい。**問うているのは「同じ年齢の2名を血管の硬さで順序づけられるか」
である。年齢と体格は較正定数に既に入っているため、それを超えて順序づけられなければ
補正の入力として意味を持たない。**したがって年齢を調整した偏相関が主たる評価になる。**

### E. 循環に介入した時刻と量（症例内で血管を動かす。問い1・問い2の両方に効く）

観察しているだけでは血管の状態はゆっくりとしか動かない。**薬で動かした瞬間**が、指標が
血管状態を追うかを最も鋭く問える。とくにフェニレフリンのボーラスは全身血管抵抗を選択的に
上げて心拍出量を下げるため、脈波伝播時間法の誤差が最も出る場面であり、かつ血管指標が
動くべき場面である。**この一点だけでも、公開データベースにはない価値がある。**

| # | 項目 | 必須度 |
|---|---|---|
| E-1 | **血管作動薬の投与時刻と用量**（フェニレフリン、エフェドリン、ノルアドレナリン、バソプレシン、ドパミン、ドブタミン、ニカルジピン、ニトログリセリン、ランジオロール、ミルリノン） | **必須** |
| E-2 | 同上の**シリンジポンプの動作記録**（開始・流量変更・停止の時刻と流量） | **必須** |
| E-3 | 麻酔薬の記録（プロポフォールの目標／実効濃度、レミフェンタニルの流量、吸入麻酔薬の呼気終末濃度の時系列） | **必須** |
| E-4 | 輸液・輸血・出血量の時刻と量、利尿薬 | **必須** |
| E-5 | **体位変換の時刻**（頭低位・頭高位・側臥位・腹臥位）と角度 | **必須** |
| E-6 | 気腹の開始・終了時刻と設定圧 | 該当例で必須 |
| E-7 | 大動脈遮断・解除、体外循環・部分体外循環の開始と終了 | 該当例で必須 |
| E-8 | 麻酔導入・気管挿管・執刀・閉創・抜管の時刻 | **必須** |
| E-9 | 硬膜外麻酔・脊髄くも膜下麻酔の併用と、局所麻酔薬の投与時刻 | **必須** |

**時刻は波形の時間軸と同じ基準で、秒単位まで。**麻酔記録上の5分刻みに丸めた時刻では
E-1 の解析に使えない。丸めがある場合はその旨を明記すること。E-2 のポンプ記録が
取り出せるなら、丸めの問題は回避できる。

### G. 装着と留置（脈波の計時に直接効く。波形の依頼で最も抜けやすい）

橈骨動脈から指尖までは解剖学的に短い区間であり、そこを通る時間の生理的な幅は狭い。
一方で装着部位・左右・プローブの型が変われば、計時は容易にそれ以上動く。
**切り分けるには、次の情報が波形と対になっている必要がある。**

| # | 項目 | 必須度 |
|---|---|---|
| G-1 | SpO₂プローブの**装着部位**（示指／中指／環指／母指／耳朶／前額）と**左右** | **必須** |
| G-2 | SpO₂プローブの**機種・型番**、透過型か反射型か、使い捨てかクリップ型か | **必須** |
| G-3 | 動脈ラインの**留置部位**（橈骨／上腕／大腿／足背）と**左右**、カテーテル径と長さ | **必須** |
| G-4 | 術中にプローブや動脈ラインを**付け替えた時刻と変更後の部位** | **必須** |
| G-5 | 非観血血圧計カフの装着側と測定間隔 | **必須** |
| G-6 | 上肢の体位（外転／体側固定）、駆血帯・タニケットの使用と時刻 | 強く推奨 |
| G-7 | 動脈圧ラインの平坦応答の確認（矩形波試験）を行っていればその記録 | あれば |

### H. 対象と症例数

パイロットであるため、**幅の広さより完全さを優先する。**全項目が揃った症例を確実に集めるほうが、
欠けた症例を多く集めるより価値が高い。

| 群 | 症例数 | 条件 | 何に使うか |
|---|---|---|---|
| **中核群** | **40例** | A ＋ C-5〜C-7（肺動脈カテーテル）＋ D-1 ＋ 動脈ライン | 問い1・問い2の両方 |
| **拡張群** | **100例** | A ＋ D-1 ＋ 動脈ライン（肺動脈カテーテルなし） | 問い1、実行可能性、再現性 |

**選択基準**　成人（20歳以上）、全身麻酔、動脈ライン留置あり、記録60分以上。
**除外基準**　心房細動など R-R 間隔が不整な症例（別集計として残すのは可）、
体外循環中の区間、上肢の手術でプローブ装着が不安定な症例、大動脈弁閉鎖不全症（中等度以上）。

**症例数の根拠**

- **問い1**　相関係数 0.5 を有意水準5%・検出力80%で検出するには29例を要する。
  較正定数の補正入力として意味を持つ指標であれば、この程度の関連は最低限あるはずである。
  0.3 の検出には84例を要するが、それはパイロットの役割ではなく次相で行う。**中核群40例**は
  年齢調整を1変数入れる余裕を含めた数である。
- **問い2**　方法比較研究では症例あたり3点以上のペア測定が慣行であり、25例以上あれば
  誤差率の推定は可能である。**中核群40例×5点以上**で足りる。
- **拡張群100例**は、肺動脈カテーテルを要しない問い1の解析と、実行可能性・再現性の推定を
  精度よく行うためのもの。**これ以上は費用と手続きに見合わない。**

**対象期間**　直近3年程度。機種・ソフトウェア版数が期間内に変わっている場合は
**その時期を明示すること**（B-7 が変われば信号処理も変わり、同じ集団として扱えない）。

**症例の幅**　血管の硬さと抵抗の範囲が狭いと問い1が検出できない。可能であれば
心臓血管外科・肝移植・肝胆膵などの高リスク手術に偏らせず、年齢と併存症の幅を持たせること。

### I. 形式・受け渡し・匿名化

| # | 項目 | 内容 |
|---|---|---|
| I-1 | 波形の形式 | Vital Recorder の `.vital`、EDF、WFDB、または CSV。**独自バイナリなら仕様書を添付すること** |
| I-2 | 時刻の表現 | UNIX時刻またはISO 8601で**ミリ秒まで**。タイムゾーンを明記 |
| I-3 | 波形と数値トレンドの関係 | **同一の時間軸**で。別ファイルでもよいが基準時刻を共有すること |

## 2. 事前に固定する判定規準（データを見る前に確定する）

パイロットの価値は「良かったら進める」を**あらかじめ定義しておくこと**にある。
以下は素案であり、**教授との合意のうえで確定し、データを見る前に凍結する。**

### 2-1. 測定が成立していることの確認（これが通らなければ他の行を読まない）

| 項目 | 通過条件 |
|---|---|
| 陽性対照 | 症例中央値の ΔT と年齢の順位相関が予測の向き（負）で、95%信頼区間が0を含まない |
| 陰性対照 | 症例の通し番号と ΔT の順位相関が、上の関連より明らかに小さい |
| 実行可能性 | 品質基準を通過した60秒ウィンドウが症例あたり60%以上。成分波分解の収束検算の通過率が50%以上 |
| 参照の充足 | 熱希釈心拍出量のペア点が症例あたり3点以上ある症例が、中核群の90%以上 |
| 同期 | 心電図と光電容積脈波の相対遅延が確定できた症例が90%以上 |

### 2-2. 問い1 ― 血管情報との関連

| | 内容 |
|---|---|
| 主要評価 | 症例中央値の ΔT（および SI）と術前 baPWV／CAVI の、**年齢を調整した偏相関** |
| 通過条件 | **絶対値が0.30以上、かつ95%信頼区間が0を含まない** |
| 副次評価 | RI と全身血管抵抗の症例内順位相関の中央値と、症例間の符号検定。RI と灌流指数の症例内順位相関 |
| 介入時の応答 | フェニレフリン投与の前後で、SI・RI が予測の向きに変化するか（対応のある検定） |

0.30 という値は、年齢と体格で既に説明される分を超えて患者を順序づけられるかの目安である。
較正定数は年齢・性別・身長・体重から決まるため、**年齢の情報しか持たない指標は補正に何も
加えない。**したがって年齢を調整した偏相関を主要評価に置く。

### 2-3. 問い2 ― esCCO の精度

| | 内容 |
|---|---|
| 主要評価 | 補正した推定器と補正しない esCCO の、熱希釈心拍出量に対する**誤差率**（Critchley）の差 |
| 通過条件 | **改善が3ポイント以上、かつ95%信頼区間が0を含まない**（差の検定は症例単位のブートストラップ） |
| 副次評価 | Bland-Altman のバイアスと一致限界、除外帯0.5 L/min の4象限一致率、変化量の追随 |
| 評価の作法 | 補正係数は症例単位の交差検証で導出fold のみから推定する。同じ症例で係数を決めて評価しない |

3ポイントという値は仮置きである。非侵襲心拍出量機器のプール誤差率は臨床的な許容水準を
上回ったままであることが報告されており、**臨床的に意味のある最小の改善幅を教授と合意して
確定する。**

### 2-4. 次相に進む条件

**2-1 がすべて通過し、かつ 2-2 または 2-3 のいずれかが通過した場合に、次相へ進む。**
2-1 が通らない場合は、結果ではなく測定系の問題として扱い、B 節の仕様と G 節の装着条件を
見直したうえでパイロットをやり直す。次相の症例数は、パイロットで得た効果量と分散から算出する。

## 3. 前向きに取れる場合に足すもの（後ろ向き抽出では得られない）

後ろ向きの抽出でも §1 は成立する。ただし前向きに設計できるなら、次を足すと研究の力が
大きく上がる。**倫理申請の内容が変わるため、方針は早い段階で決めておく。**

| # | 追加する項目 | 得られること |
|---|---|---|
| P-1 | **観察点をプロトコル化する** ― 入室時（覚醒・安静）、導入後10分、執刀前、フェニレフリン投与の直前と投与後2分・5分、手術終了時。各点で熱希釈心拍出量を測定 | 血管状態が動いた瞬間の前後で、指標と真値が対になる。問い1・問い2の両方が格段に鋭くなる |
| P-2 | **光電容積脈波を2箇所に装着**（指尖と耳朶または前額） | 2部位の差から末梢の伝播時間が直接得られる。モニタが2チャネル取れるかは要確認 |
| P-3 | **自動利得制御を切った、または利得を固定した記録** | B-3 の影響を同一患者で直接測れる |
| P-4 | 麻酔導入前後の baPWV／CAVI を測定 | 症例内の血管トーヌス変化の直接の参照。ただし術中の測定は実務上難しい |
| P-5 | チャネル間遅延の校正信号を各症例の記録開始時に流す | B-4 が実測値として症例ごとに確定する |
| P-6 | 記録開始時に**プローブの装着状態を写真で残す**（部位・向き・テープ固定） | G 節の情報が確実になる |

## 4. 全部は無理な場合の優先順位

1. **B 節（信号処理の仕様）** ― 費用がかからない。**波形より先に取ること。**
   仕様の分からない波形では、反射係数 RI の解析が原理的に成立しない。
2. **A-1・A-2・A-3（心電図・光電容積脈波・観血的動脈圧）と G 節（装着と留置）** ― 最小構成。
3. **C-1〜C-3（esCCO の出力と較正の記録）** ― 問い2 の対象そのもの。モニタから取れる。
4. **D-1（術前の脈波伝播速度）** ― 術前検査からの流用で、問い1 に直接答える唯一の項目。
5. **E-1〜E-3・E-8（血管作動薬・麻酔薬・節目の時刻）** ― 麻酔記録から取れる。
6. **C-5〜C-7（肺動脈カテーテル）** ― 症例数が限られるため中核群のみでよい。
7. **D-5（灌流指数）・A-4（直流成分）・C-4（モニタのPWTT）** ― いずれも安価で情報量が大きい。
8. D-2 以降、A-5、A-6。

## 5. 依頼文に添える一文（案）

> 本依頼は、光電容積脈波の波形解析から得られる血管指標が、測定した血管の量と関連するか、
> およびそれらの指標で心拍出量推定の精度が改善するかを検証するパイロット研究のためのものです。
>
> **B節（信号処理の仕様）は、波形データそのものと同等に重要です。**光電容積脈波の振幅から
> 作る指標を扱うため、フィルタと自動利得制御の仕様が不明なままでは、その解析が原理的に
> 実施できません。仕様の一部が非開示である場合は、**非開示である旨を明記していただければ
> 十分です。**推定値や「おそらく」の回答は解析に用いることができないため、不要です。
>
> また **G節（装着部位と留置部位）** は、波形の抽出とは別のシステムから取る必要があるため
> 見落とされやすい項目ですが、脈波の計時に直接影響するため必須です。
>
> あわせて **I-9（1症例あたりの抽出所要時間と費用、全項目が揃う症例の割合）** をご教示ください。
> 本研究はパイロットであり、結果が良好であれば規模を拡大する予定です。その規模を
> 決めるために必要です。

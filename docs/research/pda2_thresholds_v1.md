## なぜ凍結が要るのか

研究0 の第一報で、ランドマーク法を走らせる**前に**撤退方針を書いてしまい、その予測が
外れた。結果を見てから判断の基準を動かすと、それはもう検証ではない。同じ構図を
閾値でも作らないために、決定試験の前に値を固定し、振れ幅も先に決めておく。

閾値の来歴を3層に分ける。**(c) が結論を左右するなら、その結論は閾値の産物である。**

## (a) 文献から借りたもの

| 定数 | 値 | 出典 | 借用の妥当性についての注意 |
|---|---|---|---|
| `NRMSE_MAX` | 0.02 | Wang 2013 | Wang は指尖 PPG に3ガウスを当てた。標本化周波数・前処理は同一ではない |
| `ERRX_MS` | 6.0 | Wang 2013 | 鍵点（収縮期ピーク・重複切痕・拡張期ピーク）の時間位置の絶対誤差の総和。500 Hz では格子が 2 ms、鍵点3つで下限 6 ms になり閾値と同じ大きさになるので、放物線補間で副標本精度を出してから測る |
| `ERRY` | 0.01 | Wang 2013 | 同上の振幅版 |
| `LOWPASS_HZ` | 18.0 | Tigges 2017・Couceiro 2015・**Basso 2024** | 3本とも 18 Hz 4次 Butterworth。Basso はさらに**1拍 28 標本（平均 42 Hz）へ再標本化**しており、我々は 500 Hz のまま。標本数が 15 倍で拡張期の裾が二乗和を支配する。27番 B層で 40 Hz を検定する |
| 歪みガウス基底と**ピーク母数化** | (a, m, σ, α) | **Basso 2024** | 我々と同一の基底・同一の母数化が既に発表されていた。独立に同じ設計に到達していた |
| 不等式制約（第1成分の振幅最大・最頻値の単調増加） | 罰則で実装 | **Basso 2024**（内点法で厳密制約） | 制約の内容は同一。実装が罰則か厳密かだけが違う |

## (b) 自分のデータで理由づけたもの

| 定数 | 値 | 理由 |
|---|---|---|
| `SE_DT_MAX_MS` | 20.0 | 研究1で観測した症例内 ΔPWTT の標準偏差が 18 ms。これより大きい標準誤差の拍は問いに寄与しない。当てはまりの規準だけでは σ=11,725 ms の解が通ることを 25番 T4 で確認した。**読んだ文献のいずれも母数の標準誤差を報告していない。この規準は我々独自である** |
| `ALPHA_MIN` | 0.0（右歪みのみ） | **Basso 2024 は境界を置かない**（「α の範囲について事前知識がない」）。しかし**前進波については事前知識がある** ── 伝播する脈波は立ち上がりが速く減衰が遅い、すなわち右歪みである。左歪みは進行波として非生理的。α を見直すきっかけになった共分散の破綻は境界近傍の母数を固定する処理で独立に解決済みで、下限を外す必要はない。**文献と割れる選択なので 27番 B層で −8 に緩めた場合を検定する** |

## 事前指定した感度解析

`scripts/27_threshold_sensitivity.py`。**26番の実行前に書き、振れ幅を固定した。**

### A 層（当てはめ後に効く規準・当てはめ直し不要）

当てはめの診断量は 26番が被験者ごとに保存する（`nrmse` `errx` `erry` `n_landmark_matched`
`dt_se` `ambiguous`）ので、採否だけを作り直せば済む。数秒で終わる。

| 規準 | 振る値 |
|---|---|
| NRMSE 上限 | 0.010 / 0.015 / **0.020** / 0.030 / 0.050 / ∞ |
| Errx 上限 | 3 / **6** / 12 / 25 / ∞ ms |
| Erry 上限 | 0.005 / **0.010** / 0.020 / ∞ |
| ΔT の SE 上限 | 5 / 10 / **20** / 50 / ∞ ms |
| 一意性の検査 | **あり** / なし |
| すべて外す | 採否を全部無効化（共分散が計算できた拍のみ） |

再計算した採否が 26番の保存値と一致するかを毎回検算する。一致しなければ表は無効とする。

### B 層（当てはめ自体を変える規準・当てはめ直しが要る）

被験者番号を 7 で割った余りが 0 の集団（約 625 名。年齢層は均等に入る）に固定する。
**結果を見てから部分集合を選び直さない。**

| 条件 | 値 | 根拠 |
|---|---|---|
| 鍵点の重み | 1（重みなし相当） / **20** / 100 | Wang 2013 は 1〜100 を全探索。我々は探索していない |
| 低域通過 | 10 / **18** / 25 Hz | Tigges 2017・Basso 2024 は 18 Hz |
| 成分間隔の下限 | 15 / **30** / 60 ms | 根拠なし。振って確かめる |
| 成分を増やすか | **増やす** / 増やさない | Wang 2013 は 4→5 と増やす。Basso は増やさず L を並べる |
| **40 Hz へ落として当てはめ** | **500 Hz のまま** / 40 Hz | Basso 2024（1拍 28 標本≒42 Hz）・Tigges 2017（40 Hz） |
| **拍の 0〜0.9T だけ当てはめ** | **全区間** / 0.9T まで | Goswami 2010（「関心のある母数は 0〜0.9T に収まる」として裾を合わせない） |
| **歪みの下限** | **0（右歪みのみ）** / −8 | Basso 2024 は境界を置かない |

## 判定の読み方（先に決めておく）

- **どの閾値でも判定が同じ** → 結論は閾値の産物ではない。そのまま報告する
- **閾値によって割れる** → その閾値が結論を作っている。論文には**割れる範囲を明記**し、
  「成立」とは書かない
- **「すべて外す」の行が凍結値と大きく違う** → 採否そのものが選択になっている。
  26番の A・B・C の3段と合わせて読む

## 指標の追加（第1版）

**差分パルス幅 DPS = σ_reflected − σ_forward**（Goswami 2010）を `indices()` に加えた。
同論文では健常 30歳で 10 ms、高血圧 55歳で 90 ms と大きく開いている。
Lee 2011（真の熱希釈 SVR 参照）と Awad 2007 も**脈波の幅**が反射係数より末梢血管抵抗を
よく弁別すると報告しており、幅という量は独立に支持されている。
成分の幅は既に当てはめているので追加の計算費用はゼロ。
**ただし真値との向きの予測は立てられないので、26番では記述のみ（事前指定の符号なし）とする。**

## 目標変数の追加（第1版）

**頸大腿PWV を事前指定の副次目標に加えた**（Epstein 2014）。

Epstein 2014（PWDB を作った研究室の前身研究）は 1次元75動脈モデルで、
**SI を動かすのは導管動脈全体の硬さであって大動脈ではない**ことを示した。
導管全体を +200% 硬くすると SI は 60% 超上がるが、**大動脈だけを硬くすると PPT はむしろ延び、
SI は微減する**（符号が逆になる）。末梢抵抗・末梢コンプライアンスの効果は 2% 未満。

> 「硬さ指数は大動脈脈波伝播速度の直接の指標ではない。」

**主要目標（大動脈PWV・符号 −1）は凍結したまま**、頸大腿PWV を副次として並べる。
そして結果がどうであれ、**「ΔT は大動脈の硬さを測っている」とは書かない。**

## 用語の訂正（第1版）

Epstein 2014 は、**すべての末梢反射を消しても2つのピークが到達時刻を変えずに残る**ことを
示した。第2ピークは末梢反射ではなく、大動脈基部から伝播する波面と、分岐・先細り・大動脈基部での
その反射から成る。**PDA の第2成分を「反射波」と呼ぶ根拠は弱い。**
測定量としては導管の硬さとともに動くので指標には使えるが、原稿では
「第2成分（慣例に従い反射波と呼ぶが、末梢反射ではない）」と注記する。

さらに Goswami 2010 は、**分解由来の指標が計測由来（ランドマーク）の指標と系統的にずれる**理由を
数式で示している。計測波形の第2ピーク高さ h₂ = p_f(t₂) + p_r(t₂) は前進波の裾を含むので、
**RI_PDA < RI_landmark、ΔT_PDA > ΔT_landmark** となる（実測で RI 0.78 対 0.49、ΔT 142 対 228 ms）。
**PWDB で「ランドマークは通り PDA は通らない」という結果を「PDA が壊れている」とだけ読むのは誤りである。**

## 既知の未解決（閾値では解決しない）

- **重複切痕の無い波形**（Dawber 3〜4型）で ΔT の誤差が 38〜55 ms。合成波で確認済み。
  これは閾値の問題ではなく、波形に情報が無いことによる。26番の波形型別の表で
  実データでの影響を見る
- **ガンマ経路の心拍数交絡が 27 ms**（two_stage は 13.4 ms）。位置母数を足して 155→27 ms
  まで改善したが、形状母数ひとつで立ち上がりと下降の両方を決める構造は残る
- **ΔT に系統誤差**（合成で +5.9 ms）。症例内の変化を見る設計では相殺されるが、
  **絶対値を他研究と比べてはならない**
- **採否規準は正確さではなく当てはまりを選ぶ**。成分を増やすと当てはまりは良くなるが
  ΔT は真値から約 2 ms 遠ざかる。26番で成分を増やしたかどうかを層別する

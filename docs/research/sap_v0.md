# 統計解析計画（SAP）v0（下書き・チェックリスト C-5）

対象: 研究計画書 v0 の段階1（VitalDB 開発研究）。
凍結の原則: 実データで主要解析を回す前に本書の閾値・手順を確定し、以後の変更は履歴を残す。

## 1. 解析対象集団

- 適格: SNUADC 波形（PLETH・ECG・ART）と CO 系トラック（Vigileo/EV1000/Vigilance/CardioQ）を持つ症例。
- 除外: 記録長 < 30 分、脈波欠損率 > 50%、CO 値が 10 分未満しか無い症例（数値は Phase 1 で確定し凍結）。
- 拍レベル除外: SQI 不通過、PDA 収束検算（境界張り付き・振幅ゼロ・競合解の曖昧さ）不通過。棄却率を報告。

## 2. 前処理（固定手順）

1. R波検出 → 1拍切り出し → SQI → 連続4拍のアンサンブル平均（合成波形検証の帰結）
2. PDA（skewed-Gaussian 2カーネル）→ ΔT・RI、SI＝身長/ΔT
3. PWTT＝R波→脈波立ち上がり（1分中央値に平滑化）
4. 参照COとの対応付けは時刻同期のうえ 1 分ウィンドウ中央値同士で行う

## 3. モデル

- 対照: esSV = K0 × (β − α·PWTT)、K0 は年齢・性別・身長・体重の回帰。esCCO_ctrl = esSV × HR。
- 提案: K = K0 × f(SI, RI)（f は一次を基本、交互作用は感度解析）。esCCO_prop。
- 較正は症例内の初回ウィンドウで実施（実機の較正手順を模擬）。

## 4. 検証設計

- 症例単位の 5-fold 交差検証（拍・ウィンドウ単位のリークを禁止）。
- fold 間でモデル係数を再推定し、検証 fold のみで評価する。

## 5. 評価項目

- 主要: percentage error（Critchley-Critchley）: 対照 vs 提案の差。
  症例内相関を考慮しブートストラップ（症例単位リサンプリング, 2,000回）で95%CI。
- 副次: Bland–Altman（バイアス・LoA, 反復測定補正）、4分割トレンド concordance、
  ΔRI と ΔSVR（SVR = (MAP−CVP)/CO×80）・ΔSI と血圧変動の相関。
- 判定（無益性・スライド6.7のGATE）: 提案が対照より percentage error を有意（両側5%）に
  低下させない場合、臨床段階へ進まない。

## 6. 感度解析

- 参照CO装置別（FloTrac系 vs Vigilance II 熱希釈）
- 3カーネルPDA（P2/P3非分離への備え・スライド6.12）
- アンサンブル平均の拍数（1/4/8拍）
- SQI 閾値の ±変動

## 7. 欠測・多重性

- 欠測ウィンドウは補完せず除外（欠測率を報告）。
- 主要評価は1つ。副次は探索的とし多重性調整を行わない（その旨明記）。

## 1. 解析対象集団

### 1.1 コホート（実測で確定・2026-08-28）

VitalDB 6,388症例のトラック一覧から確定した（波形データそのものは未参照）。

| 条件 | 症例数 |
|---|---|
| 脈波（SNUADC/PLETH） | 6,157 |
| 心電図（SNUADC/ECG） | 6,355 |
| 動脈圧（SNUADC/ART） | 3,645 |
| CO トラックを持つ（いずれかの装置） | 993 |
| **脈波＋心電図＋動脈圧＋CO（本研究の対象集団）** | **874** |

装置別内訳（重複あり）: EV1000 552 / Vigileo 305 / CardioQ 24 / Vigilance II 5。

補足:
- CO・CI・SV・SVI のいずれかを持つ症例は全例が CO を持ち、両定義で差は生じなかった。
- 動脈圧を要求しない場合は 888 例で、要求しても 14 例しか減らない。
  ΔMAP 調整（§7.3）に動脈圧が必要なため、**動脈圧は選択基準として維持する**。
- Vigilance II（熱希釈）は 65 例あるが、うち 60 例で**脈波が記録されておらず** 5 例しか残らない。
  動脈圧の欠落が原因ではないため、基準を緩めても回復しない。
- スライド6.7の「552例」は対象集団の総数ではなく、**EV1000 単独の該当数**に一致する。
  スライドの数値は EV1000 のみを数えたものと考えられ、実際の対象集団はより大きい。

### 1.2 参照COの独立性という制約（重要）

対象集団 874 例のうち 857 例（98%）の参照COは FloTrac 系（Vigileo・EV1000）であり、
**動脈圧波形から算出**されている。FloTrac 系は脈圧の標準偏差に血管コンプライアンス補正を
掛けて1回拍出量を推定する構造で、血圧変動と並行してCO値が動くこと、
体血管抵抗が信頼性に影響することが報告されている。

本研究が検証したいのは「PWTT法の誤差が血管状態に依存し、脈波由来の血管指標で補正できるか」である。
参照側も血管状態に応じて動くため、**一致度の改善が真のCO精度向上を意味するのか、
参照側の血管依存性と提案側の補正が同方向に動いただけなのかを、FloTrac 系だけでは区別できない**。

VitalDB 内では解消できない制約である（独立な参照は熱希釈5例・食道ドプラ24例のみ）。
そこで §7 に、この制約へ正面から対処する事前指定解析を置く。

### 1.3 適格・除外基準

- 適格: SNUADC 波形（PLETH・ECG・ART）と CO 系トラック（Vigileo/EV1000/Vigilance/CardioQ）を持つ症例。
- 除外: 記録長 < 30 分、脈波欠損率 > 50%、CO 値が 10 分未満しか無い症例（数値は Phase 1 で確定し凍結）。
- 拍・ウィンドウレベル除外: SQI 不通過、PDA 収束検算不通過、後述のノイズ目標に到達しないウィンドウ。棄却率を報告。
- 症例採用は有効ウィンドウ ≥ 12（較正1 + 評価11以上）。

## 2. 指標の定義（凍結）

同じ「SI・RI」でも定義が複数あり、先行文献でも統一されていない。実データを見る前に
真値既知の合成データで同定性を比較し（`tests/test_index_variants.py`）、以下に凍結する。

### 2.1 主要指標

| 記号 | 定義 | 選定理由（合成データでの実測） |
|---|---|---|
| **ΔT** | 成分波1（前進波）と成分波2（反射波）の**ピーク時刻の差** | 候補5定義中で最も頑健。良好条件で誤差 ≤1.8 ms |
| **RI** | 成分波2と成分波1の**ピーク高さの比** | 候補3定義中で最も頑健。良好条件で誤差 ≤0.9%。振幅パラメータ比 a₂/a₁ は歪度の分だけずれ、面積比は誤差が最大 |
| SI | 身長[m] ÷ ΔT[s] | 文献比較のため併記する。**症例内の相対変化では身長が完全に約分される**ため（ΔSI% = ΔT₀/ΔT − 1）、モデルに入る情報は ΔT と同一。合成コホートで ΔPE の差は 0.1〜0.3ポイント、有意性判定は不変 |

「ピーク高さの比」は**成分波の実際のピーク値**の比であり、振幅パラメータ a の比ではない
（skewed-Gaussian ではピーク高さが歪度 α と幅 σ に依存するため両者は一致しない）。

### 2.2 副次・感度解析の指標

- **立ち上がり間 ΔT**（前進波の立ち上がり → 反射波の立ち上がり、各成分の自ピーク高の **20%** 到達点で定義）。
  生理学的には反射波の「到達時刻」をより直接に表すが、反射波の立ち上がりは前進波の裾に埋もれて
  当てはめの拘束が最も弱い領域にあたる。実測では**当てはめ誤差を 4〜6 倍に増幅**した
  （正しい解に収束した拍でも ΔT_peak 1.1 ms に対し 6.5 ms）。よって主要指標には据えず、
  感度解析として報告する。規約（20%）は本書で固定し、事後に変更しない。
- 振幅パラメータ比 a₂/a₁、成分波面積比。
- 3カーネル PDA（P2/P3 非分離への備え・スライド6.12）。

## 3. 前処理（固定手順）

1. R波検出 → 1拍切り出し → SQI
2. **アンサンブル平均の拍数は各ウィンドウのノイズから決める（適応方式）**
   - 相対ノイズ σ_rel を2階差分の頑健SDから推定（合成データでの推定誤差 ≤1.6%）
   - 必要拍数 n = ⌈(σ_rel / 0.003)²⌉、下限4拍・上限16拍
   - **上限16拍でも実効ノイズが目標 0.003 に届かないウィンドウは棄却する**
   - 採用した σ_rel・拍数・当てはめ本数は特徴量とともに記録し、Phase 2 で分布を報告する
3. PDA（skewed-Gaussian 2カーネル）→ §2 の定義で ΔT・RI（ウィンドウ内中央値）
4. PWTT＝R波→脈波foot（1分ウィンドウ中央値）。
   **重要**: VitalDBの脈波チャネルはECGに対し症例固有の固定遅延（実測~670ms）を持つため、
   (a) 遅延は症例レベルで推定し折り返しを展開する（`estimate_pleth_lag`）、
   (b) PWTTの絶対値は装置遅延を含むので**症例内の変化量のみを解析に用いる**
   （較正点からのΔで固定遅延は相殺）。絶対値の症例間比較・既報との直接比較は行わない
5. 参照COとの対応付けは時刻同期のうえ 1 分ウィンドウ中央値同士で行う

**適応方式にした理由**: 固定4拍では、ノイズが上がると2カーネル分解の解が二峰化し、
**別解に落ちた拍の 16/17 が収束検算を通過してしまう**（境界に張り付かず、競合盆地も無く、
自信を持って誤った解に収束するため）。検算は最後の砦にならないので、実効ノイズを
前処理側で抑えることが唯一の防壁になる。実測では相対ノイズ 2% のとき固定4拍で正解率
11/20 だったものが適応拍数（15拍）で 20/20、3% では固定4拍が 0/20 だった。

目標値 0.003 は保守的に設定してある（実効 0.0042 でも実測 19/20 は正解していた）。
公開データは症例数に余裕があり、偽陽性の混入コストのほうが高いため、
取りこぼしよりも安全側を採る。Phase 2 で実データの σ_rel 分布と棄却率を見て見直す場合は
改訂履歴に残す。

## 4. モデル

- 対照: esSV = K0 × (β − α·PWTT)、K0 は年齢・性別・身長・体重の回帰。esCCO_ctrl = esSV × HR。
- 提案: K = K0 × f(ΔT, RI)（f は一次を基本、交互作用は感度解析）。esCCO_prop。
  f に入るのは症例内の相対変化（Δ%）であり、絶対値ではない。
- 較正は症例内の初回ウィンドウで実施（実機の較正手順を模擬）。

## 5. 検証設計

- 症例単位の 5-fold 交差検証（拍・ウィンドウ単位のリークを禁止）。
- fold 間でモデル係数を再推定し、検証 fold のみで評価する。
- 機構は合成コホートで検証済み: 補正の余地が実在するデータでは3シードとも有意差を検出し、
  余地の無いデータでは3シードとも偽陽性ゼロ（`tests/test_pipeline_synthetic.py`）。

## 6. 評価項目

- 主要: percentage error（Critchley-Critchley）: 対照 vs 提案の差。
  症例内相関を考慮しブートストラップ（症例単位リサンプリング, 2,000回）で95%CI。
- 副次: Bland–Altman（バイアス・LoA, 反復測定補正）、4分割トレンド concordance、
  ΔRI と ΔSVR（SVR = (MAP−CVP)/CO×80）・ΔΔT と血圧変動の相関。
- 判定（無益性・スライド6.7のGATE）: 提案が対照より percentage error を有意（両側5%）に
  低下させない場合、臨床段階へ進まない。

## 7. 参照COの独立性に対処する事前指定解析

§1.2 の制約に対し、以下を主要解析と同時に実施する。いずれも実データを見る前に確定した。

### 7.1 前提検証（参照COを一切使わない）

本研究の前提は「PWTT が血管状態の影響を受けている」ことであり、これは**参照COなしで検証できる**。

- 症例内で ΔPWTT を ΔΔT%・ΔRI%（および ΔMAP%）に回帰し、血管指標で説明される成分を推定する。
- 対象は 874 例全例。参照COの質に一切依存しない、最も頑健な検証。
- 前提が成り立たなければ、以降の補正の議論そのものが成立しない。
  **この結果は主要結果と並べて必ず報告する。**

### 7.2 非FloTrac 参照での確認

- Vigilance II（熱希釈・5例）＋ CardioQ（食道ドプラ・24例）＝ 29例。
  食道ドプラは下行大動脈の血流速度を直接測るため、**動脈圧波形からは独立**である。
- 検出力は不足するが、効果の向きと大きさが FloTrac 系と整合するかを見る。
  整合しなければ、FloTrac 系での改善は参照側の性質による可能性を強く示唆する。
- 症例数が少ないため仮説検定は行わず、点推定と信頼区間の記述にとどめる。

### 7.3 血圧との関係（記述のみ・解釈の関門にはしない）

当初は「ΔMAP を共変量に入れて ΔΔT%・ΔRI% の係数が残るか」を判定に使う計画だったが、
**合成データでの検証により、この判定には判別力が無いことが分かった**
（`tests/test_reference_independence.py`）。ΔMAP と血管指標はいずれも血管状態を反映して
強く共線であり、真の効果があるシナリオでも係数は割れ、符号すら反転する。
増分価値（対照＋血圧 vs 対照＋血圧＋血管指標）の形にしても、真の効果があるシナリオで
増分は −0.16 ポイントにとどまり、偽の改善シナリオ（−0.18）と区別できなかった。

したがって以下は**記述として報告するにとどめ、解釈の関門には用いない**。

- percentage error を4条件で併記する: 対照（PWTTのみ）／＋ΔMAP%／＋血管指標／＋両方
- ΔMAP% と ΔΔT%・ΔRI% の相関係数を報告し、共線性の程度を読者が判断できるようにする

MAP は SNUADC/ART 波形のウィンドウ平均から算出する。

### 7.4 装置層別の係数比較

- 補正係数 c1・c2 を装置層（EV1000 / Vigileo / 非FloTrac）ごとに推定し、系統差を見る。
  参照側の性質を拾っているなら層間で係数が食い違うはずである。

### 7.5 その他の感度解析

- §2.2 の代替指標定義（立ち上がり間ΔT・a₂/a₁・面積比）
- 3カーネルPDA
- アンサンブル拍数の目標ノイズ（0.003 を 0.002 / 0.004 に振る）

### 7.6 結果の解釈規準（事前に固定）

合成データで各判定法の判別力を検証した結果（`tests/test_reference_independence.py`）:

| 判定法 | 真の効果 | 偽の改善（参照が血圧を追う） | 判別力 |
|---|---|---|---|
| 主要評価（ΔPE の有意性） | 3/3 有意 | **3/3 有意** | **無し** |
| §7.1 前提検証 r²_vasc | 0.658 | **0.001** | **有り** |
| §7.3 血圧を超える増分 | −0.16pt | −0.18pt | 無し |

**主要評価の有意性だけでは、真の効果と参照側の性質への追随を区別できない。**
区別できるのは §7.1 の前提検証のみである。よって解釈規準を次のように固定する。

主要評価で改善が示された場合でも、以下を満たさない限り
「PWTT法の精度が向上した」とは結論せず、「FloTrac系との一致度が向上した」にとどめる。

1. **§7.1 の前提検証で、血管指標が ΔPWTT の変動を有意に説明すること（必須）**
2. §7.2 の非FloTrac 部分集合（29例）で効果の向きが一致すること（支持材料。
   検出力不足のため必須条件とはしないが、向きが逆なら強い警告と解釈する）

逆に、主要評価で有意差が出なくても §7.1 が強く成立する場合は、
「前提は成立するが、この補正の形では誤差を減らせなかった」という結論になる
（指標ではなくモデル形の問題である可能性を考察する）。

この表と規準は論文の考察・限界の項にそのまま記載する。

## 8. 欠測・多重性

- 欠測ウィンドウは補完せず除外（欠測率を報告）。
- 主要評価は1つ（§6 の percentage error の差、§2.1 の指標定義による）。
- 副次・感度解析はすべて探索的とし、多重性調整を行わない（その旨を論文に明記する）。
- **指標定義の選択は実データを見る前に §2 で凍結済み**であり、実データでの
  当てはまりの良さによる事後選択は行わない。

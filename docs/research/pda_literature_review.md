**作成**: 2026-09-04

**動機**: PWDB で我々の PDA だけが落ちた。実装の問題か、PDA という枠組みの問題かを文献で確かめる

> **結論を先に**: 我々の実装には文献に照らして**5つの致命的な問題**がある。とくに

## 1. Tigges 2017 ― データ駆動でモデルを選ぶ

実際の指尖脈波 **7,805拍**（腕挙上研究3,725 ＋ MIMIC-II 4,080。Dawber クラス I〜IV を網羅）に対し、
4種の基底関数 × 次数 M=1〜6 を当てはめ、**補正赤池情報量規準（AICc）**で最良モデルを選ぶ頻度を数えた。

| 基底関数 | 最良となった割合（全体） |
|---|---|
| **Gamma M=3** | **28.1%** ← 推奨 |
| Rayleigh M=2 | 14.4% |
| Gamma M=4 | 11.4% |
| Gamma M=5 | 9.1% |
| Log-Normal M=4 | 7.4% |
| Normal M=1 | 5.4% |
| **Normal M=2** | **1.2%** ← **我々の選択に最も近い** |
| Normal M=5（Couceiro 式） | 0.9% |

基底関数の定義（いずれも振幅・尺度・位置の3母数）:

```
Normal      g = a·exp[−(t−μ)²/2σ²]
Log-Normal  g = a·exp[−(ln t−μ)²/2σ²]
Rayleigh    g = a·t·exp[−(t−b)²/2σ²]
Gamma       g = a·t^(α−1)·exp(−βt)        ← 指数減衰の裾を持つ
```

**Gamma が勝つ理由は構造にある。** `exp(−βt)` の裾は拡張期の下降そのものであり、
1本で「立ち上がり ＋ 減衰」を表せる。我々の歪みガウス関数にはこの裾がない。

前処理も明示されている。18 Hz の4次 Butterworth 零位相低域通過、Zong のアルゴリズムで拍を検出し
**極小点で正確に切り出す**、**各拍から線形ベースラインを推定して差し引く**、振幅を1に正規化、
AICc のために 40 Hz へダウンサンプリング。当てはめの精度改善は **M=3 を超えると頭打ち**になる。

## 2. Fleischhauer 2020 ― 我々が2カーネルの根拠にした論文

19種の PDA アルゴリズム（Gaussian・Gamma・GammaGaussian × 2〜4カーネル ＋ Gaussian 5）を、
雑音と体動を加えた模擬信号と実測 PPGI（カメラ）で比較した。評価は
**再構成波形の2次微分**の NRMSE（元波形より厳しい規準）。

### 我々に都合のよい所見

- **2カーネルが雑音・体動に最も頑健**（NRMSE で 14.09% の改善）。カーネルが増えるほど雑音に適合してしまう
- 形態の保存能力は、カーネルを増やしてもほとんど変わらない

### 我々に都合の悪い所見（こちらが本質）

> **「2カーネルの欠点は、すべての反射が単一のカーネルに凝縮されることであり、
> 収縮期成分と特定の反射との関係を評価する可能性を排除してしまう。」**
> （原文: *The drawback is that all reflections are condensed in a single kernel,
> which rules out the possibility of assessing the relationship between the systolic
> component and specific reflections.*）

**これは我々が ΔT と RI でやろうとしたことそのものである。** 引用した論文自身が、
その用途に2カーネルを使えないと書いている。我々は「2カーネルの根拠」としてこの論文を引きながら、
その2カーネルが何のために推奨されているのか（雑音耐性であって成分の分離ではない）を取り違えた。

そのほか:

- **Gamma を含むアルゴリズムが純 Gaussian より一貫して良い**（Tigges・Huang 2015 と一致）
- **初期値の与え方が決定的**。微分に依存する初期化（Couceiro は2次・3次・4次微分、Sorelli は1次微分）は
  雑音を増幅する。**汎用の初期値（generic）が最も頑健**であった
- Couceiro の5ガウス（Gauss5couceiro）は雑音下で**全アルゴリズム中最悪**の NRMSE（−10.94）
- 最良の2カーネルは **GammaGauss2generic**（NRMSE 0.9497）
- Gamma の実装上の注意: Γ(α) がカーネル数の多い場合に倍精度の範囲を超えて発散しうる

## 3. Wang 2013 ― 「当てはめの良さ」と「鍵点の正しさ」は別物である

問題設定が我々と同じである。

> 既存手法は**脈波の鍵点（crest と trough）の推定誤差に注意を払っていない**。
> しかし人の血管状態の推定は鍵点の位置に依存する。
> これら頂点の当てはめ誤差は、RTT や AIx といった母数の計算に大きく影響しうる。

### 解決策: 重み付き最小二乗（WLS）

```
MSE = (1/N) Σ (wₙ/W)·[f_DVP(n) − f_MG(n,Θ)]²
```

**鍵点の重み wₙ を 1〜100 の範囲で振り**、他の点は 1 に据え置く。100通り試し、
3つの規準を多基準意思決定（MCDM）で統合して最適な重みを選ぶ。

| 規準 | 定義 | 許容閾値 |
|---|---|---|
| NRMSE | 重み付き正規化二乗平均平方根誤差 | **< 2%** |
| **Errx** | 頂点・谷の**時間位置**の絶対誤差の総和 | **< 6 ms** |
| Erry | 頂点・谷の**振幅**の絶対誤差の総和 | < 0.01 |

さらに、**4ガウスで規準を満たさなければ5ガウスに増やす適応的な次数選択**を行う。
初期値は2次微分の特徴点（D1〜D4）から、波形の5型（Dawber の4型を拡張）ごとに与える。

150拍で NRMSE < 2.0%、鍵点の推定精度も良好と報告している。

## 4. Couceiro 2015 ― 5ガウスと不等式制約

初期値と境界は Takazawa の a〜e 波（2次微分）に Wf 波を加えて決める。Wang 2013 に倣った発見的手法。
最適化は内点法。**成分間に不等式制約を課す**点が我々と決定的に違う。

```
a1 − a2 ≤ 0  ∧  a1 − a3 ≤ 0              g1 は前進波の立ち上がり前半を担うので小さい
a3 − a2 ≤ 0  ∧  a4 − a2 ≤ 0  ∧  a5 − a2 ≤ 0   前進波 g2 が最大振幅
a5 − a4 ≤ 0                                 再反射 g5 は g4 より小さい
b1 ≤ b2 < b3 ≤ b4 ≤ b5                      位置は単調増加
```

成分の役割も固定されている。**g1 + g2 = 主前進波**、g3 = 収縮後期波、g4・g5 = 反射波。
指標は T1_2、T1_d、R1_2、R1_d、SI、RI で、**T1_d・R1_d が SI・RI に対応する**。

我々の実装は成分間に一切の不等式制約を持たない。境界だけである。
**「第1カーネルが前進波、第2カーネルが反射波」を仮定しているが、それを強制する制約がない。**

## 5. Lee 2011 ― PPG から SVR を読む先行研究（真の熱希釈参照）

- ICU 患者 48名。**肺動脈カテーテルの熱希釈 CO** から SVR = 80×(MAP−CVP)/CO。**循環論法がない**
- **PPG に高域通過フィルタをかけていない**（波形を保存）
- 手法は回帰ではなく **3群（SVR < 900 / 900〜1200 / > 1200 dyn·s·cm⁻⁵）への分類**。Bayes 分類器
- 特徴量: 脈波幅、**peak-to-notch time（TPN）**、反射係数（RI）、notch time ratio、
  PPG 変動性（LF/HF ほか）、心拍数、平均血圧
- 最良の特徴部分集合で **Cohen κ = 0.57**。低 SVR の弁別は感度 85%・特異度 86%
- 先行の Awad 2007 では、**脈波幅（半値幅）が SVR の最良の指標**であった

**含意**: PPG から血管抵抗を読む文献の主力は RI ではなく**幅と時間の特徴**であり、
単変量の相関ではなく**多変量の分類**である。我々は RI 単独の順位相関に賭けていた。

## 6. 我々の実装の何が問題か（優先順位つき）

| # | 問題 | 根拠 | 深刻度 |
|---|---|---|---|
| 1 | **2カーネルでは反射が単一カーネルに凝縮され、成分間の関係を評価できない** | Fleischhauer 2020 の考察（我々が引用した論文自身） | **致命的**。用途と手法が矛盾している |
| 2 | **鍵点の位置の正しさを検算していない** | Wang 2013。我々の検算（境界張り付き・振幅ゼロ・再現性）は最適化が収束したかを見るだけで、成分が正しい特徴の上に載ったかを見ていない | **致命的**。誤った解が ok として通る |
| 3 | **基底関数に拡張期の減衰の裾がない** | Tigges 2017（Gamma M=3 が最良、Normal M=2 は 1.2%）、Fleischhauer 2020（Gamma > Gaussian） | **重大**。第2カーネルが拡張期を吸収し心拍数に引きずられる |
| 4 | **成分間の不等式制約がない** | Couceiro 2015 の a・b の制約 | **重大**。前進波と反射波の役割が保証されない |
| 5 | 2次微分に依存する初期化 | Fleischhauer 2020（微分依存の初期化は雑音を増幅。generic が最頑健） | 中。VitalDB の処理済み波形では効く |
| 6 | 拍ごとの線形ベースライン除去をしていない | Tigges 2017・Wang 2013 の前処理 | 中 |
| 7 | 残差が一様重み | Wang 2013 の WLS | 中（2 と同根） |

### とくに 1 と 2 について

**問題1** は方法の選択と目的の不整合である。雑音耐性のために2カーネルを選び、
成分間の関係（ΔT・RI）を測ろうとした。文献はこの両立を否定している。
研究1 の Methods はこの点を誤って引用している。**訂正が必要である。**

**問題2** は検算の設計思想の誤りである。我々は「最適化が安定したか」を検算していた。
測るべきは「**成分が意図した生理的特徴の上に載ったか**」である。Wang 2013 の Errx（鍵点の
時間位置の誤差 < 6 ms）はそのための規準であり、我々にはこれに当たるものがない。
PWDB で ΔT が真値を追わなかったのは、収束していない拍が混ざっていたからではなく、
**収束した拍が間違った場所に収束していた**からだと考えられる。

## 7. どう作り直すか（設計案）

**設計目標**: 特定のデータベースに合わせない。**どの波形型でも同じアルゴリズムで、
鍵点を規定の精度で当てられること**を要件にする。

| 要素 | 現行 | 改訂案 | 根拠 |
|---|---|---|---|
| 基底関数 | 歪みガウス2本 | **Gamma、または Gamma＋Gaussian** | Tigges・Fleischhauer・Huang |
| 次数 | 2 固定 | **3 を既定**。AICc または Wang 式の適応（規準を満たすまで増やす） | Tigges（M=3 が最良・M>3 は頭打ち） |
| 初期値 | 2次微分から Δμ | **汎用初期値を主とし、微分由来を副に持つ多点起動** | Fleischhauer（generic が最頑健） |
| 制約 | 境界のみ | **振幅と位置の不等式制約**（Couceiro 式） | Couceiro |
| 目的関数 | 一様重み最小二乗 | **鍵点に重みを置く WLS** | Wang |
| 採否の検算 | 境界・振幅・再現性 | **＋ NRMSE < 2%、Errx < 6 ms、Erry < 0.01** | Wang |
| 前処理 | 拍切り出し＋最小値差引 | **＋ 18 Hz 低域通過、極小点での切り出し、線形ベースライン除去** | Tigges・Wang |
| 検証 | 合成波＋PWDB | **＋ Dawber 4型（または Wang 5型）ごとの層別**、雑音・体動を加えた頑健性 | Tigges・Fleischhauer |

### 検証の設計（これが肝心）

「Charlton の DB に合わせる」ことに価値はない。**同じアルゴリズムが次の3つすべてで
規定の精度を満たすこと**を要件にする。

1. **理想波形**（PWDB 4,374名）— 鍵点が既知。Errx を直接測れる
2. **雑音・体動を加えた模擬波形** — Fleischhauer の方法。SNR を振って劣化を測る
3. **実信号**（VitalDB 862例）— Dawber 型で層別し、型ごとの同定率と再現性を測る

**波形型ごとに成績を出すこと**が重要である。Tigges の表を見ると、モデルの当てはまりは
Dawber 型で大きく変わる。ある型でだけ動くアルゴリズムは、術中の使用に耐えない。

### 併せて検討する別路線

Lee 2011 が示すように、**PPG から血管抵抗を読む文献の主力は RI ではなく幅・時間の特徴と
多変量分類**である。PDA の改良と並行して、`14_slope_features.py` の系統
（脈波幅、peak-to-notch time、notch time ratio、上昇・下降の傾き）を
同じ真値に対して評価する価値がある。PWDB の `pw_indices.csv` にはこれらに相当する列がある。

## 6. Basso 2024 ― 我々と同じ歪みガウス PDA が既に発表されていた

MIMIC-III から 8,000拍。歪みガウス PDA を提案し、Fleischhauer 2020 のガンマ・ガウス混合と比較。

### 我々と一致している点（独立に同じ設計に至っていた）

| 項目 | Basso 2024 | 我々 |
|---|---|---|
| 基底関数 | 歪み正規分布 `A/(ω√2π)·exp(−(t−ξ)²/2ω²)·(1+erf(α(t−ξ)/√2ω))` | 同一 |
| **母数化** | **(振幅 a, 最頻値 m, 標準偏差 σ, 歪み α) に付け替え、g(t=m)=a とする** | 同一（ピーク母数化） |
| 前処理 | 18 Hz 4次 Butterworth 低域通過（Tigges 準拠） | 同一 |
| ベースライン | 立ち上がり点から最終標本までの直線を差し引く | 同一 |
| 振幅正規化 | 基線 0・最大 1 | 同一 |
| 不等式制約 | `a₁ > aₖ`（第1成分の振幅が最大）、`mₖ₋₁ < mₖ`（最頻値が単調増加） | 同一（罰則で実装） |
| 初期値 | 汎用値（Fleischhauer の generic を歪みに拡張） | 同一（汎用を主） |

**独立に同じ設計に到達していたことは、設計の妥当性を裏づける。** ただし論文を先に読んでいれば
遠回りを避けられた。原稿では Basso 2024 を引用し、本研究が同モデルを踏襲した旨を明記すること。

### 我々と違う点（うち1つは我々の欠陥だった）

1. **歪み母数 α に境界を置かない**（[−∞, +∞]）。「α の範囲について事前知識がないから」と明記。
   α < 0 は左歪み、α = 0 で通常のガウスに戻る。
   **我々は α ≥ 0 に縛っていた。** これはまさに、下限 0 まで潰れてモデルが無感応になり
   共分散を壊した母数である（25番 T4）。**Basso に合わせて ±8 に広げた。**
2. **1拍を 28 標本に再標本化**（平均 42.45 Hz。Tigges の 40 Hz に合わせている）。
   我々は PWDB の 500 Hz のまま当てはめており、標本数が 15 倍。情報の薄い拡張期の裾が
   二乗和を支配する。**27番の感度解析に「40 Hz へ落とす」条件を追加した。**
3. 目的関数は**重みなしの残差平方和**。我々は Wang 2013 の鍵点重み付き。
4. 最適化は内点法（fmincon）で**関数評価回数の上限なし**。我々は信頼領域法で上限 1200。
5. 成分数 L = 2〜4 を並べて比較。適応的に増やす仕組みは持たない。

### 成績

| | L=2 | L=3 | L=4 |
|---|---|---|---|
| 歪みガウス RSS 中央値 | 0.0089 | **0.0017** | **0.0006** |
| ガンマ・ガウス RSS 中央値 | 0.0088 | 0.0021 | 0.0008 |
| 歪みガウス IQR | **0.0084** | **0.0029** | **0.0007** |
| ガンマ・ガウス IQR | 0.0118 | 0.0055 | 0.0019 |

L=3・L=4 で歪みガウスが有意に良い（p<0.001）。L=2 では中央値はほぼ同じだが**ばらつきが小さい**。
無作為初期値 50 組の検証で、歪みガウスのほうが**初期値に鈍感で頑健**。

**Tigges 2017 は「M=3 を超えると当てはまりの改善は頭打ち」としたが、Basso では L を増やすほど
改善が続く。** ただし Basso 自身「成分を増やせば当てはまりは任意に良くできるが、
生理学的に解釈できない分解になる」と釘を刺している。我々の 2→3 の上げ方はこの範囲に収まる。

## 7. Goswami 2010 ― 我々と同じ ΔT・RI。**分解由来と計測由来がずれる理由**

Rayleigh 関数2本（前進波＋遅延した反射波）で指尖脈波を合成する。健常・治療中高血圧の 113名。

指標の定義が我々と同じである。**ΔT_TPS = tp2 − tp1**、**RI_TPS = p2/p1**（成分ピークの間隔と高さ比）。

### 決定的に重要な所見

同論文は、**分解由来の指標が計測由来（ランドマーク）の指標と系統的にずれること**を
数式で説明している。計測波形の第2ピーク高さ h₂ は

```
h₂ = p_f(t₂) + p_r(t₂)
```

すなわち**前進波の裾を含む**。さらに反射波の広がりのため t₂ ≤ tp2。したがって

- **RI_PDA は RI_landmark より小さくなる**
- **ΔT_PDA は ΔT_landmark より大きくなる**

実測例:

| | RI_landmark | RI_PDA | ΔT_landmark | ΔT_PDA |
|---|---|---|---|---|
| 健常 30歳 男 | 0.78 | **0.49** | 142 ms | **228 ms** |
| 高血圧 55歳 女 | 0.68 | **0.58** | 194 ms | **231 ms** |

**これは我々の観測と符合する。** 合成波で第2版の ΔT は真値より +6〜8 ms 大きく、RI も過大だった。
そして PWDB で「ランドマーク法は規準を満たし PDA は満たさない」という結果を、
**「PDA が壊れている」とだけ読むのは誤り**である。両者は**別の量**であり、
その差は雑音ではなく構造的なものである。研究0 の解釈をこの線で書き直す必要がある。

### 新しい指標: 差分パルス幅 DPS

**DPS = σ_reflected − σ_forward**（成分の広がりの差）。

| | DPS |
|---|---|
| 健常 30歳 | **10 ms** |
| 高血圧 55歳 | **90 ms** |

Lee 2011（真の熱希釈 SVR 参照）と Awad 2007 も**脈波の幅**が反射係数より末梢血管抵抗を
よく弁別すると報告しており、幅という量は独立に支持されている。
**我々は既に成分の幅を当てはめているので、追加の計算費用ゼロで出せる。`indices()` に加えた。**

### 当てはめの手順が我々と違う点

- **段階的**に当てはめる。まず前進波を**立ち上がりだけ**に合わせ（0 < t ≤ tp1 で二乗誤差最小、
  高さ ≥ 0.5·h₁、tp1 ≤ t₁）、次に反射波を 0.3t₁ ≤ D ≤ 0.9T で全体の二乗誤差最小に合わせる。
  我々は同時に当てはめる
- **拍の終わりは合わせない。**「関心のある母数は 0〜0.9T に収まるので重要でない」と明記。
  我々は当初、貯留槽項を置いてここを合わせにいっていた（2026-09-05 の監査で機能していないことが
  分かり削除）。**27番に「0〜0.9T だけ当てはめる」条件を追加した**
- 3〜5拍を**時間平均**した1拍に当てはめる。我々は拍ごと

## 8. Epstein 2014 ― **第2ピークは末梢反射ではない。SI は大動脈 PWV の代替ではない**

Alastruey ら（PWDB を作った Charlton と同じ研究室）による、1次元75動脈モデルでの数値実験。
**PWDB の直接の前身にあたる研究**である。

### 何を振ったか

末梢抵抗（V1）・末梢コンプライアンス（V2）・**大動脈だけの硬さ**（V3）・**導管動脈全体の硬さ**（V4）。
さらに末梢反射を境界条件の置き換えで**完全に消す**実験を行っている。

### 所見1: SI を動かすのは導管動脈全体の硬さであって、大動脈ではない

| 因子を +200% | SI の変化 |
|---|---|
| **導管動脈全体の硬さ** | **+60% 超** |
| 末梢抵抗 | < 2% |
| 末梢コンプライアンス | < 2% |
| **大動脈だけの硬さ** | **PPT はむしろ延び、SI は微減** |

> 「したがって、硬さ指数は大動脈の硬さの変化によって決まる大動脈脈波伝播速度の
> 直接の指標ではない。」

立ち上がりの到達時刻も、導管全体を +200% 硬くすると 60 ms 早まるのに対し、
**大動脈だけなら 5 ms しか早まらない。**

**我々の事前規準は「ΔT × 大動脈PWV が負」である。Epstein に従えば、大動脈だけを硬くした場合
符号は逆になりうる。** PWDB でランドマーク ΔT が脈波伝播速度因子に対して −20.6% を示した事実は、
PWDB の PWV 因子が大動脈だけでなく導管全体を変えていることを示唆する（そうでなければ符号が合わない）。
いずれにせよ、**「ΔT は大動脈の硬さを測っている」とは書けない。** 測っているのは導管動脈全体の硬さである。

**対応**: 主要目標（大動脈PWV）は凍結したまま、**頸大腿PWV を事前指定の副次として 26番に追加した。**
理由は文献であって結果ではない（26番を PWDB に対して実行する前に追加している）。

### 所見2: 第2ピークは末梢反射ではない

すべての末梢反射を消しても、**2つのピークは到達時刻を変えずに残る**。

> 「この結果は、両方のピークが主として大動脈基部から伝播する波面と、
> 動脈分岐・先細り・大動脈基部でのその反射から成っていることを示唆する。」

ただし末梢反射は**第1ピークの到達を 52 ms 遅らせる**（上半身の末梢反射が主）。

**これは PDA の第2成分を「反射波」と呼ぶ根拠を弱める。** 測定量としての第2ピークは
導管の硬さとともに動くので指標としては使えるが、**「前進波と反射波に分ける」という
物語は 1次元モデルの上では成り立っていない。** 原稿の考察と `pda2.py` の用語に注記を入れる。

なお Charlton ら自身も P164（Artery Research 2018）で
「SI などの動脈硬化指数は in vivo では参照 PWV とよく相関するが、in silico では
**大動脈の硬さ以外の心血管特性にも影響される**ことが示された」と報告している
（要旨のみ確認。全文は未入手）。

## 11. Hellqvist 2024 ― **我々の ΔT を名指しで否定し、代わりを出している**

33名（年齢中央値 44、21〜66歳）、2週間以内に再測定。指尖の赤外 PPG・単誘導心電図・
指血圧（Finapres）を同時記録。参照は**頸大腿PWV（SphygmoCor 二点トノメトリ）**、
比較用に上腕カフ振動法の大動脈PWV（Arteriograph）。既知の特徴量 136 と新規 13 を作り、機械学習。

### 最良の特徴量: Am_b / Am_p1

| 指標 | 頸大腿PWV との r |
|---|---|
| **Am_b / Am_p1（本論文の新規）** | **−0.81** |
| ばね定数 | −0.72 |
| 加齢指数 (b−c−d−e)/a | 0.65 |
| **硬さ指数（既報3本）** | **0.65 / 0.58 / 0.66** |
| b/a | 0.54 |

予測誤差は頸大腿PWV で RMSE 0.70 m/s、大動脈PWV で 0.52 m/s。年齢も体格も血圧も使っていない。
再現性は参照機器と同等。

### 定義

- **p1**（収縮期ピークの新しい求め方）: 1次微分の最初の山 w の後、**下降の初期の直線部分に接線を
  引き、その零交点**を p1 とする。**「6つの波形型すべてで機能した」**。型1では収縮期ピーク S と
  一致することが多く、他の型では前収縮期切痕と一致することがある
- **Am_b**: 2次微分の b 波（最初の谷）の時刻における PPG 振幅
- **Am_p1**: p1 における PPG 振幅
- 伝播が速い（硬い）ほど比は小さくなる。「大動脈で早期収縮期の終わりに生じる抵抗を表しているのかもしれない」

### 我々への直撃

> 「大動脈硬化を推定するには、たとえば硬さ指数のように **S と D のピーク間の時間**に頼る指標や、
>  解釈できない加齢指数 (b−c−d−e)/a、全収縮期振幅に頼るばね定数ではなく、
>  **波形のこの特定の早期部分にもっと注目すべきである**。」

**我々の ΔT は「S と D のピーク間の時間」そのものである。** 本研究の中心指標が、
指尖 PPG から大動脈硬化を読む目的に対して、文献上より劣ると名指しされている。

**対応（26番の実行前）**:
- **Am_b/Am_p1 を第4の手法として 26番に追加した**（予測の向きは負。文献が明示している）
- **p1 を収縮期ピークに使った ΔT（dt_p1_ms）も追加した**。p1 は切痕の無い波形でも定義できるので、
  我々の未解決問題（型3〜4で ΔT 誤差 38〜55 ms）に効くかを見る
- 合成波で確認したところ、**p1 は切痕の無い波形でも収縮期ピークを 0.8 ms 以内で再現した**
  （p1 127.1 ms 対 真の 127.9 ms）。一方 **Am_b/Am_p1 は合成波ではほとんど動かない**
  （ΔT 340→180 ms で 0.9848→0.9828）。我々の合成波は前進波を固定しているので、
  **この指標は原理的に合成波では評価できない。PWDB でしか判定できない**

### もう一つ: 指尖では反射係数が低い

> 「指のような末梢の測定部位では、波動インピーダンスが特性インピーダンスに近い。
>  すなわち**反射係数が低い**。したがって信号は、それぞれの伝播経路と伝播速度で決まる
>  時間遅れをもって到達する『**入射波の連なり**』から成る。」

**Epstein 2014 と独立に同じことを言っている。** 指尖 PPG の第2ピークを「反射波」と呼ぶ根拠は、
これで2つの独立した文献から否定されたことになる。

## 12. Charlton P164 ― **単一指標で門を通そうとする我々の設計への警告**

Charlton・Aresu・Spear・Chowienczyk・Alastruey（2018）。**PWDB を作った本人たちの研究**である。

- in silico: Willemet 2015 の伝播モデルで 25〜75歳の仮想健常者。年代ごとに複数回の模擬
  （＝**PWDB そのもの**）。血圧波から PPG 波を生成
- **文献にある 30 以上の動脈硬化指数（ASI）**を指尖 PPG から算出する算法を設計
- in vivo: Airwave 研究の **6,506名**。3回反復の PPG と参照 PWV

### 結果

> 「in silico と in vivo における ASI の成績は**大きくばらついた**。硬さ指数は in vivo では
>  よい成績で、参照 PWV と強く相関した。**しかし in silico の評価では、硬さ指数も他の ASI も、
>  大動脈の硬さだけでなく他の心血管特性に影響されることが示された。**」

> 「将来は**複数の ASI を組み合わせる**べきである。ASI ごとに生理学的な決定要因が異なるからである。」

### 我々への意味

我々の研究0 の門は「**単一の指標**が、年齢層内の順位相関で全6層とも予測の向き、かつ中央値
|ρ| ≥ 0.3」である。Charlton 自身が、**in silico では単一 ASI がそもそも交絡すると報告している。**

- **PDA が門を通らなかったことは、PDA が特別に悪いことの証拠にはならない**（ただし
  同じ波形からのランドマーク ΔT は通っている 0.710 ので、門自体は通過可能である）
- **in vivo でよくても in silico で悪い**という乖離が、硬さ指数について既に報告されている。
  研究0（in silico）で不成立でも、研究1・2（in vivo）が無意味になるわけではない。
  **撤退の判断基準を、この乖離を織り込んだものに書き換える必要がある**
- 「複数の ASI を組み合わせよ」は、我々が ΔT・RI・DPS・Am_b/Am_p1 を並べる方向と一致する

## 13. Putcha 2026（PPG-Basis）― 実装上の参考

UNC-Chapel Hill。ガウス・ガンマ・**歪みガウス**の3カーネルを揃えた Python ツール箱。

### 採り入れられる点

- **目的関数に順位統計量を併用する。** 二乗誤差だけでは鋭い特徴が抽出できないので、
  Kendall の τ（ピークの順序が保たれているか）を重み付きで足す。
  「τ を使うと、鋭いピークが降順ではなく昇順で抽出される」
- **2次微分の NRMSE を使う。**「2次微分は信号の歪みを増幅するから」
  （Fleischhauer 2020 も同じ理由で2次微分の NRMSE を採用している）
- **2段階の最適化**: 差分進化（DE、population 15×母数、変異 0.8、交叉 0.7、許容 1e−6）で
  粗く全域探索 → SLSQP で局所精密化。さらに「全母数同時」と「基底ごとに巡回」の2方式
- 位相領域で解くことで一桁速い

### 我々との関係

- **我々の Errx（鍵点の時間位置誤差）は τ と同じ失敗様式を狙っている**（成分の順序・位置が
  正しいか）。しかも我々の指標に直結しているぶん τ より適している。採用は見送る
- **我々の多点初期値（5〜6点）は DE の貧者版である。** DE は遅いので今回は採らないが、
  当てはめが局所解に嵌っている疑いが出たら試す価値がある
- 歪みガウスが標準カーネルの一つとして実装されていることは、Basso 2024 と合わせて
  **我々の基底選択が定着しつつある選択であることを裏づける**

## 2. 方針を作り替える3つの事実

### (a) 関係は「無い」のではなく「方向は正しいが2桁小さい」

- 症例内回帰の ΔSI% 係数の**符号の揃い 78%**（862例の符号検定で p≪0.001）、
  向きは血管仮説の予測どおり（SI↑ → PWTT↓）
- しかし β = −0.027。**ΔSI% が10%動いて PWTT は0.27%しか動かない**。
  一方 PWTT 自体は症例内で数%動く
- → 指標を精緻化しても2桁は埋まらない。**入力としての桁が足りない**

### (b) ΔPWTT には説明すべき構造がある。届いていないのは我々の指標

| 説明変数 | ΔPWTT% の r²（切片あり） |
|---|---|
| 血管指標（ΔSI% + ΔRI%） | 0.044 |
| ΔMAP% | **0.139** |
| ΔHR% | 0.081 |
| 測定4変数すべて | 0.196 |
| 窓間自己相関 +0.746 から推定した再現性成分 | **0.56–0.75** |

→ 結論は「補正の余地がない」ではなく「**これらの指標が余地に届かない**」。

### (c) 支配しているのは心臓側である可能性が高い

- Sugo 2012（メーカー側の報告）: **PEP が PWTT 変化の約半分**を占める
- 本研究の原稿でも、残差の最有力候補として PEP を挙げているが、
  **測れていない**ことを限界として記述している
- → 次に測るべきは血管ではなく **PEP**

### 統合

> 術中の ΔPWTT は主に**心臓側（PEP・駆出動態）**が動かしており、血管側は
> 方向こそ正しいが桁が足りない。よって esCCO 改善の梃子は
> 「較正定数の血管補正」ではなく「**PWTT の PEP 成分の分離**」にある可能性が高い。

### 研究0（新設・最優先）— 真値既知の仮想集団で構成概念妥当性を示す

**なぜこれが最初か**: 測定に基づく研究の筋道は、(1) 指標が測りたい量を測れているか、
(2) その量が生理学的な標的と関連するか、(3) その情報で臨床推定が改善するか、の順である。
研究1は (2) を飛ばして (2) と (3) の中間の変則的な問い（指標は ΔPWTT を説明するか）を
問うた。そのため陰性の解釈が繰り返し曖昧になっている。**SI が脈波伝播速度と、RI が
末梢血管抵抗と関連することを先に示すべきであった。**

そしてそれは、無償で、倫理手続きなしで、真値に対して検証できる。

#### Charlton の Pulse Wave Database（PWDB）

| 項目 | 内容 |
|---|---|
| 規模 | 仮想被験者 **4,374名**（25〜75歳・10歳刻み） |
| 波形 | 圧・流速・内腔断面積・**光電容積脈波**。大動脈・頸動脈・上腕・橈骨・**指尖**・大腿 |
| 真値 | **大動脈脈波伝播速度**、**末梢血管抵抗（PVR, Pa·s/m³）**、総動脈コンプライアンス、1回拍出量 |
| 形式 | Matlab / **CSV** / WFDB |
| 入手 | **無償**。Zenodo doi:10.5281/zenodo.3275625 |
| 検証 | in vivo データと照合済み（Charlton 2019, Am J Physiol Heart Circ Physiol） |

原著は**従来のランドマーク法由来**の指標を大動脈PWVと対比している。
**PDA由来の SI・RI で行った報告はない。** ここが本研究の入口になる。

#### 何を問うか

1. PDA由来の SI は、真値の大動脈脈波伝播速度とどれだけ関連するか
2. PDA由来の RI は、真値の末梢血管抵抗とどれだけ関連するか
3. 2カーネルと3カーネルで、成分対の取り方により (1)(2) がどう変わるか
   （Couceiro の R1_2 と R1_d の対比を、真値に対して決着させる）
4. 総動脈コンプライアンス・1回拍出量との関連（Zc・C と心拍出量の理論的な鎖の検証）

#### なぜ決定的か ― 2×2 で切り分けられる

| | in silico で成立 | in silico で不成立 |
|---|---|---|
| **VitalDB で成立** | 概念も信号鎖も問題なし | 論理的にありえない。要再検討 |
| **VitalDB で不成立** | **信号鎖の問題** → 研究2 へ | **概念の限界** → 撤退 |

本研究は既に下段のどちらかにいる。in silico を行えばどちらかが確定する。
**撤退の判断も、研究2 の必要性の判断も、ここで決まる。**

#### コスト

ダウンロードのみ。倫理手続き不要。既存の `src/pda.py` をそのまま適用できる。
波形は理想信号なのでノイズ管理も不要。**数日で終わる。**

### 研究1c（最優先）— 指標の妥当性を急性血管トーヌスに対して示す

**なぜ最初に置くか**: 研究1の陽性対照は**年齢と高血圧既往**、すなわち慢性・構造的な
血管性状に対してのみ ΔT の妥当性を示した。しかし esCCO の動的補正が必要とするのは
**急性の血管トーヌス変化**であり、そこに対する妥当性は一度も検証していない。
ΔT が妥当なスティフネス指標でありながら急性トーヌスには盲目、という状態はありうる。
この穴が埋まらない限り、研究1の陰性も、今後のどの補正研究も、
**未検証の測定器の上に立つ**ことになる。

#### C-1（主解析）フェニレフリンを自然実験として使う

- α₁ 選択的で直接の変力作用がほぼない純粋昇圧薬。**外因性の介入なので循環論法がない**
- `Orchestra/PHEN_RATE` の**用量ステップ**の前後で SI・RI・ΔT の動きを見る。
  実データでは持続投与のまま細かく増減されることが多く（実測: ある症例で
  on/off 遷移5回に対し用量ステップ12回）、**二値の on/off を解析単位にすると
  材料を大きく取りこぼす**。SAP-1c は用量ステップを単位に定義すること
- 方向は事前に予測できる: 血管収縮 → 反射波の到達が早まる → **ΔT 短縮・RI 上昇**
- 事前指定: 効果の向き・最小効果量・ウォッシュイン時間・除外条件を凍結してから解析

#### C-2（副次）SVR との相関

- `EV1000/SVR` ・`EV1000/SVRI` と症例内で対応づける
- **限界を明示**: EV1000 の SVR は (MAP−CVP)/CO で、CO は動脈圧波形由来。
  よって**部分的に循環**しており、主解析にはしない

#### C-3 陰性対照

- レミフェンタニル・プロポフォールのレート変化（血管作用はあるが機序・向きが異なる）
- 昇圧薬非投与期間のランダムな時点

#### 使える症例数（`data/trks.csv` の実測。波形は未参照）

| 材料 | 症例数 | 抽出コスト |
|---|---|---|
| `EV1000/SVR` ・`SVRI` | **206例**（全例が現コホート内） | **再抽出不要**。数値トラックを取得して `t0` で結合するだけ |
| `Orchestra/PHEN_RATE` | 103例（うち38例は抽出済み） | 差分のみ追加抽出 |
| `Orchestra/NEPI_RATE` | 61例 | 同上 |
| 昇圧薬いずれか | **159例** | 8コアで数時間 |
| PLETH+ECG+ART が揃う母集団 | **3,458例** | — |

**重要**: 参照COを必要としないため、母集団が 874例 → **3,458例**に広がる。
CO トラックの要求は esCCO 研究の制約であって、指標の妥当性検証には不要である。

#### 限界（先に明記する）

- Orchestra は**輸液ポンプの記録**であり、麻酔科医が手押しした昇圧薬ボーラスは
  記録されない。したがって「非投与期間」に未記録の血管収縮が混入する。
  これは**帰無仮説の側にバイアスする**（＝陽性が出れば信頼できる）
- 昇圧薬投与時は血圧・心拍も同時に動くため、MAP・HR で調整した解析を併記する

#### 分岐

| 結果 | 意味 | 帰結 |
|---|---|---|
| 指標が昇圧薬に反応する | **指標は妥当。PWTT が血管性でないだけ** | 研究1の主張が格段に鋭くなる。指標自体が「術中の非侵襲血管トーヌス指標」として独立の価値を持つ |
| 反応しない | **PPG-PDA 指標は急性トーヌスに盲目** | PPG-PDA 路線を根拠をもって完全に終了できる。撤退も成果 |

#### 研究1への即時の還元

C-2（SVR 206例）は**再抽出が不要**なので、研究1の投稿前に間に合う。
研究1の陽性対照に「急性血管トーヌス」の次元を追加できる
（**SAP凍結後の探索的解析**として明記する。2026-08-29 の陽性対照追加と同じ扱い）。
これは現時点で研究1の最大の査読脆弱性（「指標が主張どおりのものを測っている証拠が
間接的」）を直接ふさぐ。

### 研究1b（研究1c の後・追加コストほぼゼロ）

`03_run_analysis.py` は既に `SNUADC/ART` を 500 Hz で取得している。
**追加ダウンロードは不要**、再抽出1回（変種抽出と同規模）で足りる。

#### B-1: PWTT の3分割 — PEP を含まない区間を作る

```
T1 = R波 → 橈骨動脈圧の立ち上がり      = PEP + 中枢動脈伝播
T2 = R波 → PPG立ち上がり − 660 ms      = PEP + 中枢 + 末梢動脈伝播
T2 − T1                                = 橈骨→指尖の純粋な動脈伝播時間
                                         （PEP を一切含まない）
```

- 装置遅延 660 ms は定数なので**症例内Δで相殺される**（T1・T2 いずれも）
- 問い: 症例内の ΔT2（＝ΔPWTT）のうち、Δ(T2 − T1) が説明するのは何%か
- 予測: ごく一部 → 「**ΔPWTT は PEP + 中枢が支配**」を直接示す
- **参照COを一切使わない**ので、非独立性の問題が原理的に生じない

**リスクと可測性ゲート（着手前に必ず通す）**

橈骨→指尖は短区間（伝播 30〜50 ms 程度）で、PPG 側の立ち上がり検出ジッタに
埋もれうる。また 660 ms 遅延の**症例内**安定性は未確認（症例間 IQR 644–676 は
確認済みだが、症例内で漂う可能性は排除していない）。よって10例で先に確認する:

- Δ(T2 − T1) の窓間自己相関 ≥ 0.3
- Δ(T2 − T1) の症例内変動係数 ≤ 0.5
- 症例内での T2 − T1 の系統的ドリフトがないこと（遅延の症例内安定性の代理）

いずれか不通過なら **B-1 は中止**し、B-2 のみ実施する。

#### B-2: 動脈圧波形由来の血管指標で前提を再検証

- 指標: **dP/dt_max と 拡張期下降時定数 τ=RC**（`15_art_indices.py`・合成データ検証済み）
- **AIx／動脈圧PDA は保留**: 凍結済みの2カーネルPDAを動脈圧波形に当てると σ が
  上限に張り付き、収束検算で全滅する（貯留槽成分をカーネルが吸収するため）。
  両端を通す指数を引く簡易な excess pressure 分離では足りない。
  駆出中に立ち上がる貯留槽成分まで含めた分離を設計・検証してから行う
- 動脈圧波形は AGC・帯域制限を受けないため、PPG の RI が壊れた原因
  （機構実験: 拍内ゲイン τ≈0.25 s で RI +61%・ΔT は −9 ms のみ）から自由
- 参照COを使わない前提検証なので**非独立性の問題が一切ない**

| 結果 | 意味 | 帰結 |
|---|---|---|
| 動脈圧指標でも説明できない | **概念の限界** | 研究1の主張が PPG を超えて一般化。格段に強い論文になる |
| 動脈圧指標なら説明できる | **PPG の測定限界** | 研究2 の設計根拠が立つ |

#### B-3: 研究1が閉じていない2経路（記述のみ・検定しない）

- **ゲイン補正経路**: PWTT の水準ではなく PWTT→SV の傾きに作用する経路
- **ベースライン K の個別化**: 症例間。ΔT は年齢と ρ=−0.197（p<0.0001）で
  有意に相関しており、症例間の血管情報は持っている。研究1は全解析が症例内

いずれも参照COが FloTrac 系である限り検定できない。**仮説生成に留め、
§7.6 の規準（精度エンドポイントを結論に使わない）を維持する。**

**成果物**: 研究1の姉妹論文、または研究1の Discussion 拡充。B-1/B-2 の結果を見て判断。

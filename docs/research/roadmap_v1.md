## 2. 方針を作り替える3つの事実

### (a) 関係は「無い」のではなく「方向は正しいが2桁小さい」

- 症例内回帰の ΔSI% 係数の**符号の揃い 78%**（862例の符号検定で p≪0.001）、
  向きは血管仮説の予測どおり（SI↑ → PWTT↓）
- しかし β = −0.027。**ΔSI% が10%動いて PWTT は0.27%しか動かない**。
  一方 PWTT 自体は症例内で数%動く
- → 指標を精緻化しても2桁は埋まらない。**入力としての桁が足りない**

### (b) ΔPWTT には説明すべき構造がある。届いていないのは我々の指標

| 説明変数 | ΔPWTT% の r²（切片あり） |
|---|---|
| 血管指標（ΔSI% + ΔRI%） | 0.044 |
| ΔMAP% | **0.139** |
| ΔHR% | 0.081 |
| 測定4変数すべて | 0.196 |
| 窓間自己相関 +0.746 から推定した再現性成分 | **0.56–0.75** |

→ 結論は「補正の余地がない」ではなく「**これらの指標が余地に届かない**」。

### (c) 支配しているのは心臓側である可能性が高い

- Sugo 2012（メーカー側の報告）: **PEP が PWTT 変化の約半分**を占める
- 本研究の原稿でも、残差の最有力候補として PEP を挙げているが、
  **測れていない**ことを限界として記述している
- → 次に測るべきは血管ではなく **PEP**

### 統合

> 術中の ΔPWTT は主に**心臓側（PEP・駆出動態）**が動かしており、血管側は
> 方向こそ正しいが桁が足りない。よって esCCO 改善の梃子は
> 「較正定数の血管補正」ではなく「**PWTT の PEP 成分の分離**」にある可能性が高い。

### 研究0（新設・最優先）— 真値既知の仮想集団で構成概念妥当性を示す

**なぜこれが最初か**: 測定に基づく研究の筋道は、(1) 指標が測りたい量を測れているか、
(2) その量が生理学的な標的と関連するか、(3) その情報で臨床推定が改善するか、の順である。
研究1は (2) を飛ばして (2) と (3) の中間の変則的な問い（指標は ΔPWTT を説明するか）を
問うた。そのため陰性の解釈が繰り返し曖昧になっている。**SI が脈波伝播速度と、RI が
末梢血管抵抗と関連することを先に示すべきであった。**

そしてそれは、無償で、倫理手続きなしで、真値に対して検証できる。

#### Charlton の Pulse Wave Database（PWDB）

| 項目 | 内容 |
|---|---|
| 規模 | 仮想被験者 **4,374名**（25〜75歳・10歳刻み） |
| 波形 | 圧・流速・内腔断面積・**光電容積脈波**。大動脈・頸動脈・上腕・橈骨・**指尖**・大腿 |
| 真値 | **大動脈脈波伝播速度**、**末梢血管抵抗（PVR, Pa·s/m³）**、総動脈コンプライアンス、1回拍出量 |
| 形式 | Matlab / **CSV** / WFDB |
| 入手 | **無償**。Zenodo doi:10.5281/zenodo.3275625 |
| 検証 | in vivo データと照合済み（Charlton 2019, Am J Physiol Heart Circ Physiol） |

原著は**従来のランドマーク法由来**の指標を大動脈PWVと対比している。
**PDA由来の SI・RI で行った報告はない。** ここが本研究の入口になる。

#### 何を問うか

1. PDA由来の SI は、真値の大動脈脈波伝播速度とどれだけ関連するか
2. PDA由来の RI は、真値の末梢血管抵抗とどれだけ関連するか
3. 2カーネルと3カーネルで、成分対の取り方により (1)(2) がどう変わるか
   （Couceiro の R1_2 と R1_d の対比を、真値に対して決着させる）
4. 総動脈コンプライアンス・1回拍出量との関連（Zc・C と心拍出量の理論的な鎖の検証）

#### なぜ決定的か ― 2×2 で切り分けられる

| | in silico で成立 | in silico で不成立 |
|---|---|---|
| **VitalDB で成立** | 概念も信号鎖も問題なし | 論理的にありえない。要再検討 |
| **VitalDB で不成立** | **信号鎖の問題** → 研究2 へ | **概念の限界** → 撤退 |

本研究は既に下段のどちらかにいる。in silico を行えばどちらかが確定する。
**撤退の判断も、研究2 の必要性の判断も、ここで決まる。**

#### コスト

ダウンロードのみ。倫理手続き不要。既存の `src/pda.py` をそのまま適用できる。
波形は理想信号なのでノイズ管理も不要。**数日で終わる。**

### 研究1c（最優先）— 指標の妥当性を急性血管トーヌスに対して示す

**なぜ最初に置くか**: 研究1の陽性対照は**年齢と高血圧既往**、すなわち慢性・構造的な
血管性状に対してのみ ΔT の妥当性を示した。しかし esCCO の動的補正が必要とするのは
**急性の血管トーヌス変化**であり、そこに対する妥当性は一度も検証していない。
ΔT が妥当なスティフネス指標でありながら急性トーヌスには盲目、という状態はありうる。
この穴が埋まらない限り、研究1の陰性も、今後のどの補正研究も、
**未検証の測定器の上に立つ**ことになる。

#### C-1（主解析）フェニレフリンを自然実験として使う

- α₁ 選択的で直接の変力作用がほぼない純粋昇圧薬。**外因性の介入なので循環論法がない**
- `Orchestra/PHEN_RATE` の**用量ステップ**の前後で SI・RI・ΔT の動きを見る。
  実データでは持続投与のまま細かく増減されることが多く（実測: ある症例で
  on/off 遷移5回に対し用量ステップ12回）、**二値の on/off を解析単位にすると
  材料を大きく取りこぼす**。SAP-1c は用量ステップを単位に定義すること
- 方向は事前に予測できる: 血管収縮 → 反射波の到達が早まる → **ΔT 短縮・RI 上昇**
- 事前指定: 効果の向き・最小効果量・ウォッシュイン時間・除外条件を凍結してから解析

#### C-2（副次）SVR との相関

- `EV1000/SVR` ・`EV1000/SVRI` と症例内で対応づける
- **限界を明示**: EV1000 の SVR は (MAP−CVP)/CO で、CO は動脈圧波形由来。
  よって**部分的に循環**しており、主解析にはしない

#### C-3 陰性対照

- レミフェンタニル・プロポフォールのレート変化（血管作用はあるが機序・向きが異なる）
- 昇圧薬非投与期間のランダムな時点

#### 使える症例数（`data/trks.csv` の実測。波形は未参照）

| 材料 | 症例数 | 抽出コスト |
|---|---|---|
| `EV1000/SVR` ・`SVRI` | **206例**（全例が現コホート内） | **再抽出不要**。数値トラックを取得して `t0` で結合するだけ |
| `Orchestra/PHEN_RATE` | 103例（うち38例は抽出済み） | 差分のみ追加抽出 |
| `Orchestra/NEPI_RATE` | 61例 | 同上 |
| 昇圧薬いずれか | **159例** | 8コアで数時間 |
| PLETH+ECG+ART が揃う母集団 | **3,458例** | — |

**重要**: 参照COを必要としないため、母集団が 874例 → **3,458例**に広がる。
CO トラックの要求は esCCO 研究の制約であって、指標の妥当性検証には不要である。

#### 限界（先に明記する）

- Orchestra は**輸液ポンプの記録**であり、麻酔科医が手押しした昇圧薬ボーラスは
  記録されない。したがって「非投与期間」に未記録の血管収縮が混入する。
  これは**帰無仮説の側にバイアスする**（＝陽性が出れば信頼できる）
- 昇圧薬投与時は血圧・心拍も同時に動くため、MAP・HR で調整した解析を併記する

#### 分岐

| 結果 | 意味 | 帰結 |
|---|---|---|
| 指標が昇圧薬に反応する | **指標は妥当。PWTT が血管性でないだけ** | 研究1の主張が格段に鋭くなる。指標自体が「術中の非侵襲血管トーヌス指標」として独立の価値を持つ |
| 反応しない | **PPG-PDA 指標は急性トーヌスに盲目** | PPG-PDA 路線を根拠をもって完全に終了できる。撤退も成果 |

#### 研究1への即時の還元

C-2（SVR 206例）は**再抽出が不要**なので、研究1の投稿前に間に合う。
研究1の陽性対照に「急性血管トーヌス」の次元を追加できる
（**SAP凍結後の探索的解析**として明記する。2026-08-29 の陽性対照追加と同じ扱い）。
これは現時点で研究1の最大の査読脆弱性（「指標が主張どおりのものを測っている証拠が
間接的」）を直接ふさぐ。

### 研究1b（研究1c の後・追加コストほぼゼロ）

`03_run_analysis.py` は既に `SNUADC/ART` を 500 Hz で取得している。
**追加ダウンロードは不要**、再抽出1回（変種抽出と同規模）で足りる。

#### B-1: PWTT の3分割 — PEP を含まない区間を作る

```
T1 = R波 → 橈骨動脈圧の立ち上がり      = PEP + 中枢動脈伝播
T2 = R波 → PPG立ち上がり − 660 ms      = PEP + 中枢 + 末梢動脈伝播
T2 − T1                                = 橈骨→指尖の純粋な動脈伝播時間
                                         （PEP を一切含まない）
```

- 装置遅延 660 ms は定数なので**症例内Δで相殺される**（T1・T2 いずれも）
- 問い: 症例内の ΔT2（＝ΔPWTT）のうち、Δ(T2 − T1) が説明するのは何%か
- 予測: ごく一部 → 「**ΔPWTT は PEP + 中枢が支配**」を直接示す
- **参照COを一切使わない**ので、非独立性の問題が原理的に生じない

**リスクと可測性ゲート（着手前に必ず通す）**

橈骨→指尖は短区間（伝播 30〜50 ms 程度）で、PPG 側の立ち上がり検出ジッタに
埋もれうる。また 660 ms 遅延の**症例内**安定性は未確認（症例間 IQR 644–676 は
確認済みだが、症例内で漂う可能性は排除していない）。よって10例で先に確認する:

- Δ(T2 − T1) の窓間自己相関 ≥ 0.3
- Δ(T2 − T1) の症例内変動係数 ≤ 0.5
- 症例内での T2 − T1 の系統的ドリフトがないこと（遅延の症例内安定性の代理）

いずれか不通過なら **B-1 は中止**し、B-2 のみ実施する。

#### B-2: 動脈圧波形由来の血管指標で前提を再検証

- 指標: **dP/dt_max と 拡張期下降時定数 τ=RC**（`15_art_indices.py`・合成データ検証済み）
- **AIx／動脈圧PDA は保留**: 凍結済みの2カーネルPDAを動脈圧波形に当てると σ が
  上限に張り付き、収束検算で全滅する（貯留槽成分をカーネルが吸収するため）。
  両端を通す指数を引く簡易な excess pressure 分離では足りない。
  駆出中に立ち上がる貯留槽成分まで含めた分離を設計・検証してから行う
- 動脈圧波形は AGC・帯域制限を受けないため、PPG の RI が壊れた原因
  （機構実験: 拍内ゲイン τ≈0.25 s で RI +61%・ΔT は −9 ms のみ）から自由
- 参照COを使わない前提検証なので**非独立性の問題が一切ない**

| 結果 | 意味 | 帰結 |
|---|---|---|
| 動脈圧指標でも説明できない | **概念の限界** | 研究1の主張が PPG を超えて一般化。格段に強い論文になる |
| 動脈圧指標なら説明できる | **PPG の測定限界** | 研究2 の設計根拠が立つ |

#### B-3: 研究1が閉じていない2経路（記述のみ・検定しない）

- **ゲイン補正経路**: PWTT の水準ではなく PWTT→SV の傾きに作用する経路
- **ベースライン K の個別化**: 症例間。ΔT は年齢と ρ=−0.197（p<0.0001）で
  有意に相関しており、症例間の血管情報は持っている。研究1は全解析が症例内

いずれも参照COが FloTrac 系である限り検定できない。**仮説生成に留め、
§7.6 の規準（精度エンドポイントを結論に使わない）を維持する。**

**成果物**: 研究1の姉妹論文、または研究1の Discussion 拡充。B-1/B-2 の結果を見て判断。

**RI × 末梢血管抵抗は Couceiro 2015 の R1_d（0.585）だけがランドマーク（0.501）に届く。**規則どおりこの表では採らず、
試すなら RI に限った新しい事前登録の下で第3版とする。ただし RI×pvr は貯留槽の振幅を通じた内蔵の関係を含み、実機側は
研究1 の RI 不成立と 32番の型4 35% で道が狭いので、判断は研究2 で生波形の拡張期が取れると分かってからにする。

### 実機で我々と文献の分解を並べた結果（2026-09-06 追記・34番・探索。lab_log 追記19〜20）

VitalDB のモニタ波形 20 例・360 窓で、第2版・凍結版・文献 6 本の分解と、ランドマーク ΔT・Am_b/Am_p1・PWTT を同じ平均拍に当てた。
Mac と雲で同じ規則で回したところ表が一致せず（lab_log 追記21。vitaldb の版による波形の違いが候補）、**両機で変わらない所見だけを残す**:
分解由来の ΔT は常に値が出る（同定率 ≈ 1.00 対 ランドマーク 0.61）。拡張期の錨が無い型4 の窓（39%）でも隣の窓と再現する
（第2版 歪みガウス 0.58／0.41、Basso L=2 0.40／0.72）。分解の利点「切痕が無くても値が出る」は実機で本当に出る。
**しかし年齢の向きを持たない**（分解由来は −0.09〜+0.28。計測由来の Am_b/Am_p1 は −0.37／−0.36、PWTT は −0.36／−0.41）。
PWDB で分解由来の ΔT が真値を追わなかったことと合わせ、実機で再現しているのは血管の量ではない可能性が高い。
再現性は妥当性を含意しないので、分解を主指標に戻す事前登録は立てない。「分解が計測を再現性で上回るか」（問い 1）は機械で割れたので答えを保留する。
Am_b/Am_p1（同定率 1.00・自己相関 0.45 が両機で一致・年齢 −0.37）が計測由来で最も良く、研究2 の主指標候補は変えない。

### 書かないこと（`gate0_rules_v2.md` のまま）

「ΔT は大動脈の硬さを測る」「第2成分は反射波である」「PDA は壊れている」「in silico で不成立だから in vivo でも無意味」
「in silico で成立したから実機でも使える」。ΔT_PDA の絶対値を他研究と比べない。

## 10. 2026-09-07 追記 ― 研究1b の確定、機構の考察、方針の整理

§9 までで判定は出そろっている。ここは**判定を動かさず**、その後に確定した事実と、
それに伴う方針の整理を記録する。

### 10.1 研究1b は完了した ― 前駆出期による打ち消し説は否定された

2026-08-30 の教授報告では「今回の陰性は前駆出期（PEP）と動脈伝播時間が逆向きに動いて
互いを打ち消した見かけのものではないか」を最優先の問いとしていた。**答えは否である。**

| 被説明変数 | 説明変数 | r² | 症例内順位相関の中央値 |
|---|---|---|---|
| Δ(T2−T1)%（橈骨→指尖。前駆出期を含まない） | ΔT%（分解由来の血管指標） | **0.008** | +0.122 |
| ΔPWTT%（比較） | ΔT% | −0.053 | +0.216 |

**前者は後者より大きくない。むしろ小さい。**前駆出期を完全に除いた純粋な末梢動脈区間でも、
血管指標は説明しない。研究1 の陰性は前駆出期による見かけのものではなかった。

分散の在りかは Δ(T2−T1)% に 0.534、ΔT1% に 0.073 だが、**これは恒等式
T2 = T1 + (T2−T1) の分散分解であって「説明」ではない**。さらに PPG 側の立ち上がり検出の
ジッタはすべて (T2−T1) の項に入るので、末梢区間の分散には生理と測定雑音の両方が含まれる。
この留保を付けずに引用しない（`terminology.md` の r² の決まり）。

動脈圧波形由来の指標（拡張期の時定数 τ・dP/dt_max）でも r² = 0.015（Gate 3）。
PPG の測定限界ではなく、その手前の問題である。

### 10.2 2026-08-30 の報告で立てた「並列入力」案の現状

当時は「較正定数を血管指標で補正するのではなく、血管指標を PWTT と**並列の入力変数**として
加えるべきである」と書いた。**この案は現時点では支持されていない。**理由は 2 つ。

1. 10.1 のとおり、ΔPWTT% の分散が偏っている末梢区間そのものを、血管指標が説明しない。
2. 研究0 のとおり、当時使っていた分解由来の指標は**血管の量を測れていなかった**。
   並列に入れる前に、指標の構成概念妥当性が要る。

並列入力そのものを否定はしない。ただし**指標を替えてから**でなければ検証できない。
その第一歩が §5 の 2（早期振幅比による前提検証・探索的）である。

### 10.3 分解法が理想波形で真値と関連しなかった理由（考察）

`why_pda_failed_in_silico.md` に独立の文書として書いた。**判定はこの §9 が正本で、
あの文書は考察である。**要点だけ:

- シミュレーションの側の問題ではない（陽性対照 0.571、**同じ波形を測り方だけ変えると
  0.167 → 0.710 → 0.836**、因子ごとの主効果、型の分布の 4 検査）。
- 文献の成績と矛盾しない。文献が評価していたのは当てはまりの良さ・雑音への頑健性・
  常に値が返ることの 3 点で、**この 3 点は 34番で我々も再現している**。
  落ちたのは「年齢層内で真値と順位が一致するか」という、どの論文もそのままの形では
  評価していない項目である。
- 機構は 6 つ。最も強いのは同定不能（境界張り付き 87〜97%・当てはまりと相関が逆に動く・
  基底で ΔT が 264〜640 ms に動く）と、**応答が単調でない**（脈波伝播速度の行だけ
  ΔT が 332 → 353 → 251、RI が U 字。主効果は 6 因子中 最大なのに層内 ρ は −0.26／−0.17）。

### 10.4 「使えない」の書き方（原稿の表現を固定する）

分解由来の ΔT について、次の 3 点以上のことは書かない。

1. **感度はあるが特異性がない。**脈波伝播速度の主効果は 6 因子中 最大（−17.0%）で 6/6 層が
   予測の向き。何も測っていないのではない。ただし順位では心拍数（ρ −0.54）のほうが強い。
2. **できないのは「同じ年齢の 2 人を硬さで順序づける」ことである。**これは esCCO の較正定数の
   補正が必要とすることそのものである（較正定数には既に年齢と体格が入っている）。
3. **実機ではさらに悪い。**年齢との相関すら予測の向きにならない（−0.09〜+0.28）。

## 11. 2026-09-07 追記2 ― プログラムの終わりどころを事前規準に照らして判定する

§10 までを教授報告としてまとめる過程で、研究1c・研究2・研究3 の見通しを正面から問い直した。
**判定は §9 のまま動かさない。**ここで決めるのは「次に何をするか」だけである。

### 11.1 研究3 は設計しない ― 中止基準に該当する

§4 の中止基準に「研究1b で候補1〜3 のいずれも見込みが立たない → プログラムを研究1（＋1b）の
2報で完結させる」と事前に書いてある。**これに該当する。**

- 候補1 **PEP 補正** ― 研究1b で弱まった（ΔT1% の寄与 7.3%。Sugo 2012 の「約半分」と整合しない）。
- 候補2 **ゲイン補正**、候補3 **ベースライン較正定数の個別化** ― どちらも参照 CO の独立性を要する。
  SAP §1.2 の制約（98% が動脈圧波形由来）は解けていない。
- **決定的な数値**: PWDB の橈骨→指尖の真の伝播時間は中央値 **8 ms（5–95% で 4–16 ms）**、
  6 因子を ±1 SD 振っても幅は 12 ms。一方 VitalDB の Δ(T2−T1) の症例内 SD は **≈18 ms** で、
  この幅を超える（lab_log 追記12 の 6）。**術中の PWTT 変動のうち末梢区間に見えている分は、
  末梢動脈の生理では説明できない。**PPG の立ち上がり検出のばらつきか装置遅延の揺らぎである。

したがって esCCO の精度に残る余地は、血管でも前駆出期でもなく**検出の安定化**にある。
それは前向き多施設試験の一次仮説ではない。**研究3 は設計しない。**

### 11.2 研究1c ― 目的と主指標が食い違っている

「急性の血管トーヌス変化を捉えるか」を問うなら、どの指標を主に据えるべきかを整理した。

| | 概念妥当性（研究0） | 実機での同定性（32番） |
|---|---|---|
| RI（特徴点由来） | **末梢血管抵抗と 0.504（6/6）で成立** | 拡張期ピークが要る。平均拍の 34% が型4 で**測れない** |
| 早期振幅比 Am_b/Am_p1 | 大動脈PWV と 0.836。**末梢血管抵抗との関連は未検証** | 同定率 0.95 で**測れる** |

**概念が合う指標は測れず、測れる指標は概念が合わない。**現時点で C-1 の主指標に据えられる
血管トーヌス指標は無い。さらに現行の SAP-1c の主指標は T2−T1（主）・T1（副次1）であって
RI でも早期振幅比でもないので、**「血管トーヌスの検証」という目的と主指標が食い違っている。**
凍結の前に整理する。

**安価に決着する検討を 1 件立てる（下記 11.4 の (i)）。**

### 11.3 研究2 ― 目的を切り替えない限り理由が立たない

「真値と関連しない指標を測っても意味がない」という指摘は**分解由来の指標については正しい**が、
研究2 の対象は分解ではない（早期振幅比 0.836・特徴点 ΔT 0.710 で真値と関連する）。
ただし研究2 が答えられるのは 2 点だけである。

1. 型4 が 34% を占めるのは信号鎖か麻酔下の生理か
2. 早期振幅比のウィンドウ間の再現性（0.36）が上がるか

**そして 1・2 が両方うまくいっても esCCO の改善にはつながらない**（11.1）。
研究2 が意味を持つのは「PPG 形態指標を非侵襲の血管モニタとして使う」という**別の目的**に対してだけである。
**この切り替えを明示しない限り、研究2 は行わない。**

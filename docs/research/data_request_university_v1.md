# 大学の実データ取得依頼 ― 必要なデータの一覧（第1.0版）

**作成**: 2026-09-08　**作成者**: 川副靖晃（長崎県五島中央病院麻酔科）
**位置づけ**: 業者に渡す取得仕様。**2026-09-08 に第2.0版（`data_request_university_v2.md`）へ差し替えた。**
本版は公開データベースで残った論点に絞った限定版であり、当初の2つの問いを一から検証する
パイロット研究には第2.0版を用いる。以下は記録として残す。

研究1（VitalDB 862例）と研究0（PWDB 4,374名）で
残った問いのうち、**実測データでしか答えられないもの**だけを対象とする。

## 0. なぜこの項目なのか（依頼の設計方針）

公開データベースでの解析は完了しており、次の3点が未解決のまま残った。この一覧は
その3点に対応させて作ってあり、それ以外は入れていない。

| 残った問い | 公開データで詰んだ理由 | 実データで必要になるもの |
|---|---|---|
| **①** 反射係数（振幅比）は本当に血管を測れないのか、モニタの利得制御で潰れているだけか | 光電容積脈波チャネルが表示用で、フィルタ仕様も自動利得制御の有無も非公開だった。振幅由来の指標は加齢との陽性対照を通らなかった（ρ＝+0.041） | **生波形と信号処理の仕様の開示**（→ A・B） |
| **②** 特徴点法の指標は実機の波形でも同定でき、真の脈波伝播速度を追うか | 仮想集団では追った（0.71）が、モニタ処理を経た波形で残存するかは未検証。真の脈波伝播速度は実測データに存在しない | **測定した脈波伝播速度**（→ D） |
| **③** 術中の脈波伝播時間の変動の大半を占める末梢区間は、生理か測定誤差か | 橈骨→指尖の真の伝播時間は8 ms（4〜16）しかないのに、症例内の標準偏差は約18 msあった。装着部位・同側対側の情報が無く切り分けられない | **装着部位と動脈ライン留置部位、チャネル間同期**（→ B・G） |

加えて、公開データベース最大の弱点であった参照心拍出量の独立性（解析862例中846例が
動脈圧波形由来で、血圧と連動するため独立でない）を、実データでは肺動脈カテーテルで
解消できる（→ C）。

**この依頼で答えないこと**: 「成分波分解の指標で較正定数を補正すれば心拍出量推定が
改善するか」。これは既に否定されており（前提の説明割合0.000、早期振幅比でやり直しても
0.0002）、雑音ゼロの仮想集団でも成立しなかった以上、実データで回復する筋はない。
実データの価値は、①②③と参照の独立性にある。

## A. 波形データ（必須。これが無ければ研究が成立しない）

チャネル名は機種依存のため、求める信号の中身で記す。

| # | 信号 | 標本化周波数 | 必須度 | 用途 |
|---|---|---|---|---|
| A-1 | 心電図（II誘導またはR波が最も明瞭な誘導） | 500 Hz以上、可能なら1,000 Hz | **必須** | 脈波伝播時間の起点。R波検出 |
| A-2 | 光電容積脈波（SpO₂プローブ）。**表示用ではなく生波形を最優先** | 500 Hz以上 | **必須** | 本研究の対象そのもの |
| A-3 | 観血的動脈圧（橈骨動脈） | 500 Hz以上 | **必須** | 脈波伝播時間を中枢区間と末梢区間に分割する。研究1で最も情報量が多かった解析 |
| A-4 | 光電容積脈波の直流成分（可能なら赤色光・赤外光それぞれの生強度） | 500 Hz以上 | 強く推奨 | 灌流指数の算出。振幅の正規化に依存しない解析ができる |
| A-5 | カプノグラム、気道内圧 | 100 Hz以上 | あれば | 呼吸性変動の除去。人工呼吸の設定変更点の同定 |

**共通の要件**

- **無圧縮・無間引き**。表示のためのダウンサンプル、スパイク除去、欠測の前値保持を
  していないこと。加工している場合は加工の内容を明記すること。
- **欠測はNaNまたは欠測フラグで残す**。ゼロ埋めや前値保持をしない。
- **全チャネルが同一の時間軸**にあること。ずれている場合は D-0（下記B-4）を必ず開示すること。
- 記録は麻酔導入前から抜管まで**連続**。区間を切り出したものは不可。

## B. 信号処理の仕様（データではないが、無いと①③が解析できない）

**この節が本依頼で最も重要である。**研究1では光電容積脈波の処理仕様が非公開であったため、
振幅由来の指標について「血管を測れていない」のか「モニタが振幅情報を落としている」のかを
最後まで区別できなかった。波形だけ受け取っても同じことが起きる。

| # | 開示を求める項目 | なぜ必要か |
|---|---|---|
| B-1 | 光電容積脈波チャネルは**表示用か、生波形か** | 表示用なら振幅由来の指標の解釈が原理的に制限される |
| B-2 | **フィルタの種類・次数・遮断周波数**（高域・低域とも） | 帯域制限は特徴点の位置を年齢依存的に動かす |
| B-3 | **自動利得制御の有無。あれば時定数と正規化の単位**（拍ごと／固定時間窓／記録全体） | 拍の内部で変化する利得のみが、観測された振幅比の偏りを再現した（合成波で+61%）。ここが分かれば①に決着がつく |
| B-4 | **心電図と光電容積脈波の相対遅延**。値、固定か可変か、機種・モジュール依存か | 研究1では660 msの固定遅延があった。未補正だと通過時間が心周期を法として折り返す |
| B-5 | 各チャネルの**実効標本化周波数**（内部で間引いていないか） | 見かけの周波数と実効値が違う機種がある |
| B-6 | 欠測・アーチファクト区間の扱い（NaNか、前値保持か、内挿か） | 内挿された区間を実測として解析すると偽の相関が出る |
| B-7 | **モニタの機種名とソフトウェア版数**、SpO₂モジュールの型番 | 上記すべてが機種依存であるため |
| B-8 | esCCO を出力している場合、その**更新周期と平滑化の窓** | 実機と我々の再現式を比較するのに必要 |

**利得固定または自動利得制御を切った記録が可能かを、必ず確認すること。**
1例でも取れれば、同一患者で通常記録と比較して B-3 の影響を直接測れる。

## C. 参照心拍出量（独立した標準。公開データベースの最大の弱点）

| # | 項目 | 必須度 | 備考 |
|---|---|---|---|
| C-1 | **肺動脈カテーテルによる熱希釈心拍出量（間欠法）** | 強く推奨 | 実施時刻と値のペア。1症例あたり3点以上。方法比較の標準 |
| C-2 | 同カテーテルによる**連続心拍出量**（Vigilance等）の時系列 | 強く推奨 | 熱希釈ベースであり動脈圧と独立 |
| C-3 | **中心静脈圧**の時系列 | **必須（C-1またはC-2がある場合）** | 全身血管抵抗の算出に要る |
| C-4 | **esCCO の出力**（モニタが算出しているもの） | 強く推奨 | 実機の係数は非公開のため、研究1では公表式の再現しか比較できなかった |
| C-5 | 動脈圧波形由来の心拍出量（FloTrac／EV1000等）の時系列 | あれば | 公開データベースとの比較のため。**これのみでは独立参照にならない** |
| C-6 | 経食道心エコーの左室流出路血流速度時間積分 | あれば | 測定時刻とペアで |

肺動脈カテーテルを入れる症例は限られる。**C-1〜C-3 を持つ症例だけの部分集合**として
取得できれば十分であり、全症例に求めるものではない。

## D. 参照となる血管の量（仮想集団にしか無かったもの。②の中核）

指標が「測っていると称する量」の実測値。これが本依頼で新しく加わる最大の価値である。

| # | 項目 | 必須度 | 備考 |
|---|---|---|---|
| D-1 | **上腕-足首脈波伝播速度（baPWV）**または**心臓足首血管指数（CAVI）** | **強く推奨** | 術前の生理機能検査にあれば流用できる。測定日を必ず添える |
| D-2 | 頸動脈-大腿動脈脈波伝播速度（cfPWV） | あれば | 動脈スティフネスの参照標準。実施施設は限られる |
| D-3 | 足関節上腕血圧比（ABI） | あれば | 末梢動脈疾患の除外。指尖の灌流に効く |
| D-4 | 全身血管抵抗（C-1〜C-3から算出できるならその旨。装置が算出しているならその値と算出式） | 強く推奨 | 術中の血管トーヌスの参照。**算出に用いた心拍出量が動脈圧波形由来か熱希釈由来かを明記すること**（前者なら部分的に循環する） |
| D-5 | 術前の心エコー（駆出率、弁膜症、左室流出路径） | あれば | 前駆出期に効く |

**D-1 は術前に一度の測定でよい。**問うているのは「同じ年齢の2名を硬さで順序づけられるか」
であり、術中の変化ではない。仮想集団で特徴点法の指標が満たした規準（年齢層内の
順位相関で絶対値の中央値0.30以上）を、実測の脈波伝播速度に対して問い直す。

## E. 循環に介入した時刻と量（統制された血管運動負荷。公開データベースに無かった）

観察だけでは血管の状態はゆっくりしか動かない。**薬で動かした瞬間**が、指標が血管状態を
追うかを最も鋭く問える。とくにフェニレフリンのボーラスは全身血管抵抗を選択的に上げて
心拍出量を下げるため、通過時間法の誤差が最も出る場面であり、かつ血管指標が動くべき場面である。

| # | 項目 | 必須度 |
|---|---|---|
| E-1 | **血管作動薬の投与時刻と用量**（フェニレフリン、エフェドリン、ノルアドレナリン、ドパミン、ドブタミン、ニカルジピン、ニトログリセリン、ランジオロール） | **必須** |
| E-2 | 同上について、**シリンジポンプの動作記録**（開始・変更・停止の時刻と流量） | 強く推奨 |
| E-3 | 麻酔薬の投与記録（プロポフォール、レミフェンタニル、吸入麻酔薬の呼気終末濃度の時系列） | **必須** |
| E-4 | 輸液・輸血・出血量の時刻と量 | 強く推奨 |
| E-5 | **体位変換の時刻**（頭低位・頭高位・側臥位）と角度 | 強く推奨 |
| E-6 | 気腹の開始・終了時刻と設定圧 | 強く推奨 |
| E-7 | 大動脈遮断・解除、部分体外循環の開始・終了時刻（該当例） | 該当例で必須 |
| E-8 | 麻酔導入・気管挿管・執刀・閉創・抜管の時刻 | **必須** |
| E-9 | 体温（中枢温）の時系列 | 強く推奨 |

**時刻は波形の時間軸と同じ基準でミリ秒または秒まで。**麻酔記録上の丸めた時刻
（5分刻み等）では E-1 の解析に使えない。丸められている場合はその旨を明記すること。

## F. 患者背景

通過時間法の較正定数は年齢・性別・身長・体重から決まるため、F-1 は必須である。

| # | 項目 | 必須度 |
|---|---|---|
| F-1 | 年齢、性別、身長、体重 | **必須** |
| F-2 | ASA-PS、緊急／待機の別 | **必須** |
| F-3 | 既往：高血圧、糖尿病、脂質異常症、慢性腎臓病（透析の有無）、心房細動、末梢動脈疾患、脳血管障害 | **必須** |
| F-4 | 常用薬：降圧薬の種類（Ca拮抗薬／ARB・ACE阻害薬／β遮断薬／利尿薬）、スタチン、抗血小板薬 | 強く推奨 |
| F-5 | 喫煙歴 | あれば |
| F-6 | 術式、診療科、手術時間 | **必須** |
| F-7 | 術前の血液検査（ヘモグロビン、アルブミン、クレアチニン、HbA1c） | 強く推奨 |

高血圧の既往は、指標が血管情報を保持しているかの副次的な確認に使う（研究1では

## G. 装着と留置の情報（③の切り分けに要る。見落とされやすい）

橈骨から指尖までの真の伝播時間は仮想集団で8 ms（5〜95パーセンタイル4〜16）しかなく、
全年齢と6因子の±1標準偏差を通じても12 msの幅しか持たない。ところが研究1では
この区間の症例内標準偏差が約18 msあった。**この差が装着由来か生理由来かを分けるには、
次の情報が要る。**

| # | 項目 | 必須度 |
|---|---|---|
| G-1 | SpO₂プローブの**装着部位**（示指／中指／環指／耳朶／前額）と**左右** | **必須** |
| G-2 | SpO₂プローブの**機種・型番**、透過型か反射型か | **必須** |
| G-3 | 動脈ラインの**留置部位**（橈骨／上腕／大腿）と**左右** | **必須** |
| G-4 | 術中にプローブを付け替えた場合、その**時刻と変更後の部位** | **必須** |
| G-5 | 血圧計カフの装着側（PPGと同側なら加圧のたびに波形が消える） | 強く推奨 |
| G-6 | 上肢の体位（外転／体側固定）、駆血帯の使用 | あれば |

## H. 記録の範囲と症例数

| # | 項目 | 内容 |
|---|---|---|
| H-1 | 対象期間 | 直近3年程度。機種・ソフトウェア版数が途中で変わっている場合は、**その時期を明示すること**（B-7が変わると信号処理も変わる） |
| H-2 | 選択基準 | 成人（20歳以上）、全身麻酔、動脈ライン留置あり、記録60分以上 |
| H-3 | 除外基準 | 心房細動などR波の間隔が不整な症例（別集計として残すのは可）、体外循環中の区間、上肢の手術でプローブ装着が不安定な症例 |
| H-4 | **症例数** | **全体で200例程度。**うち肺動脈カテーテル留置例（C-1〜C-3）が50例、術前脈波伝播速度（D-1）のある例が100例あることが望ましい |

**200例の根拠**: 前提の検証そのものは公開データベースの862例で決着しており、今回の
問いは(ⅰ)実機波形での特徴点の同定率、(ⅱ)血管作動薬投与時の応答、(ⅲ)独立参照に対する
精度の3つである。(ⅰ)は50〜100例で十分な精度が出る。(ⅱ)は1症例あたり複数回の投与が
あるため200例で数百イベントになる。(ⅲ)は方法比較研究の慣行として症例あたり3点以上の
ペアが25例以上あればよく、50例で足りる。**これ以上は費用と手続きに見合わない。**

## K. 全部は無理な場合の優先順位

費用や手続きで削る必要が出た場合、次の順に残す。

1. **B節（信号処理の仕様）** ― これは費用がかからない。**波形より先に取ること。**
   仕様が分からない波形は、研究1と同じ袋小路に入る。
2. **A-1・A-2・A-3（心電図・光電容積脈波・動脈圧の3チャネル）と G節（装着部位）**
   ― 最小構成。これだけで②の一部と③に答えられる。
3. **D-1（術前の脈波伝播速度）** ― 術前検査からの流用なので追加コストが小さい割に、
   ②に直接答える唯一の項目である。
4. **E-1・E-3・E-8（血管作動薬・麻酔薬・節目の時刻）** ― 麻酔記録から取れる。
5. **C-1〜C-3（肺動脈カテーテル）** ― 症例数が限られるので部分集合でよい。
6. A-4（直流成分）、C-4（esCCO 出力）、D-2以降。

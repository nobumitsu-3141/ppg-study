# 用語の決まり（2026-09-07 制定・2026-09-09 改訂）

**造語をしない。文献にある用語をそのまま使う。**訳語が定まっていないものは原語を併記する。
比喩で説明しない（「配管」「土俵」「錨」のような言い換えは、読み手が原論文に戻れなくなる）。
**医学・生理の内容は、原文の語か、広く受け入れられている訳語で書く。**
迷ったら原語をそのまま出す。分かりやすくしようとして語を足さない。
**難しい内容ほど、余計な語を足さずに書く。**

## r² を書くときの決まり

**r² は必ず「何を何で説明したときの決定係数か」を書く。**本研究には形の違う r² が 4 つある。

| 出どころ | 被説明変数 | 説明変数 | 値 |
|---|---|---|---|
| 研究1 §7.1 前提検証 | ΔPWTT%（症例内・ウィンドウごと） | ΔSI% ＋ ΔRI% | 0.044 |
| 同（比較） | ΔPWTT% | ΔMAP% のみ | 0.139 |
| 研究1b Q1 | Δ(T2−T1)%（橈骨→指尖の伝播時間の変化） | ΔT%（分解由来の血管指標） | 0.008 |
| 研究1b Q2 | ΔPWTT% | Δ(T2−T1)% ／ ΔT1% | 0.534 ／ 0.073 |
| 研究1b B-2 | ΔPWTT% | τ ＋ dP/dt_max | 0.015 |

**Q2 の 0.534 と 0.073 は「説明」ではなく分散分解である**（T2 = T1 + (T2−T1) は恒等式）。
さらに PPG 側の立ち上がり検出のジッタはすべて (T2−T1) の項に入るので、末梢区間の分散には
生理と測定雑音の両方が含まれる。この留保を付けずに引用しない。

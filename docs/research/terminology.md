# 用語の決まり（2026-09-07 制定）

**造語をしない。文献にある用語をそのまま使う。**訳語が定まっていないものは原語を併記する。
比喩で説明しない（「配管」「土俵」「錨」のような言い換えは、読み手が原論文に戻れなくなる）。

以下は 2026-09-06 までの文書・要約に混入していた造語と、これから使う語である。
**過去の `lab_log.md` の追記は歴史的記録なので書き換えない**（当時そう書いたことも記録である）。
原稿・要約・スライド・これから書く文書はこの表に従う。

## 言い換え表

| 使わない（造語・比喩） | 使う | 根拠・注 |
|---|---|---|
| 肩 | **変曲点**（下降脚の変曲点） | Dawber 型3 の定義は "no notch develops but there is a well-defined change in the angle of the descent"。下降脚の傾きが変わる点であり、変曲点と呼ぶ |
| 錨（がない） | **切痕も変曲点も無い**／**拡張期ピークが定義できない** | 「錨」は造語。何が無いのかを書く |
| 鍵点 | **特徴点**（fiducial point） | Wang 2013 の "key points, such as the crests and troughs" は収縮期ピーク・切痕・拡張期ピーク。日本語の定訳は特徴点 |
| ランドマーク法 | **特徴点法**（fiducial point analysis） | Basso 2024 の呼称。コード内の識別子（`dt_lm_ms` 等）は変えないが、文章では特徴点法と書く |
| 窓 | **ウィンドウ**（解析ウィンドウ） | 60 秒ごとに区切った解析区間。窓関数（window function）と紛れるうえ、ウィンドウのほうが通りが良い |
| 変種 | **指標の定義を変えた版**／**代替定義** | 実体は ΔT・RI の定義変更（立ち上がり間 ΔT・振幅母数比・成分波面積比）、成分数の変更、品質基準の変更である。SAP §7.5 の感度解析 |
| 指標が届く／届かない | **相関の大きさが〜に及ばない**／**〜を説明できない** | 何と比べて何が足りないのかを毎回書く。「届く」だけでは判定基準が読み取れない |
| 配管 | **解析の流れ**／**処理系** | 陽性対照が確かめているのは、読み込みから判定までの処理が意図どおり動いているか |
| 土俵 | **データセット**／**条件** | 「PWDB という条件では」のように書く |
| 売り文句 | **主張されている利点** | |

## そのまま使う語（造語ではない）

| 語 | 出典 |
|---|---|
| PDA（pulse decomposition analysis）／分解法 | Rubins 2008 以降の定訳 |
| 前進波・反射波 | ただし Epstein 2014・Hellqvist 2024 は「第2成分＝末梢反射」を否定しているので、**慣例上の呼称であると注記して使う** |
| 収縮期ピーク（S）・重複切痕・拡張期ピーク（D） | Dawber 分類、Millasseau 以降 |
| ΔT・RI・SI・AI・AGI_mod | 各原著の定義に従う。分解由来と特徴点由来は別の量なので、必ずどちらか明示する（Goswami 2010） |
| p1・b 波・早期振幅比 Am_b/Am_p1 | Hellqvist 2024。p1 はこの論文が新しく定義した点 |
| 型1〜型5 | Dawber 1973 の 4 型を Wang 2013 が 5 型に細分したもの |
| 同定率・窓間自己相関・級内相関 ICC | 一般的な計量用語 |

## 書かないこと（既存の規則。`gate0_rules_v2.md` より）

- 「ΔT は大動脈の硬さを測る」（Epstein 2014）
- 「第2成分は反射波である」（注記なしに断定しない。Epstein・Hellqvist）
- 「PDA は壊れている」（Goswami。分解由来と特徴点由来は別の量である）
- 「in silico で不成立だから in vivo でも無意味」（Charlton P164）
- 「in silico で成立したから実機でも使える」

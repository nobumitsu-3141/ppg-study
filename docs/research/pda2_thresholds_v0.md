## なぜ凍結が要るのか

研究0 の第一報で、ランドマーク法を走らせる**前に**撤退方針を書いてしまい、その予測が
外れた。結果を見てから判断の基準を動かすと、それはもう検証ではない。同じ構図を
閾値でも作らないために、決定試験の前に値を固定し、振れ幅も先に決めておく。

閾値の来歴を3層に分ける。**(c) が結論を左右するなら、その結論は閾値の産物である。**

## (a) 文献から借りたもの

| 定数 | 値 | 出典 | 借用の妥当性についての注意 |
|---|---|---|---|
| `NRMSE_MAX` | 0.02 | Wang 2013 | Wang は指尖 PPG に3ガウスを当てた。標本化周波数・前処理は同一ではない |
| `ERRX_MS` | 6.0 | Wang 2013 | 鍵点（収縮期ピーク・重複切痕・拡張期ピーク）の時間位置の絶対誤差の総和。500 Hz では格子が 2 ms、鍵点3つで下限 6 ms になり閾値と同じ大きさになるので、放物線補間で副標本精度を出してから測る |
| `ERRY` | 0.01 | Wang 2013 | 同上の振幅版 |
| `LOWPASS_HZ` | 18.0 | Tigges 2017・Couceiro 2015 | Tigges は 18 Hz で帯域制限してから AICc を計算している |

## (b) 自分のデータで理由づけたもの

| 定数 | 値 | 理由 |
|---|---|---|
| `SE_DT_MAX_MS` | 20.0 | 研究1で観測した症例内 ΔPWTT の標準偏差が 18 ms。これより大きい標準誤差の拍は問いに寄与しない。当てはまりの規準だけでは σ=11,725 ms の解が通ることを 25番 T4 で確認した |

## (c) 根拠なく決めたもの（**ここが危ない**）

| 定数 | 値 | どう決めたか |
|---|---|---|
| `W_KEY` | 20.0 | Wang は 1〜100 を探索している。その中間を取っただけ |
| `min_gap`（成分間隔の下限） | 0.03 s | 重複切痕の幅の見当。文献の根拠なし |
| 貯留槽の窓 | `max(dia_t+0.10, 0.62T)` | 拡張期ピークを避ける必要から逆算した。0.10 も 0.62 も根拠なし |
| `rise_exp`（貯留槽の立ち上がり次数） | 2.0 | 二次で滑らかに立ち上がればよい、という以上の理由はない |
| 貯留槽カーネルの判定 | `dia_t+0.08` かつ `0.60T` | ガンマに位置母数を入れた後の応急処置 |
| 境界近傍の許容 | 可動域の 0.1% | 共分散の発散を止めるために置いた。0.1% である理由はない |
| 特異性の打ち切り | `sv_min ≤ sv_max × 1e-6` | 同上 |
| 一意性の検査 | `tol_cost=1.15`, `tol_dt=0.20` | 「残差が 15% 以内で競合し、ΔT が 20% 以上違えば曖昧」。どちらも見当 |
| `max_nfev` | 1200 | 収束の観察から。1200 で足りない拍がありうる |

## 事前指定した感度解析

`scripts/27_threshold_sensitivity.py`。**26番の実行前に書き、振れ幅を固定した。**

### A 層（当てはめ後に効く規準・当てはめ直し不要）

当てはめの診断量は 26番が被験者ごとに保存する（`nrmse` `errx` `erry` `n_landmark_matched`
`dt_se` `ambiguous`）ので、採否だけを作り直せば済む。数秒で終わる。

| 規準 | 振る値 |
|---|---|
| NRMSE 上限 | 0.010 / 0.015 / **0.020** / 0.030 / 0.050 / ∞ |
| Errx 上限 | 3 / **6** / 12 / 25 / ∞ ms |
| Erry 上限 | 0.005 / **0.010** / 0.020 / ∞ |
| ΔT の SE 上限 | 5 / 10 / **20** / 50 / ∞ ms |
| 一意性の検査 | **あり** / なし |
| すべて外す | 採否を全部無効化（共分散が計算できた拍のみ） |

再計算した採否が 26番の保存値と一致するかを毎回検算する。一致しなければ表は無効とする。

### B 層（当てはめ自体を変える規準・当てはめ直しが要る）

被験者番号を 7 で割った余りが 0 の集団（約 625 名。年齢層は均等に入る）に固定する。
**結果を見てから部分集合を選び直さない。**

| 条件 | 値 |
|---|---|
| 鍵点の重み | 1（重みなし相当） / **20** / 100（Wang の上限） |
| 低域通過 | 10 / **18** / 25 Hz |
| 成分間隔の下限 | 15 / **30** / 60 ms |
| 成分を増やすか | **増やす** / 増やさない |

## 判定の読み方（先に決めておく）

- **どの閾値でも判定が同じ** → 結論は閾値の産物ではない。そのまま報告する
- **閾値によって割れる** → その閾値が結論を作っている。論文には**割れる範囲を明記**し、
  「成立」とは書かない
- **「すべて外す」の行が凍結値と大きく違う** → 採否そのものが選択になっている。
  26番の A・B・C の3段と合わせて読む

## 既知の未解決（閾値では解決しない）

- **重複切痕の無い波形**（Dawber 3〜4型）で ΔT の誤差が 38〜55 ms。合成波で確認済み。
  これは閾値の問題ではなく、波形に情報が無いことによる。26番の波形型別の表で
  実データでの影響を見る
- **ガンマ経路の心拍数交絡が 27 ms**（two_stage は 13.4 ms）。位置母数を足して 155→27 ms
  まで改善したが、形状母数ひとつで立ち上がりと下降の両方を決める構造は残る
- **ΔT に系統誤差**（合成で +5.9 ms）。症例内の変化を見る設計では相殺されるが、
  **絶対値を他研究と比べてはならない**
- **採否規準は正確さではなく当てはまりを選ぶ**。成分を増やすと当てはまりは良くなるが
  ΔT は真値から約 2 ms 遠ざかる。26番で成分を増やしたかどうかを層別する

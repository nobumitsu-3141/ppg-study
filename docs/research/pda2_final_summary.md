## 1. 位置づけ（何を決めようとしているか）

研究0 は「指尖 PPG から取り出した指標が、真値既知の仮想集団（Charlton PWDB、4,374 名）で
脈波伝播速度・末梢血管抵抗を追えるか」を問う。2026-09-03 の凍結版 2 カーネル PDA は不成立
（ΔT×大動脈PWV の年齢層内 |ρ| 中央値 0.223、RI×末梢血管抵抗 0.207）、同じ波形からの
ランドマーク法は成立（0.710・0.504）だった。文献精読（Wang 2013・Tigges 2017・Couceiro 2015・
Fleischhauer 2020・Basso 2024・Goswami 2010・Epstein 2014・Hellqvist 2024・Charlton P164）で
凍結版の欠陥が特定できたので、第2版（`src/pda2.py`）を作り、**同じ被験者・同じ真値・同じ規準**で
第2版・凍結版・ランドマーク法・早期振幅比（Hellqvist）を並べる決定試験（26番）を用意した。
判定の読み方は `gate0_rules_v2.md` に、閾値は `pda2_thresholds_v2.md` に、主張と検査の対応は
`pda2_verification_matrix.md` に、実行前に固定してある。

## 2. 最終的に固まった処理と条件

### 2.1 処理の流れ（`pda2.decompose(t, y, fs, route)`）

| 段 | 関数 | 何をするか | 条件・定数 |
|---|---|---|---|
| 入口 | `decompose` | fs が有限の正、t が秒の単調な等間隔、t と y が同じ長さ・1 次元（n×1 は潰す）。250 Hz 未満は低域通過の**前**に 500 Hz へ補間、1000 Hz 超は後に 500 Hz へ落とす | 違えば `bad_input` |
| 前処理 | `preprocess` | 18 Hz 4 次 Butterworth 零位相 → 両端 8% の中の足を結ぶ直線を引く（足→足基線）→ 基線 0・最大 1 | `LOWPASS_HZ` 18、`FOOT_SEARCH_FRAC` 0.08 |
| 鍵点 | `find_landmarks` | 収縮期ピーク S。極小（切痕）→ 極大（拡張期ピーク）を窓 0.05T〜0.65T／〜0.85T で探し、高低差 ≥ 0.01 なら**型1**。無ければ 1 次微分の局所極値で代用（最速下降点＝切痕代用、肩＝拡張期代用。肩の顕著さは両側で測り最大傾斜の 5% 以上）なら**型3**。無ければ**型4**。S が末尾なら型5。位置は放物線補間で副標本精度 | `NOTCH_MIN/MAX_FRAC` 0.05/0.65T、`DIA_MAX_FRAC` 0.85T、`EXTREMA_MIN_PROM` 0.01、`PROXY_MIN_PROM` 0.05 |
| 早期特徴 | `early_features` | Hellqvist の p1（b 波での接線の零交点）・b・Am_b/Am_p1 | 分解を使わない第 4 の腕 |
| 重み | `_weights` | 鍵点 ±6 ms に重み 20（Wang の WLS。近傍は標本数でなく時間で指定） | `W_KEY` 20 |
| 初期値 | `_wave_starts` | 汎用初期値を主（Fleischhauer）、ランドマーク由来を副、位置を振った 3 点。幅は拍長 T で尺度化 | `T_REF` 60/70 s |
| 探索範囲 | `_wave_bounds` | 高さ 前進波 0.30〜1.6・他 0.02〜1.6、ピーク時刻 前進波 ≤ 0.55T・他 ≤ 0.95T、幅 0.012〜0.28 × T/T_REF、歪み 0〜8（ガンマ: 形状 1.05〜40、立ち上がり 0.015〜0.35 × T/T_REF） | `ALPHA_MIN` 0、`GAMMA_SHAPE_MAX` 40、`GAMMA_RISE_MAX` 0.35 |
| 制約 | `_order_penalty` | ピーク時刻の単調増加（間隔 ≥ 30 ms）と前進波が最大、を罰則で（Couceiro・Basso） | `min_gap` 0.03 s |
| 当てはめ | `_multistart` → `fit_waves`／`fit_gamma` | 信頼領域法（`x_scale="jac"`）、起動あたり 1200 評価。歪みガウス 2 成分（`skew`）／ガンマ 3 成分（`gamma`。到達時刻の母数つき） | `MAX_NFEV` 1200（飽和率を表 1 で監視） |
| 採否 | `acceptance` | データと同じ方法で模型の鍵点を取り、NRMSE < 0.02・Errx < 6 ms・Erry < 0.01・鍵点 2 つ以上（Wang 2013） | `NRMSE_MAX` `ERRX_MS` `ERRY` |
| 次数 | `decompose`（`escalate`） | 採否か曖昧判定を満たさなければ成分を 1 つ足す（歪みガウス 3・ガンマ 4）。**ΔT の SE 超過では足さない**。足したかを返し下流で層別 | Wang の 4→5 に相当 |
| 役割 | `assign_roles` | 前進波＝最初の成分。拡張期ピーク +80 ms かつ 0.60T より後の最後の成分は貯留槽（減衰）。反射波＝拡張期の鍵点に最も近い成分。2 番目の候補との僅差 `ref_margin_ms`、貯留槽の境目までの距離 `res_margin_ms` を返す | +0.08 s／0.60T |
| 一意性 | `_ambiguous`・`competing_spread_ms`・`ambiguity_flags` | 残差が最良解の 1.15 倍以内の競合解に**役割を割り当て直して** ΔT の広がりを測る。広がり > 20 ms、前進波がスロット 0 でない、反射波の僅差 < 20 ms、貯留槽の境目 < 20 ms、のどれかで曖昧 | `TOL_COST` 1.15、`SE_DT_MAX_MS` 20 |
| 指標 | `_peaks_and_se`・`indices` | ΔT = 反射波ピーク時刻 − 前進波ピーク時刻、RI = 高さ比、DPS = 幅の差（Goswami）。標準誤差は Wald（境界近傍の母数を固定、J の SVD、順序罰則の行は自由度から外す、張り付いたピーク時刻は SE = ∞） | SE ≤ 20 ms |
| 型3 | `decompose`（`accept_proxy=False`） | 代用点しか無い拍は**規則で採用しない** | 理由 `proxy_landmarks` |

理由コードは 1 つだけ返す（優先順: `bad_input` → `amplitude` → `fit_failed` → `no_landmarks` →
`proxy_landmarks` → `landmark_or_fit` → `no_reflected` → `ambiguous` → `dt_se`／`no_se`）。

| 群 | 定数 | 値 | 由来 |

| 文献 | 基底・ピーク母数化・不等式制約・幅の尺度化・汎用初期値・次数の適応 | — | Basso・Couceiro・Fleischhauer・Wang |

27番で検定する（振れ幅は実行前に固定）。

### 2.3 決定試験の設計（26番・27番・28番）

- **4 手法**（第2版 歪みガウス／ガンマ・凍結版・ランドマーク（Charlton 同梱値）・早期振幅比）を
  同じ真値（大動脈PWV・末梢血管抵抗、副次に頸大腿PWV）に当てる。
- **判定規準**（凍結・20番と共有）: 年齢層内 Spearman ρ が 6 層すべてで予測の向き、かつ中央値 |ρ| ≥ 0.30。
  層は 8 名以上。層が欠けた判定には `*`。
- **3 段**: A 各手法の合格例、B 3 手法共通の合格例、C 採否を無視した全例。
  「成立」は主たる経路（歪みガウス）が **2 つの問いの両方**で **A・B・C すべて**、`*` なし。
- **陽性対照**: モデル出力 PTT × 大動脈PWV の |ρ| ≥ 0.50 でなければ表全体を無効。
- **27番**: A 層（当てはめ直し不要。NRMSE・Errx・Erry・SE・曖昧判定・型3 を振る）と
  B 層（`subj_no % 7 == 0` の約 625 名で当てはめ直し、14 条件）。判定が閾値で割れれば「成立」と書かない。
- **28番**: 乱数の拍 150 × 2 領域で不変条件 I1〜I9。領域内（心拍 50〜100・雑音 ≤ 0.01・RI ≥ 0.3）の
  歪みガウスの誤採用率 ≤ 10% を退行の門番にする（現版 3/48）。

## 3. 文献との一致と違い、その理由

| 文献 | 文献の主張 | 採ったこと | 採らなかった／変えたこと | なぜ |
|---|---|---|---|---|
| **Basso 2024**（歪みガウス PDA） | 歪み正規分布をピーク母数化、18 Hz、足からの直線基線、振幅正規化、`a₁` 最大・最頻値単調の制約、汎用初期値 | **設計はほぼ同一**（独立に同じ設計に至っていた。原稿で踏襲を明記） | (1) 歪み α: Basso は無制約、我々は **0〜8**。(2) 標本化: Basso は 28 標本（≈ 42 Hz）、我々は **500 Hz** のまま。(3) 目的関数: 重みなし → **鍵点重みつき**。(4) 最適化: fmincon 無制限 → 信頼領域法・1200 評価。(5) 成分数 L=2〜4 を並べる → **2 から適応的に 3** | (1) 前進波は右歪みという事前知識。左歪みは B 層（−8）で検定。(2) 鍵点の時間誤差の閾値 6 ms は 500 Hz の格子 2 ms × 3 点と同じ大きさなので副標本精度が要る。100 Hz では肩（型3 の代用点）が 60 ms 動いた（7 巡目）。40 Hz は B 層で検定。(3)(5) Wang（下）。(4) 飽和率を表 1 で監視し、1200→4000 で採否・ΔT が不変（7 巡目） |
| **Wang 2013**（WLS と鍵点の検算） | 当てはまりの良さと鍵点の正しさは別。鍵点に重み 1〜100、NRMSE < 2%・Errx < 6 ms・Erry < 0.01、4 → 5 ガウスの適応 | **採否規準・WLS・次数の適応をそのまま採用**。重みは範囲の中間 20 | Wang の 3 規準に **ΔT の SE ≤ 20 ms・曖昧判定・型3 の除外**を足した。初期値は 2 次微分由来ではなく汎用 | 合成波で Wang の 3 規準をすべて通る当てはめが ΔT +23 ms（型3・ガンマ）を採用した（T5）。競合解が残差で拮抗して ΔT が 130 ms 違う例（F5）、貯留槽の境目の 1 µs で ΔT が 180 ms 跳ぶ例（F2）があり、当てはまりでは弾けない。微分由来の初期値は雑音を増幅する（Fleischhauer） |
| **Tigges 2017**（AICc で基底を選ぶ） | 実測 7,805 拍で Gamma M=3 が最良、Normal M=2（我々の凍結版に最も近い）は 1.2%。18 Hz・極小点で切り出し・線形基線 | **ガンマ経路を設け**、前処理を合わせた | Tigges のガンマ（拍の先頭から立ち上がる）に**到達時刻の母数を足した**。AICc による次数選択は採らず Wang 式 | 到達時刻が無いと全成分が拍の先頭から立ち上がり、遅れて届く反射波を表せない（心拍交絡 155 ms → 18.8 ms、T3）。AICc は当てはまりの規準であって鍵点の正しさを見ない |
| **Fleischhauer 2020**（19 手法の比較） | 2 カーネルが雑音に最も頑健。ただし「2 カーネルは反射をひとつに凝縮し、収縮期成分と特定の反射の関係を評価できない」。汎用初期値が最も頑健。2 次微分の NRMSE で評価 | **汎用初期値を主**にする多点起動。歪みガウスは 2 成分を既定 | 2 カーネル固定は捨て、**足りなければ 3**。評価は 2 次微分の NRMSE ではなく Errx | 我々が 2 カーネルの根拠にした論文自身が、ΔT・RI の用途に 2 カーネルは使えないと書いていた。3 成分を既定にすると同じ 150 拍で誤採用 3→6・誤差中央値 3.6→4.9 ms と悪化した（10 巡目）ので「足りなければ」に留めた。Errx は鍵点の位置を直接見るので、我々の指標に近い |
| **Couceiro 2015**（5 ガウスと不等式制約） | 成分間に振幅と位置の不等式制約、役割を固定 | **単調な位置・前進波最大**を罰則で課す | 5 ガウスは採らない。役割は当てはめに決めさせず**規則**（拡張期の鍵点に最も近い成分）で決める | 18 Hz の 1 拍の独立標本は 24〜40 点で、5 成分 20 母数は過剰母数化。Couceiro の 5 ガウスは雑音下で最悪（Fleischhauer）。凍結版は「第 1 が前進波・第 2 が反射波」を仮定しながら強制していなかった |
| **Goswami 2010**（Rayleigh 2 本の ΔT・RI） | ΔT = tp2 − tp1、RI = p2/p1。**分解由来は計測由来と構造的にずれる**（h₂ は前進波の裾を含む。RI_PDA < RI_lm、ΔT_PDA > ΔT_lm）。差分パルス幅 DPS。段階的な当てはめ、拍の終わり（0.9T 以降）は合わせない | 指標の定義は同一。**DPS を記述指標として追加**。「PDA 不成立・ランドマーク成立」を「別の量」として読む判定行を置き、ΔT_PDA の絶対値は他研究と比べない | 段階的当てはめは採らず同時に当てはめる。`fit_frac=0.9` は B 層の条件 | 合成波でも ΔT_PDA は真値より +6〜8 ms 大きく RI は小さく、Goswami の説明と符合した。貯留槽項で拍の終わりを合わせにいった第1版は機能せず（τ 0.151 対 真値 0.35）削除 |
| **Epstein 2014**（1 次元 75 動脈モデル） | SI を動かすのは導管動脈全体の硬さ。大動脈だけを硬くすると PPT はむしろ延びる。末梢反射を消しても 2 つのピークは残る | 主要目標（大動脈PWV）は凍結したまま、**頸大腿PWV を副次に追加**。「大動脈の硬さ」「第 2 成分は反射波」とは書かない（書かないことの一覧） | — | 事前規準の符号（ΔT×大動脈PWV が負）は大動脈だけを硬くした場合に逆になりうる。PWDB のランドマーク ΔT が PWV 因子に −20% を示す事実は、PWV 因子が導管全体を変えていることを示唆する |
| **Hellqvist 2024**（早期振幅比） | Am_b/Am_p1 が頸大腿PWV と r = −0.81。「S と D のピーク間の時間に頼る指標ではなく波形の早期部分に注目すべき」。p1 は 6 型すべてで定義できる | **Am_b/Am_p1 を第 4 の腕**として同じ表に並べる。**p1 基準の ΔT** を追加（切痕なし波形の収縮期ピーク） | 主指標の差し替えは結果を見てから（判定規則の行: 早期振幅比がランドマーク ΔT と同等以上なら研究2 の主指標候補にする） | 我々の ΔT はまさに名指しされた「ピーク間の時間」。合成波では Am_b/Am_p1 が動かない（前進波を固定しているため）ので PWDB でしか判定できず、散らばりが狭い（幅 < 0.05）場合は指標の実力と読まないと決めた |
| **Charlton P164**（PWDB の作者） | in silico では単一の動脈硬化指数がそもそも交絡する。in vivo で良い硬さ指数が in silico では悪い。複数指標を組み合わせよ | 撤退規則を「3 系統すべて in silico で不成立、かつ研究1 で信号なし」に書き換えた。4 手法を並べる | — | in silico の不成立は in vivo の否定にならない。逆に in silico の成立も実機での成立を含意しない（雑音・体動・装置特性が無い）と明記 |
| **Putcha 2026**（PPG-Basis） | Kendall τ の併用、2 次微分の NRMSE、差分進化 → SLSQP | 歪みガウスが標準カーネルであることの傍証 | τ・DE は採らない | Errx が同じ失敗様式（順序・位置）をより直接に見る。多点起動 5〜6 点は DE の簡易版。局所解の疑いが出たら試す |
| **Lee 2011・Awad 2007** | 脈波の幅が反射係数より末梢血管抵抗をよく弁別 | DPS（幅の差）を記述に加える根拠 | 向きは事前指定しない | 真値との向きの予測までは立たない |

## 4. なぜそうなったか（監査 49 巡で何が決めたか）

閾値・規則の値は**文献か生理か自分のデータ**で決め、**PWDB の結果では決めない**、を貫いた。
決め手になった合成波の測定を挙げる（25番・28番。値は現版）。

| 決めたこと | 決め手 |
|---|---|
| 貯留槽項の削除 | 線形基線除去後の 1 拍では減衰が末尾で強制的に 0 になり、時定数が真値の半分以下（0.151 対 0.35 s）。膝をどこに置いても振幅が潰れるか当てはまりが壊れる。減衰は成分を 1 つ増やせば担える（90% の拍） |
| ガンマに到達時刻の母数 | 無いと心拍交絡 155 ms。足して 18.8 ms（歪みガウス 12.6、凍結版 14.6。T3） |
| 歪みガウス 2 → 3 の適応（3 を既定にしない） | 3 既定は誤採用 3→6・誤差中央値 3.6→4.9 ms に悪化。増やした拍は ΔT が約 2 ms 遠ざかるので層別 |
| Wang の規準だけでは足りない | 規準をすべて通って ΔT +23 ms（型3・ガンマ）。→ 型3 は採用しない・SE 上限・曖昧判定 |
| SE の上限 20 ms を 4 か所に | 反射波の 2 候補が僅差なら選択はくじ引きで ΔT はその差だけ動く。貯留槽を外した成分も候補だった（この経路の誤差中央値 +15.1 対 +5.3 ms、F1）。境目は崖（180 ms、F2）。競合解は役割を割り当て直して比べる（309 対 130 ms が広がり 1.9 ms と出ていた、F5） |
| 張り付いたピーク時刻の SE は ∞ | 分散 0 で同定できていないのに門番を通っていた（F7）。順序罰則の行は自由度から外す（F6） |
| 標本化周波数を 500 Hz に正規化 | 100 Hz で肩が 60 ms 動く、1000 Hz 超で 1 拍 200 s、fs=inf で例外（7 巡目の独立監査） |
| 幅の尺度化 | 心拍数だけを振ったとき ΔT が動かない（T3）ための最小限。Basso と同じ |
| 3 段（A・B・C）と `*` | A だけ通るのは難しい拍を捨てた効果。層が減ると判定が通りやすくなる |
| 陽性対照を表の先頭に | 規則には書いてあったのにコードが 0.5 を評価していなかった（M4）。列が無ければ無効 |
| 内部結合（分母） | 600 名の予備実行で採択率が 75% → 19% に見えた（M1） |
| 28番の門番は「退行」の監視 | 幅広い反射波（切痕なし・幅 90 ms）は貯留槽と区別できず、規準では落とせない。領域内 3/48・3/68。順位相関は 0.993 → 0.982／0.987 としか下がらないので不成立の言い訳にしない |
| RI の成立は独立の証拠にしない | 貯留槽の振幅だけを 0.15→0.70 に振ると RI が 0.45→0.57（歪み）／0.80（ガンマ）。PWDB では末梢抵抗が貯留槽を決めるので関係の一部は推定器に内蔵 |

見つかり方の推移も記録に値する。1〜6 巡目はコードの挙動、7 巡目は「なぜ毎回見つかるのか」を
止めるための検証表と乱数検査、10 巡目は表を読む人の目（分母 3 か所）、11 巡目は独立の 2 体の精読
（25 件）、12 巡目以降は視点を変える反復（挙動に関わるもの 1 件・検査の穴 3 件・文書の鮮度 10 件）で、
47〜49 巡目に修正点が出なくなった。**同じ対話が書いて同じ対話が検べる限り穴は残る**、が教訓である。

## 5. 既知の限界（先に書いておく。詳細は `pda2_thresholds_v2.md`）

- ΔT_PDA とランドマーク ΔT は別の量（Goswami）。測るのは導管動脈全体の硬さ（Epstein）。第 2 成分を
  「反射波」と呼ぶ根拠は 2 文献で否定されている（Epstein・Hellqvist）。
- 型3（切痕なし）では第2版の ΔT は得られない。型3 はランドマーク・p1・早期振幅比で読む。
- 採用した拍でも 4〜6% で ΔT が 20 ms 以上ずれる（幅広い反射波）。順位相関はほとんど減衰しない。
- ガンマ経路は採用の 96% が探索範囲の上限に張り付き、心拍交絡も大きい。頑健性の確認用。
- in silico の限界: 雑音・体動・装置特性が無い、1 被験者 1 拍、年齢層は模型の母数を振ったもの、
  真値は模型の入力。成立しても「概念として標的を追える」までしか言えない。

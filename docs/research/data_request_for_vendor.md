# 波形データ抽出の仕様（業者さま向け）

**2026-09-08　長崎県五島中央病院麻酔科　川副靖晃**
**研究名**　光電容積脈波の波形解析による血管指標と脈波伝播時間法の心拍出量推定に関する研究

対象症例の選定と件数は別紙「大学ご担当者さま向け」に記載しています。
本紙は抽出の技術仕様です。**§5 の回答欄のご記入を、波形の抽出より先にお願いいたします。**

**モニタは日本光電製と伺っています。**参考として挙げている VitalDB のチャネル名は、
モニタのアナログ出力を専用のA/D変換器で全チャネル 500 Hz 標本化したものです。
**モニタのネットワーク出力から抽出する場合、標本化周波数が異なる可能性があります**ので、
§5-1 と §5-2 を先にご確認ください。

## 1. 抽出する波形

| # | 信号 | 標本化周波数 | 参考（VitalDB のチャネル名） |
|---|---|---|---|
| 1 | 心電図（II誘導、R波が明瞭な誘導） | **500 Hz 以上** | `SNUADC/ECG_II` |
| 2 | 光電容積脈波（SpO₂プローブ） | **500 Hz 以上** | `SNUADC/PLETH` |
| 3 | 観血的動脈圧（橈骨動脈） | **500 Hz 以上** | `SNUADC/ART` |

**心拍数・平均血圧・脈拍数などの算出値は不要です。**上記3チャネルから当方で計算します。

### 波形の取り扱い

| # | 要件 |
|---|---|
| 1-1 | **無圧縮・無間引き。**表示のためのダウンサンプル、スパイク除去、平滑化を行わないこと |
| 1-2 | **欠測は NaN または欠測フラグで残すこと。**ゼロ埋め・前値保持・内挿を行わないこと |
| 1-3 | 麻酔導入前（可能なら入室時）から抜管まで**連続**。区間の切り出しは不可 |
| 1-4 | **3チャネルが同一の時間軸にあること。**ずれがある場合は §5 の 5-6 で開示すること |
| 1-5 | **光電容積脈波が心電図と同じ標本化周波数であること。**ベッドサイドモニタでは、心電図と脈波で出力レートが異なる構成が少なくありません。同じにできない場合は §5-2 に実際の値をご記入ください |

## 5. 信号処理の仕様（**最重要。波形の抽出より先にご回答ください**）

本研究は光電容積脈波の**振幅**から作る指標を扱います。モニタ側で自動利得制御が
かかっていると、振幅の情報は解析に到達する前に失われますが、**失われたこと自体は
波形からは判別できません。**そのため、下記の仕様が不明なままでは当該解析が
原理的に成立しません。

**非開示の項目は「非開示」とご記入ください。それで十分です。**
推定値や「おそらく」のご回答は解析に用いることができないため、不要です。

**2-3 についての注（なぜボーラス熱希釈の時刻が要るか）**
本研究は 60 秒ごとに指標を計算し、その症例内の変化を心拍出量・血管抵抗の変化と突き合わせます。
公開データベース（VitalDB）の肺動脈カテーテル症例で確かめたところ、**連続心拍出量は数分の
移動平均であるため 60 秒の区間ではほとんど動かず、そこから算出した全身血管抵抗が平均血圧の
ほぼ定数倍になってしまいました**（両者の相対変化の症例内順位相関が +0.79）。これでは
「熱希釈由来」と名がついていても、動脈圧波形と独立した血管抵抗になっていません。
**ボーラス熱希釈の時刻に合わせて解析すれば、その時点の心拍出量は完全に独立です。**
1症例あたり3〜5点でも、独立性のほうが点数より重要です。5-14 を伺いたいのも同じ理由です。

### 可能であればご検討いただきたいこと

| # | 内容 | 目的 |
|---|---|---|
| 5-12 | **自動利得制御を切った、または利得を固定した記録**を1例でも取得できないか | 同一患者で通常記録と比較すれば、5-5 の影響を直接測定できます |
| 5-13 | 心電図入力と SpO₂ 入力に**同時に既知の信号を入れた記録**を1回だけ取得できないか | 5-6 が非開示でも、チャネル間の遅延が実測値として確定します |

### 500 Hz が確保できない場合

ネットワーク出力の標本化周波数が低い場合（100 Hz 程度など）、次の順でご検討ください。

1. **モニタのアナログ出力に A/D 変換器を入れる。**VitalDB と同じ構成になり、
   3チャネルとも 500 Hz・同一時間軸で取得できます。研究用に数台あれば足ります。
2. **Vital Recorder 等の波形記録ソフトで取得できないか確認する。**複数ベンダのベッドサイド
   モニタに対応していますが、日本光電製で実際に何チャネルを何 Hz で取得できるかは、
   実機での確認が要ります。
3. **低い標本化周波数のまま進める。**この場合、脈波の立ち上がり時刻の分解能が
   標本化間隔（100 Hz なら 10 ms）に制限されます。本研究が扱う変動は数十 ms の
   範囲であるため、**解析の精度が落ちることを承知のうえで進める判断**になります。
   その場合も、実際の標本化周波数を 5-2 にご記入ください。

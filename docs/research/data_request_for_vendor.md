# 波形データ抽出の仕様（業者さま向け）

**2026-09-08　長崎県五島中央病院麻酔科　川副靖晃**
**研究名**　光電容積脈波の波形解析による血管指標と脈波伝播時間法の心拍出量推定に関する研究

対象症例の選定と件数は別紙「大学ご担当者さま向け」に記載しています。
本紙は抽出の技術仕様です。**§5 の回答欄のご記入を、波形の抽出より先にお願いいたします。**

---

## 1. 抽出する波形

| # | 信号 | 標本化周波数 | 参考（VitalDB のチャネル名） |
|---|---|---|---|
| 1 | 心電図（II誘導、R波が明瞭な誘導） | **500 Hz 以上** | `SNUADC/ECG_II` |
| 2 | 光電容積脈波（SpO₂プローブ） | **500 Hz 以上** | `SNUADC/PLETH` |
| 3 | 観血的動脈圧（橈骨動脈） | **500 Hz 以上** | `SNUADC/ART` |

**心拍数・平均血圧・脈拍数などの算出値は不要です。**上記3チャネルから当方で計算します。

### 波形の取り扱い

| # | 要件 |
|---|---|
| 1-1 | **無圧縮・無間引き。**表示のためのダウンサンプル、スパイク除去、平滑化を行わないこと |
| 1-2 | **欠測は NaN または欠測フラグで残すこと。**ゼロ埋め・前値保持・内挿を行わないこと |
| 1-3 | 麻酔導入前（可能なら入室時）から抜管まで**連続**。区間の切り出しは不可 |
| 1-4 | **3チャネルが同一の時間軸にあること。**ずれがある場合は §5 の 5-4 で開示すること |

## 2. 抽出する数値データ

| # | 項目 | 間隔 |
|---|---|---|
| 2-1 | 心拍出量の時系列 | 1秒〜1分のいずれでも可 |

| 2-4 | esCCO の出力（表示している症例のみ） | 装置の更新周期のまま |

## 3. 患者背景（別ファイル、1行1症例）

年齢／性別／身長／体重／症例の通し番号。

**任意（既存記録から取り出せる場合のみ）**
SpO₂プローブの装着部位と左右／動脈ラインの留置部位と左右／
術前 baPWV または CAVI と測定日／血管作動薬の投与時刻と用量。

## 4. 出力形式

| # | 項目 | 内容 |
|---|---|---|
| 4-1 | 波形の形式 | Vital Recorder の `.vital`、EDF、WFDB、CSV のいずれか。**独自形式の場合は仕様書を添付してください** |
| 4-2 | 時刻の表現 | UNIX時刻または ISO 8601 で**ミリ秒まで**。タイムゾーンを明記 |
| 4-3 | 時間軸の共有 | 波形・数値データ・イベントが**同一の基準時刻**を持つこと。別ファイルでも可 |
| 4-4 | 背景・イベント | CSV または Excel。文字コードは UTF-8 |
| 4-5 | 匿名化 | 症例識別子は通し番号のみ。氏名・カルテ番号・生年月日・手術日・施設内担当者名を含めないこと。対応表は貴学（依頼元）で保持 |
| 4-6 | 受け渡し | 暗号化した媒体または認証つきストレージ |
| 4-7 | 概算容量 | 3チャネル×500 Hz×4時間 ≒ 1症例あたり約200 MB（倍精度・無圧縮）。**圧縮形式で可** |

## 5. 信号処理の仕様（**最重要。波形の抽出より先にご回答ください**）

本研究は光電容積脈波の**振幅**から作る指標を扱います。モニタ側で自動利得制御が
かかっていると、振幅の情報は解析に到達する前に失われますが、**失われたこと自体は
波形からは判別できません。**そのため、下記の仕様が不明なままでは当該解析が
原理的に成立しません。

**非開示の項目は「非開示」とご記入ください。それで十分です。**
推定値や「おそらく」のご回答は解析に用いることができないため、不要です。

| # | 確認事項 | ご回答欄 |
|---|---|---|
| 5-1 | 光電容積脈波チャネルは**表示用の波形**ですか、**生波形**ですか |  |
| 5-2 | かかっている**フィルタ**の種類・次数・遮断周波数（高域・低域とも） |  |
| 5-3 | **自動利得制御（AGC）または振幅の正規化**はありますか。ある場合、その時定数と単位（拍ごと／固定時間窓／記録全体） |  |
| 5-4 | **心電図と光電容積脈波の相対遅延**はありますか。ある場合、その値と、固定か可変か |  |
| 5-5 | 各チャネルの**実効標本化周波数**（内部で間引いていないか） |  |
| 5-6 | 欠測・アーチファクト区間の扱い（NaN／前値保持／内挿／その他） |  |
| 5-7 | **モニタの機種名とソフトウェア版数**、SpO₂モジュールの型番 |  |
| 5-8 | 対象期間内に機種・ソフトウェア版数の変更がありましたか（あればその時期） |  |
| 5-9 | esCCO を出力している場合、その**更新周期と平滑化の窓** |  |

### 可能であればご検討いただきたいこと

| # | 内容 | 目的 |
|---|---|---|
| 5-10 | **自動利得制御を切った、または利得を固定した記録**を1例でも取得できないか | 同一患者で通常記録と比較すれば、5-3 の影響を直接測定できます |
| 5-11 | 心電図入力と SpO₂ 入力に**同時に既知の信号を入れた記録**を1回だけ取得できないか | 5-4 が非開示でも、チャネル間の遅延が実測値として確定します |

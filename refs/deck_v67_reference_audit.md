## 3. 内容の誤りとして修正した点

1. **p56（Lee 2011）**
   - 「ICU 患者 64 人」→ **48 人**（原著の対象数）
   - 「単独の特徴量では識別能力が**高い**」→ **低い**（RI 単独 κ=0.33 に対し最良の特徴量セットで κ=0.57。スライドに貼られた原著の表とも矛盾していた）
2. **p62（d/a と RI）**
   - 「Mdlazim **2023**」→ **24. Md Lazim 2020**（2023 年版は存在しない）
   - 昇圧薬 AT II への反応：d/a・RI とも「低下」→ **d/a 低下・RI 上昇**（Millasseau 2003 で RI は 12.6% 増加）
   - 降圧薬 GTN への反応：RI「上昇」→ **低下**（同 32% 減少）。d/a は用量依存的に変化せず（△のまま）
   - 「SVR との比較：RI あり（まずまず）」→ **κ=0.33（単独）** と数値を明示
3. **p61（b/a と SI）**
   - 「批判：臓器障害との関連が**ない**」→ **弱い**（Tabara 2016 は「弱いか有意でない」。b/a で β=0.069, P=0.002）
   - 「血圧との相関：SI あり（特に DBP で 0.68）」→ 出典を特定できず **△（MAP 依存）** に変更
   - 年齢との相関 0.63 は Millasseau **2003** の値であることを明示
4. **p66（極端な動脈硬化）**
   - 「切痕不明瞭なのは…重複切痕は 25,286 名（14%）」は文がねじれており誤読を招く。
     Cunningham 2023（n=169,787）の 25,286 名（14%）は**切痕が欠如していた人数**。
     すなわち **86% では切痕が見える**。改訂ページでこの向きに直した。
5. **p22（Wu 2010）の番号**：「22. Wu 2010」の 22 は Elgendi 2012。別番号（36）に分離した。

## 4. 検証しきれず「要出典」と明記した数値

p61 の表にある **b/a の 年齢 0.51 ／ PWV 0.61 ／ 血圧 0.19** は、von Wowern 2015・
Tabara 2016 の抄録からは確認できなかった。改訂ページでは○×の定性表示にとどめ、
スライド面に「b/a の相関係数は抄録に記載がなく、原著本文での確認が必要（要出典）」と
赤字で明示してある。原著本文を確認できしだい数値を戻すのが望ましい。

また p53 の「SI と年齢 r = 0.67」は Millasseau 2002 の抄録からは裏づけられない
（同論文にあるのは重回帰 SI = 0.63 + 0.086×age + 0.042×MAP, r = 0.69）。
年齢との単相関 R = 0.63 は Millasseau **2003** の値である。要修正。

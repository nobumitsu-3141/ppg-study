原題：The relationship between the area of peripherally-derived pressure volume loops and systemic vascular resistance

抄録

動脈波形とフォトプレチスモグラフィ（PPG）波形は、脈波輪郭から一回拍出量を非侵襲的に推定するために利用されてきた。これらの脈波輪郭装置が一回拍出量を正確に予測する能力は、後負荷が有意に変化すると低下する。血管トーヌスがいつ変化したかを同定できる非侵襲的装置が必要である。Shelley らは以前、末梢の圧容積（PV）ループ（動脈内カテーテルからの圧波形を PPG 波形からの容積波形と組み合わせたもの）と血管トーヌスの変化との定性的な関係を記述した。本研究の目的は、大手術を受ける患者集団において、末梢 PV ループの面積の変化と全身血管抵抗（SVR）の変化を定量的に比較することであった。肝移植を受ける10名の患者の生理学的データを血行動態データベースから抽出した。動脈波形と PPG 波形の両方にピーク検出アルゴリズムを適用し、谷が同一の時点で生じるよう手動で位置合わせした。各心拍について PV ループ面積（PVA）を算出し、各分について PVA の中央値を記録した。各患者の PVA は最初の5分間の平均値に対して指数化し（PPG 振幅には標準がなく患者間で比較できないため）、SVR が利用可能なすべての時点における指数化 SVR と比較した。SVR と PVA を時間の関数としてプロットし、外れ値（3.1%）を除去した。PVAi と SVRi の関係を記述する Pearson 相関係数は 0.67（1728分のデータ、p = 0.0020、10名の患者にわたる符号検定）、MAP と SVR の間では 0.71 であった。ΔSVR と ΔPVA あるいは ΔMAP のいずれとの間にも（分ごとの変化に基づく）意味のある相関はなかった。PVA の指数化値は SVR の指数化値と相関し、後負荷の変化についての有用なモニタとなりうるが、現在の形では MAP の測定を上回る付加価値を提供しない。異なる部位（たとえば指、額）や冗長な部位（たとえば両側）を組み込むことで、この手法の正確性が有意に改善する可能性がある。

キーワード　モニタリング・後負荷・フォトプレチスモグラフィ・血管トーヌス・コンプライアンス・非侵襲的

1　序論

心拍出量と一回拍出量は、目標指向型治療レジメンの一般的なエンドポイントである [1, 2]。近年、低侵襲あるいは非侵襲的な心拍出量モニタの開発に大きな関心が寄せられている [3]。動脈波形の形状に基づいて一回拍出量を測定しようとする脈波輪郭装置 [4] は広く用いられている。残念ながら、非較正の脈波輪郭装置は較正されたものより正確性が劣ると考えられ [5, 6]、その正確性は負荷条件が変化すると低下すると考えられる [7]。現在利用可能な較正済み脈波輪郭装置は、リチウム希釈法あるいは経肺熱希釈法のいずれかを必要とし、そのいずれも間欠的に実施される。したがって、血管抵抗の連続モニタが必要である。

フォトプレチスモグラフィ（PPG）波形の形状は、被検組織の容積変化（それが赤色および赤外スペクトルの電磁放射の吸光度に影響する）に対する応答である。したがって、末梢組織の血液量の変化は PPG 波形の検討によって解析できる。Shelley ら [8] は以前、PPG 波形と動脈圧波形を同じグラフ上にプロットして末梢の圧「容積」ループを作成し、そうすることで PVA と血管トーヌスの変化の間の定性的な関係を発見した。本研究の目的は、末梢 PVA と全身血管抵抗（SVR）の関係を定量的に記述することであった。

2　方法

本研究はバージニア大学の施設審査委員会（Health Sciences Research）の承認を得た。肝移植を受ける10名の患者の生理学的データを、一回拍出量を測定する脈波輪郭法を開発するために当初作成された血行動態データベースから抽出した（表1）。

2.1　データ収集

血行動態波形データベースのデータは、患者と麻酔科医が使用するトランスデューサの間に配置した追加の圧トランスデューサ（Transpac®, ICU Medical, San Clemente, CA）の電圧出力を記録することにより収集した。電圧と圧の関係は、実験室で Omega Engineering（Stamford, CT）DPI 605 圧力校正器を用いて測定した。このシステムの共振周波数は、in vivo で試験したとき 35 Hz であった [9]。電圧データは National Instruments USB-9239 アナログ入力モジュール（National Instruments, Austin, TX）により 2000 Hz で収集し、ローパスフィルタ処理（50 Hz カットオフ）を行い、保存のため 200 Hz にダウンサンプリングし、線形補間を用いて解析のため 75 Hz に変換した。

赤外吸光度波形は、耳に装着した Nonin（Nonin Medical, Plymouth MN）OEM III オキシメータから収集した。Nonin OEM III は16ビット分解能を提供し、75 Hz でサンプリングする。標準的な指プローブと比較して末梢血管トーヌスの変化の影響を受けにくいため、耳が選択された [10, 11]。

当施設の標準的診療として、CCOmbo 肺動脈カテーテル（Edwards Lifesciences, Irvine, CA）を、全身麻酔導入後・手術切開前に右内頸静脈に留置したマルチアクセスカテーテルを通じて進め、その出力を1分間隔で麻酔情報管理システム（AIMS）にエクスポートした。

2.2　アルゴリズム

著者の一人（DAC）が MATLAB（Mathworks, Natick, MA）で作成したピーク・谷検出アルゴリズムを、動脈波形と PPG 波形の両方に適用した。2つの波形は、谷が同一の時点で生じるよう手動で位置合わせした（これは、波形を照合するための心電図同期が利用できなかったため必要であり、圧と容積の変化がほぼ同時に生じるという仮定に基づく。ドリフトの可能性を除くため、位置合わせは毎分実施した）。1心拍にわたる PV 面積（PVA）は、谷から開始し台形法を用いて算出した。

PVA = Σ ± 0.5 × (Pi+1 + Pi) × (Ai+1 − Ai)

ここで Px は圧、Ax は吸光度を表し（図1）、± は吸光度が増加している（+）か減少している（−）かによって決まる。各分について PVA の中央値を算出した。PPG 吸光度は各患者に固有であり患者間で比較できないため、各患者の PVA は、各時点における PVA を記録データの最初の5分間の平均 PVA（PVA1–5）で割ることにより、（肺動脈カテーテル留置後の）最初の5分間の平均値に対して指数化した。SVR も同様に指数化した（指数化 SVR = [SVR時刻 = t]/[SVR1–5]）。SVR と PVA を時間の関数としてプロットし、外れ値を除去した。

図1　PVA の算出。明るい色の領域は減算され、暗い領域は加算される（図示のため、信号は 75 Hz から 15 Hz にダウンサンプリングされていることに注意）。

2.3　統計解析

指数化 PVA（PVAi）と指数化 SVR（SVRi）は、当初線形回帰を用いて比較した。データが反復測定の性質をもつため、データの独立性は仮定できなかった。データの時間依存性を検定したところ、PVA と SVR の双方が実質的な系列相関を示した。したがって、最良適合線（すべての患者のすべてのデータ点を含む）の傾きがゼロでない確率を、伝統的な手法で推定することはできなかった。

データの時間依存的な性質にもかかわらず、異なる患者からの標本は独立と仮定できる。したがって我々の解析は、10名の患者にわたって最良適合線を比較することによって進められた。帰無仮説（PVAi と SVRi の間の相関が 0 であること）を、符号検定を用いて両側対立仮説に対して検定した。追加の仮定を必要としないため符号検定が選択された。

ΔPVAi のトレンド追従能を評価するため、ΔPVAi と ΔSVRi を1分、5分、10分の間隔で比較した。最後に、PVAi と SVRi の間の一致限界を算出するため、反復測定 Bland–Altman 法を用いた [12, 13]。異なるレベルの血管収縮における本手法の信頼性を検討するため、等しい大きさの3分位（低、中、高の SVRi）について解析を繰り返した。

3　結果

10名の患者から1728分のデータが利用可能であった。1分間で 50% 増加したデータ点を除去するフィルタを適用した結果、54の外れ値（データ点の 3.13%）が除去された。PVAi と SVRi の関係を記述する Pearson 相関係数は 0.67 であり（図2）、最良適合線は以下のとおりであった。

SVRi = 1.2121(PVAi) − 0.1154

比較として、平均動脈圧と SVR の関係を記述する Pearson 相関係数は 0.71 であった。個別の散布図を図3に示す。各被験者について PVAi と SVRi を時間の関数としてプロットしたものを図4に示す。個人レベルでは、PVAi と SVRi の相関は 0.3453（患者8）から 0.8369（患者9）にわたった。これらの値により、PVA と SVR の間の相関が 0 であるという仮説を両側対立仮説に対して検定することができた。得られた（符号検定に基づく）p 値は 0.0020 であり、観察された相関が強く統計学的に有意であることを示した。

4　考察

我々は初めて、フォトプレチスモグラフィから導出される圧容積ループの面積（PVAi）と血管トーヌスの定量的指標（SVRi）の間の統計学的に有意な相関を示した。長時間（5〜10分）にわたって、SVRi と PVAi は同じ方向に動くと考えられる。しかしながら、臨床的有用性についての Critchley の広く受け入れられた 30% の精度という閾値に基づけば、SVRi と PVAi の間の一致が不良であることが、現在の形での PVAi を血管運動トーヌスの信頼できる指標として使用することを妨げている。加えて、PVAi と SVRi の関係は MAP と SVR の関係より優れてはいなかったが（PVAi を単独で測定することに付加価値がないことを示唆する）、PVAi と MAPi の間の相関はとくに弱く（r = 0.50）、両者を組み合わせることで SVR を非侵襲的に予測する能力が改善しうることを示唆している。

Shelley ら [8] は以前、直接作用型血管収縮薬であるフェニレフリンの投与後に PPG 由来の圧容積ループに生じる定性的変化を記述した。PVA はこの論文において PV ループ形態の「重要な特徴」として言及され（そしてより最近には血管コンプライアンスと定性的に関連することが認識されている [15]）ているが、正式に算出されて SVR と比較されたことはなかった。とはいえ、Shelley の論文の図1、2、6を検討すると、フェニレフリン投与後の PVA の増加が明瞭に示されている。我々も同じ現象を観察した（図1）。なお、我々の位置合わせ手法（谷の検出と位置合わせに基づく）は、PPG 信号からの 25 ms の処理遅延を仮定した Shelley らのアプローチとは異なっていた。これが、Shelley らが「フィッシュテール（fishtail）」現象を観察したのに対し、我々が観察しなかった理由を説明する。

指の PPG 振幅が血管トーヌスの増加とともに低下することは知られているが、PVA は容積の変化と圧の変化の双方の関数である。容積変化の減少（たとえば極度の血管収縮の際に生じるような）は、脈圧の増加によって相殺されない場合にのみ PVA の減少をもたらす。両者の関係は複雑であり、単に ΔV/ΔP として適切に記述することはできない。むしろ、血管運動トーヌスの変化によって誘発される PPG 波形と動脈圧波形の双方の形状の変化を完全に説明するには、PV ループ全体にわたる積分が必要である。血管収縮に対する異なる組織床の応答の違いが、この現象をさらに説明しうる。すなわち、神経支配の豊富な組織（たとえば指）から血液が移動するにつれて、交感神経刺激への反応性が低い血管床（たとえば耳）へ移行し、PVA の増加をもたらしうる [10]。

図3、4、6を検討すると、単一部位（耳）から導出される PPG に基づく PVA は、血管運動トーヌスの臨床モニタとして使用するには十分な信頼性がないことが示唆される。とくに、PVA の予測能には個人差が大きいと考えられる。これらは抵抗、動脈あるいは静脈のトーヌス、温度、プローブ位置、あるいは他の未解明の現象の違いによるかもしれない。

いくつかの単純な改善によって本手法の臨床的有用性が高まるかもしれない。第1に、パルスオキシメータのプローブは日常の麻酔管理や ICU ケアの間に不用意に動かされることがある。複数のプローブ（たとえば両側の耳プローブ）を用いて出力を平均することで、結果の安定性が改善するかもしれない。耳に加えて、独特の血管運動特性をもつ追加の部位（たとえば額、指。いずれも指とは異なる形態をもつ）を含めることで、血管運動トーヌスの変化を検出する PVA の能力が改善するかもしれない。最後に、現在のパルスオキシメータのノイズ除去アルゴリズムは誤った SpO2 の読み値を最小化するよう設計されているが、誤った PVA の読み値も除去するよう修正することが可能であろう。

本論文で記述した PVA が臨床使用に対して明らかに準備が整っていない一方で、その可能性については楽観的である理由がある。図4を検討すると、PVAi が SVRi を著しくよく追従している時間帯が明瞭に示されている。PVAi が時に SVRi を追従できない理由（たとえば体動アーチファクト、信号処理）を明らかにすることが、この技術の発展における重要な次の段階である。

末期肝不全の血管拡張作用が我々の知見の一般化可能性を制限しており、血管トーヌスが一般集団により近い心臓外科患者における今後の研究が計画されている。本研究の他の限界には、（これらの患者のモニタリングに用いた TRAM システムのアナログ出力の制限のため）指から PPG 情報を抽出できなかったこと、ゴールドスタンダードとして連続心拍出量モニタを用いたこと（間欠的熱希釈法のほうがより正確でありラグが少ないかもしれない [16]。ただしこれは装置に依存する [17]）、そして PPG 波形と動脈波形の測定に2つの別々の記録システムを必要としたこと（谷の位置合わせを必要とし、血管トーヌスにも関係する脈波伝播時間の測定を複雑にする [18]）が含まれる。

統計解析に関して——反復測定データの関係を記述する相関係数は、被験者内相関と被験者間相関の両方の関数である。被験者内と被験者間の一致を分離するために特別に設計された反復測定 Bland–Altman 法 [13] とは異なり、回帰分析ではこれら2つの現象を数学的に分離できない。我々の回帰分析は、被験者間の一致（あるいは相関）が被験者内の一致より顕著であることを示唆しており、PVAi の変化と SVRi の変化（これらは定義上、被験者内で測定される）の間の相関が不良であることの可能な説明を提供する。

5　結論

PPG 波形と動脈圧波形から導出される平均動脈圧と PVA の変化は、肝移植を受ける患者において肺動脈カテーテルで測定される SVR の変化と有意に相関する。しかしながら、MAP に（現在の形での）PVAi を加えても、臨床医が SVRi を非侵襲的に推定する能力は向上しない。代替部位の追加、信号処理アルゴリズムの実装、そして（心電図トレースの利用可能性に基づく）正確な位相の位置合わせが、患者を医原性の合併症のリスクに曝すことなく臨床医に SVR の連続モニタを提供しうるかどうかを判定するには、追加の研究が必要である。

要旨（Summary）

パルスオキシメトリは、酸素化を連続的・正確かつ非侵襲的にモニタする能力に革命をもたらした。その普遍的な使用にもかかわらず、多くの医療従事者がその機能の機序の背後にある基本原理を知らないというのが我々の印象であり、また研究によっても裏づけられている。この知識は重要である。なぜならそれは、その限界を把握し、パルスオキシメータの読み値が誤りでありうる場合を認識するための概念的基礎を提供するからである。本総説では、パルスオキシメータがどのようにして酸素化ヘモグロビンを脱酸素化ヘモグロビンから区別できるのか、そしてどのようにして血液の動脈成分のみから酸素飽和度を認識できるのかを論じる。これらの原理に基づいて、誤った読み値を引き起こしうる種々の状態と、その基礎にある機序を論じる。

機能の基本原理

パルスオキシメータは、動脈血中ヘモグロビンの機能的酸素飽和度（SaO2）を連続的かつ経皮的にモニタできる能力によって、現代医学に革命をもたらした。パルスオキシメトリは医療において非常に広く普及しており、しばしば第5のバイタルサインとみなされる（文献 1）。誤った読み値は不必要な検査につながりうるため（文献 2）、この技術がどのように機能するか、およびその限界を理解することが重要である。集中治療室における頻繁な偽アラームもまた、介護者の注意をそらすことによって患者安全を損ないうる。パルスオキシメータによる酸素飽和度の読み値（SpO2）が真の SaO2 の誤った推定をもたらしうる状況を認識するには、パルスオキシメトリの2つの基本原理を理解することが必要である。すなわち、(i) オキシヘモグロビン（O2Hb）がどのようにデオキシヘモグロビン（HHb）から区別されるか、(ii) SpO2 がどのようにして血液の動脈成分のみから算出されるか、である。

パルスオキシメトリは、O2Hb と HHb が赤色光と近赤外（IR）光を異なる程度に吸収するという原理に基づいている。O2Hb と HHb が赤色光と近赤外光において吸収に有意な差をもつことは幸運である。なぜならこれら2つの波長は組織をよく透過するのに対し、青色、緑色、黄色、遠赤外の光は非血管性組織と水によって著しく吸収されるからである（文献 3）。O2Hb は HHb より多くの IR 光を吸収し、より少ない赤色光を吸収する。これは経験と一致する。すなわち、O2Hb 濃度が高くよく酸素化された血液は、HHb より多くの赤色光を散乱するため、目には鮮紅色に見える。他方、HHb はより多くの赤色光を吸収し、赤みが少なく見える。O2Hb と HHb の間のこの光吸収特性の差を利用して、パルスオキシメータは指プローブの一方のアームに配置された一対の小さな発光ダイオードから、660 nm の赤色光と 940 nm の近赤外光の2波長を放射する。指を透過した光は、プローブの反対側のアームにあるフォトダイオードによって検出される。すなわち、赤色光と IR 光の吸収される相対量が、パルスオキシメータによって最終的に酸素と結合した Hb の割合を決定するために用いられる。

パルスオキシメトリが動脈血のみの SpO2 を検出できる能力は、動脈血液量が収縮期に増加し拡張期に減少するため、吸収される赤色光と IR 光の量が心周期とともに変動するという原理に基づいている。これに対し、静脈と毛細血管内の血液量、ならびに皮膚、脂肪、骨などの体積は比較的一定に保たれる。吸収されずに組織を通過した光の一部はプローブの光検出器に到達し、それに応じて、比較的安定で非拍動性の「直流（DC）」成分と拍動性の「交流（AC）」成分をもつ信号を生成する（図1A）。収縮期と拡張期における動脈と静脈の断面図は、動脈の非拍動性（DC）成分と拍動性（AC）成分、ならびに静脈と毛細血管における容積変化の相対的な欠如を図示している（図1B）。パルスオキシメータは吸光度の振幅を用いて赤色：赤外変調比（Red:IR Modulation Ratio, R）を算出する（文献 4）。すなわち、

R = (Ared,AC/Ared,DC) / (AIR,AC/AIR,DC)

ここで A = 吸光度である。言い換えれば、R は赤色光吸収の拍動性成分と非拍動性成分の比を、IR 光吸収のそれで割った二重比である。動脈血酸素飽和度が低く HHb が増加している場合、脈波による赤色光吸光度の振幅の相対的変化は IR 吸光度のそれより大きく、すなわち Ared,AC > AIR,AC となり、より高い R 値をもたらす。逆に、酸素飽和度が高い場合には AIR,AC > Ared,AC となり、R 値はより低くなる（図1C）。パルスオキシメータのマイクロプロセッサは、この比（一連の脈波にわたって算出される）を用いて、健常ボランティアにおいて飽和度を 100% からおよそ 70% まで変化させて R を測定することにより経験的に作成された較正曲線に基づいて SpO2 を決定する（文献 5）（図1C）。したがって 70% 未満の SpO2 の読み値は定量的に信頼できるとみなすべきではない。ただし、70% 未満で測定される SpO2 の差に基づいて臨床判断が変更されることはまずないであろう（文献 3, 6）。

パルスオキシメータがどのようにして静脈血・毛細血管血およびその他の静止組織の影響を SpO2 の算出から除外するかは、吸光度の Beer–Lambert の法則を検討することによって概念的に理解できる。モデル化された血管に適用される Beer–Lambert の法則によれば、A = εbc である。ここで A = 吸光度、ε = 特定の波長におけるヘモグロビンの吸収（吸光）係数（O2Hb と HHb の係数の組み合わせ）、b = 放射された光が血管を通って進む光路長、c = Hb の濃度である。絶対吸光度を単に測定するだけでは、静脈血中の上昇した HHb レベルも測定値に寄与するため、動脈の SpO2 の推定として不正確であろう。しかしながら、パルスオキシメータは吸光度の経時的変化を測定することによって動脈の SpO2 のみを決定できる。この概念を数学的に説明すると、全吸光度（At）は静脈（Av）と動脈（Aa）の吸光度の線形結合と考えることができる（At = Av + Aa = εvbvcv + εabaca）。パルスオキシメータは吸光度を時間に対して測定するので、前式の導関数は dAt/dt = d(εvbvcv)/dt + d(εabaca)/dt となる。ε と c は定数である（ε は光の波長によって変わりうるが、特定の波長と Hb 種については定数であることに注意）ので、前式は dAt/dt = (dbv/dt)(εvcv) + (dba/dt)(εaca) と単純化される。動脈は静脈よりはるかに大きく拡張・収縮するので、すなわち ba の変化 ≫ bv の変化（dba/dt ≫ dbv/dt）であるから、bv を定数、dbv/dt = 0 と仮定できる。したがって前式は dAt/dt = (dba/dt)(εaca)、あるいは同等に ΔAt = ΔAa と単純化される。言い換えれば、測定される At の変化 = 動脈血成分による吸光度の変化であり、静脈血の寄与はほとんどないか皆無である。したがって、パルスオキシメータが機能するには十分な脈波が必要であり、これは血液灌流がほとんどないか皆無の領域で SpO2 を測定しようとすると読み値が得られないか不正確になるという、よく知られた事実の基礎となっている（文献 4）。これらの原理は、以下でさらに論じるように、パルスオキシメトリの特定の挙動を説明するのに役立てることができる。

異なる種類のパルスオキシメータ・プローブの長所と短所

パルスオキシメータのプローブが指、鼻、耳垂、額を対象とする理由は、これらの部位の皮膚が、たとえば胸壁の皮膚よりもはるかに高い血管密度をもつからである（文献 4）。再使用可能なクリップ型プローブ（指、鼻、耳）と単一患者用の粘着型プローブ（指、額）が、パルスオキシメータ・プローブの2つの主要な種類である。再使用可能なクリップ型プローブの利点は、迅速に装着できること、低振幅波の場合に異なる身体部位を容易にサンプリングできること、そして SpO2 の測定が1回だけでよいため1つのプローブで複数の患者を順次測定できる外来環境における費用対効果である。単一患者用粘着型プローブの利点は、院内感染の伝播が少ない可能性、患者の体動が過度な場合のより確実な装着、そして四肢末端部以外の部位をモニタできることである。後者の部位は血管収縮に対してより脆弱だからである。したがって、SpO2 の連続モニタリングには、臨床状況に応じて特定の種類のプローブが他より適切でありうる。すなわち、最適なプローブを見つけるにはある程度の「試行錯誤」が必要かもしれない。たとえば、低血圧で血管収縮した患者では、耳と額のプローブがより信頼できるかもしれない。これらの部位は内因性・外因性のカテコールアミンに応答して指ほど血管収縮しにくいからである（文献 3, 7）。二次的な血管収縮を伴う低体温では、額のプローブが指のプローブより信頼できることが示されている（文献 8, 9）。

プローブの種類を最適化した後でも、種々の状況や医学的状態において SpO2 の誤った読み値が生じうる。以下の節では、信頼できない SpO2 の読み値の原因と機序を論じ、表1にまとめる。最後に、動脈血酸素飽和度の測定において SpO2 が実際には SaO2 の読み値よりも信頼できるという、よりまれな事例についての議論で締めくくる。

間欠的なドロップアウトあるいは SpO2 読み取り不能の原因

集中治療室のモニタに表示されるパルスオキシメータの波形が減衰したり一定しなかったりすることが、SpO2 の読み値が信頼できない、あるいは信頼できなくなりうることの徴候であるのは周知の事実である。すなわち、ドロップアウトの増加や偽の一過性 SpO2 変化である。そのようなパルスオキシメータ波形の振幅は、心電図上の QRS 波の開始とパルスオキシメトリ波形の陽性偏位の開始がほぼ同時であることに示されるように、心臓によって誘発される光変調の量を反映している（図1A）。携帯型パルスオキシメータは通常そのような波形をもたないが、しばしば光吸収の変化のレベル（したがって脈波の強さ）を示す脈波信号バーを備えており、最適でない読み値の可能性を示す。

低振幅のパルスオキシメトリ波形は、血液分布異常性ショックや循環血液量減少性ショック、低体温、血管収縮薬の使用、ポンプ失調や不整脈による心拍出量低下など、多数の原因による血管収縮および／または低血圧に起因する指の灌流不良によって生じうる。動脈の圧迫（たとえば加圧された血圧計）やプローブ装着部位より近位の動脈の閉塞（たとえば末梢血管疾患）も、パルスオキシメトリ波形の不良をもたらしうる。動脈血信号における脈波振幅の低下は、さらにパルスオキシメータの信号対雑音比を低下させ、値を表示できないこと、間欠的なドロップアウトとアラーム、および不安定な SpO2 読み値をもたらしうる。前述の状態が誤った SpO2 読み値をもたらしうることを知っておくことが、偽性に低い SpO2 読み値を受け入れてしまうことに対する最良の抑止力である。臨床的評価は偽の SpO2 読み値と真の読み値の鑑別に役立つが、不確実な症例は動脈血液ガス分析によって裏づけられるべきである。

SpO2 が偽性に正常あるいは上昇する原因

一酸化炭素中毒

一酸化炭素（CO）は無臭・無色・無味で非刺激性の気体である。CO 中毒の患者は非特異的な徴候・症状（たとえば頭痛）、他の疾患を模倣する症状（たとえば食中毒、アルコール中毒、急性精神科的破綻、あるいは「インフルエンザ様症状」）、あるいは CO 毒性によって誘発される真の疾患（たとえば狭心症、失神）を呈しうるため、潜在的な曝露では診断がしばしば見逃される。CO 毒性は、プロパンエンジン、天然ガス、自動車排気、可搬型発電機、ガスログ暖炉、灯油ストーブ、火災の煙、そしてこれらの製品に含まれるジクロロメタンが CO に代謝されることによる塗料剥離剤やスプレー塗料など、種々の発生源からの曝露に起因しうる。CO 中毒の主要な病因機序は、CO の Hb に対する強い親和性（O2 の240倍）であり、カルボキシ Hb（COHb）を形成して Hb の O2 運搬能を低下させ、組織の低酸素症を招く。CO はまたミオグロビンとミトコンドリアの機能を障害し、血管拡張と低血圧をもたらしうるグアニル酸シクラーゼの活性化を増加させ、微小血管障害と再灌流障害を引き起こす脂質過酸化を増強しうる。

CO 中毒の可能性を鑑別診断に含めることが、病的な患者においてその存在を認識するための要であるが、診断は客観的になされなければならない。O2Hb と COHb は赤色光（660 nm）を同様に吸収し、COHb は近赤外光（940 nm）をほとんど吸収しないため（図2）、赤色光と近赤外光しか放射しない標準的なパルスオキシメータのフォトダイオードは、O2Hb と COHb を区別できない。O2Hb と COHb の赤色光に対する類似した吸収特性は、カルボキシヘモグロビン血症の患者が鮮紅色に見えチアノーゼを呈さないという臨床的観察と一致する（文献 10）。R の文脈では、COHb は HHb と O2Hb の両方の濃度を減少させるため、通常より大きい HHb による赤色光吸収は減少するが、O2Hb と COHb を合わせた種による赤色光吸収は維持されるかわずかに増加する。しかしながら、HHb は COHb や O2Hb のいずれよりも赤色光をよく吸収するため、カルボキシヘモグロビン血症の存在下での HHb の減少は、赤色光吸収の減少と、予測されるより大きな R の低下という正味の効果をもたらし（図1C を参照）、その結果 SpO2 は分画的 O2Hb 含量（FO2Hb）を過大評価することになる。FO2Hb もコオキシメータによって測定されるが、SaO2 とは対照的に COHb 濃度を考慮に入れる。したがって、有意なカルボキシヘモグロビン血症では、標準的なパルスオキシメータは、実際には FO2Hb が低いにもかかわらず偽性に正常（あるいは上昇した）SpO2 を示しうる。用語上、COHb によって低下するのは SaO2 ではなく FO2Hb 含量であることを強調することが重要である（Box 1 を参照）。パルスオキシメータが O2Hb と HHb に加えて COHb も検出できるようにするには、少なくとも3つの異なる波長の光ビームをもつ機器を用いる必要があるだろう（文献 10）。そのような機器は存在するが、広くは利用できない。

鎌状赤血球貧血の血管閉塞性発作

血管閉塞性発作や急性胸部症候群といった鎌状赤血球症の合併症は、しばしば低酸素血症によって誘発あるいは増悪され、さらなる鎌状化と血管閉塞性発作の悪循環をもたらしうる（文献 11）。したがって、これらの患者における低酸素血症の正確な検出は、赤血球のさらなる鎌状化を軽減するうえで重要な役割を果たす。鎌状赤血球症における酸素化モニタリングにおけるパルスオキシメトリの正確性については議論がある。鎌状赤血球症の患者17名を対象とした研究では、SpO2 は FO2Hb 含量を平均 3.4% 過大評価し、SaO2 を平均 1.1% 過小評価することが見出された（文献 12）。しかしながら、これらのパルスオキシメータ読み値のわずかなバイアスは、正常酸素血症あるいは低酸素血症のいずれの誤診にもつながらなかった。同様に、鎌状赤血球症の患者24名の研究では、SpO2 が SaO2 の読み値を 1.6% 過小評価すると判定された。この差は臨床的に有意ではなかった（文献 13）。しかしながら著者らは、鎌状赤血球症において SpO2 は SaO2 の正確な表現として使用できるものの、FO2Hb のほうがより有用な測定値でありうると述べている。鎌状赤血球症の一部の人では COHb が上昇していることがあるからである（後述するように、ヘムのビリルビンと CO への代謝による）。これらの場合、Box 1 で論じるように SpO2 は FO2Hb を過大評価する。他の研究はさらに、SpO2 による FO2Hb の過大評価と SaO2 の過小評価が血管閉塞性発作の際により顕著になることを示唆している（文献 14, 15）。

Box 1. 分画的 O2Hb 含量と SaO2 の違い

血液ガス分析において、文献ではしばしば機能的 SaO2 と表記される SaO2 は、[O2Hb]/([O2Hb] + [HHb]) と定義される。この式に基づけば、COHb のような異常ヘモグロビンの存在は SaO2 に影響しないはずである。したがって、機能的 SaO2 が COHb によって低下すると述べるのは正しくない。むしろ COHb によって低下するのは分画的 O2Hb 含量（しばしば FO2Hb と略される）、すなわち分画的 SaO2 とも呼ばれるものである。なぜなら FO2Hb = [O2Hb]/([O2Hb] + [HHb] + [COHb] + [MetHb]) であり、[MetHb] = 血中メトヘモグロビン濃度だからである。コオキシメータの報告には通常、「SaO2」（機能的 SaO2 の意）と FO2Hb（分画的 SaO2 の意。ただし混同を避けるため分画的 O2Hb 含量という用語が用いられる）の両方が含まれる。したがって、機能的 SaO2 と SpO2 はいずれも COHb によってごくわずかしか影響されず、COHb が 40% に至っても同様である（文献 54）。実験動物における CO 曝露の研究では、同時の COHb 値が 70%、FO2Hb 飽和度が 30% であったときに、SpO2 レベル 90% が記録された（文献 55）。したがって、有意な CO 中毒であっても、機能的 SaO2 と SpO2 はいずれも酸素化について「偽性に正常」との指標を与える一方、FO2Hb によって示される Hb の O2 運搬能は憂慮すべきほど低下している。SaO2 と FO2Hb のこの区別は図3に模式的に図示されており、高度の貧血患者が正常な SaO2 をもつからといって血中の O2 運搬能が十分であると誤って結論することと類似している。

鎌状赤血球症患者における酸素飽和度の判定に関するもう1つの重要な注意点は、HbS の重合がほとんどない正常酸素条件下では、HbS の酸素親和性は正常な HbA と同様であることである。しかしながら、低酸素血症を含む鎌状化を誘発する条件の存在下では、HbS は酸素への親和性が低くなり、酸素-Hb 解離曲線は右方に偏位する。すなわち、任意の PaO2 に対して SaO2 はより低くなる（文献 16, 17）。目的論的には、この偏位は組織への酸素供給を増加させるうえで有利である。

SpO2 が偽性に低下する原因

静脈拍動

各心周期で静脈容積の有意な変化を引き起こす静脈拍動は、静脈の O2Hb 飽和度（SvO2）もパルスオキシメータによって測定されることになり、動脈飽和度を人為的に低下させるため、偽性に低い SpO2 読み値に寄与しうる。静脈拍動は、粘着型の指プローブが指の周りにきつく装着されすぎた場合、高度の三尖弁逆流において、プローブの位置が下垂位にある場合（たとえば患者がトレンデレンブルグ位で額にプローブを装着している場合）、そしておそらく広範な血管拡張が生理学的な動静脈シャントをもたらす血液分布異常性ショックにおいて生じうる（文献 18, 19）。仰臥位あるいはトレンデレンブルグ位を要する患者において額のセンサで静脈拍動が生じていると考えられる場合、額のセンサに弾性のヘッドバンドを適用することで、偽性に低い SpO2 読み値の発生を有意に減らすことができる（文献 20）。

過度の体動

振戦や痙攣といった過度の体動は、偽性に低い SpO2 を引き起こすことが記録されており、時に 50% 未満の飽和度低下が観察される（文献 21, 22）。ただし、より頻度は低いが SpO2 の過大評価も生じうる。理論的には、体動によって、センサ位置に対して通常静止している組織が動脈の脈波の時間枠で変化しうる。時にこの体動は、静脈内の血液（および以前は静止していた他の組織）が動くことで心臓由来の信号を増強あるいは模倣し、被検組織における赤色光と IR 光の減衰をさらに変調しうる（Box 2 を参照）。しかしながら、多くの新世代のパルスオキシメータは、患者の過度の体動による誤った SpO2 読み値の発生を減らす改良された処理アルゴリズムを備えている（文献 21, 22）。

Box 2. 呼吸困難を伴わない極端に低い SpO2

93歳の男性が、胃腸炎のエピソードの後に非 ST 上昇型心筋梗塞のため入院した。彼は自立して生活し、自分で買い物をし、問題なく車を運転していた。生涯非喫煙者であり、週に1本のビールを飲んでいた。既往歴として本態性振戦、甲状腺機能低下症、前立腺肥大症、透析未導入の慢性腎臓病ステージ4、緑内障、および3年前の静脈血栓塞栓症が特筆される。診察では急性の苦痛はなく、実年齢よりはるかに若く見えた。体温 97.1 °F、脈拍 80/分、血圧 125/60 mmHg、呼吸数 16/分、ベースラインの酸素 2 L/分投与下で SpO2 93% であった。診察上は軽度の安静時手指振戦のみが特筆された。

彼はジピリダモール-99mTc-セスタミビ核医学灌流検査を受けた。負荷検査から病室に戻った際、看護学生が壁掛け型パルスオキシメータを用いて測定したバイタルサインでは、脈拍数 228/分、SpO2 73% であった。彼はフェイスマスクによる高流量酸素投与とされ、迅速対応医療チームが招集された。SpO2 が持続して低いため、非再呼吸マスクで 100% 酸素投与としたが、SpO2 は 40〜70% のままで、モニタ上の心拍数は 200/分を超えたままであった。測定された血圧は 135/80 mmHg であった。彼は胸痛も呼吸の変化も否定した。不安そうに見えたがチアノーゼはなかった。肺は聴診上清明であった。心電図のリズムストリップが記録され、ベースラインの心拍数 60/分と、QRS 波の間の小さなスパイク（II 誘導で最もよく見える）が示された（図4）。これらの低電位スパイクは彼の手指振戦によるもので、指プローブで測定された SpO2 は手指振戦のため偽性に低いと考えられた。この推定は、オキシメータによる脈拍の読み値 200/分が心電図上の振戦の頻度と類似していたという観察と一致していた。プローブを額に装着した別のパルスオキシメータを用いると、脈拍数は 65/分、同時の SpO2 は非再呼吸マスクによる高流量酸素吸入下で 100% であった。確認のため、100% 非再呼吸マスク下で得られた動脈血液ガスでは pH 7.36、PaCO2 41 mmHg、PaO2 302 mmHg、SaO2 100% であった。動脈血液ガスが採取された時点で、指プローブを用いた同時の SpO2 の読み値は 48% であった。振り返ってみれば、心拍の聴診および／または橈骨動脈の触知により心拍数が 200/分を超えていないことが分かれば、SpO2 のパルスオキシメトリ読み値が不正確であることを速やかに示せたであろう。

静注色素

色素は医療的に、あるいは種々の医学的診断検査における試薬として用いられる。たとえばメチレンブルーの主要な医薬用途はメトヘモグロビン血症であり、そこでは還元剤として作用する。メチレンブルーはまた、内視鏡的ポリープ切除術において、切除するポリープ周囲の粘膜下層に注入して、追加の組織切除が必要になった場合に備えて部位を標識する色素としても用いられてきた。インジゴカルミン（FD&C Blue#2）系色素は、羊水漏出の検出や、手術中の尿路系の漏出の検出に、静注インジゴカルミンが腎臓から速やかに排泄されることを利用して、まれに用いられる。イオドシアニングリーンは、肝機能と肝血流の判定や眼科的血管造影など、種々の医学的診断検査に用いられる。

メチレンブルーの吸収ピークは 668 nm（図5）であり、HHb による強い赤色光吸収に非常に近く、より高い R 値をもたらして HHb を模倣する（文献 23）。したがって、メチレンブルーを血流に投与すると SpO2 の読み値が偽性に低下しうる。ベースライン SpO2 が正常（〜97%）のヒトボランティアにおいて、1% メチレンブルー 5 mL の静注投与後に SpO2 の著明な低下が生じ、SpO2 最低値の中央値は 65% であったが、被験者間で SpO2 低下の幅は広かった（文献 23）。インドシアニングリーンとインジゴカルミンは赤色光に対してそれほど大きな吸収をもたない（図5）。これは、インドシアニングリーンの静注では指プローブを用いた SpO2 の低下が 〜3〜4% とわずかであり、インジゴカルミンの静注では SpO2 にほとんどあるいはまったく変化がなかったという知見と一致する（文献 23）。

遺伝性の異常ヘモグロビン

まれな Hb 変異体が偽性に低下した SpO2 読み値を引き起こすことが報告されており、Hb Lansing（文献 24）、Hb Bonn（文献 25）、Hb Köln（文献 26, 27）、Hb Hammersmith（文献 28）、Hb Cheverly（文献 29）が含まれる。Sarikonda ら（文献 24）は、総 Hb の約 11% を占める異常 Hb 変異体（Hb Lansing）のために SpO2 の読み値が SaO2 の測定値より 10% 以上低かった父娘を報告した。酸素親和性の評価は正常であり、赤色光および／または近赤外光の吸光度に対する異常 Hb による干渉が SpO2 の偽性低下の原因であることが示唆された（文献 24）。ALPHA-Hb 遺伝子の変異によりヒスチジンからアスパラギン酸への置換を生じた（Hb Bonn）父子が、偽性に低い SpO2 を呈したと報告されている（文献 25）。Hb Bonn は 668 nm（メチレンブルーと同じ）に吸収ピークをもつことが見出され、これは赤色光の波長 660 nm に非常に近い（文献 25）。したがって R の文脈では、Hb Bonn は赤色光吸収の増強を引き起こし、R 値の上昇と SpO2 測定値の低下をもたらす。言い換えれば、Hb Bonn は HHb やメチレンブルーのように振る舞う。同様に、Hb Cheverly のスペクトルは、この異常 Hb の赤色光吸光度が HbA より大きいことを示した（文献 29）。5.4% の Hb Köln をもつ患者の O2Hb と HHb の両方の吸収スペクトルでは、赤色光吸光度が HbA より Hb Köln のほうが大きいことが見出され、R が正の方向に偏り、SpO2 を偽性に低下させることが示された（文献 27）。

マニキュア

パルスオキシメータに関する初期の報告では、マニキュア、とくに黒、青、緑の色が SpO2 を最大 10% 低下させうることが指摘された（文献 30, 31）。新しいモデルのパルスオキシメータを用いたより最近の研究では、マニキュアが SpO2 の読み値にわずかな影響しか及ぼさないことが見出された。すなわち、黒と茶色のマニキュアが SpO2 読み値の最大の低下を示したが、平均で 2% の低下にとどまった（文献 32, 33）。

高度貧血（低酸素血症を伴う場合）

理論的には、O2Hb と HHb の両方が比例して影響を受けるため、貧血は SpO2 の読み値にあまり影響を及ぼさないはずである。しかしながら、高度の貧血が SpO2 に偽性に影響しうることが観察されている（文献 34, 35）。機序としては、ヒト組織による可視光と近赤外光の散乱が、単一の明確に定義された光路を仮定する簡略化された Beer–Lambert の式では考慮されていないためである（文献 4, 36）。この光散乱は赤血球数に影響されるであろう。すなわち、貧血では光散乱がより少なくなるのに対し、較正曲線は貧血のない健常者から導出されている。したがって、Hb 含量の変化に伴って、透過する赤色光と近赤外光の光路長が変化し、R と SpO2 の読み値にバイアスを生じることになる。

イヌを用いた実験的研究では、SpO2 はヘマトクリット 10〜14% までは SaO2 の読み値の正確な表現であることが見出された。ヘマトクリットが 10% 未満に低下すると、パルスオキシメータの正確性は低下し、コオキシメータの読み値を平均 5.4% 過小評価した（文献 37）。これらの知見はヒトの研究でも裏づけられ、低酸素血症の患者では貧血の存在が SpO2 による SaO2 のさらなる過小評価を引き起こした（文献 38）。これに対し、正常酸素の個人では高度の貧血が SpO2 値に及ぼす影響は最小であった（文献 38–40）。この現象の機序的説明は複雑で本総説の範囲を超えるが、貧血それ自体が偽性に低い SpO2 を引き起こすのではなく、真の低酸素血症を有する患者において SpO2 が SaO2 を過小評価するようにさせるのであり、正常酸素の個人では SpO2 の測定にほとんど影響しないことを強調することが重要である。高度貧血の存在下で真の低酸素血症を有する者では SpO2 が過小評価されるので、この誤差の方向は好都合である。なぜなら SpO2 測定による低酸素血症のより早い警告が、より適時の酸素投与につながるからである。

SpO2 が偽性に低下または上昇する原因

メトヘモグロビン血症

メトヘモグロビン血症は、チアノーゼを呈する患者、とくに酸素分圧（PaO2）が正常あるいはほぼ正常である場合に考慮すべきである（文献 41）。メトヘモグロビン（MetHb）は、ヘム部分の鉄（Fe）が Fe+2 から Fe+3 に酸化されたときに形成される。MetHb は2つの異なる機序によって組織への酸素供給を障害する。すなわち、(i) MetHb 自体が酸素と結合する能力が低いこと、(ii) MetHb が正常な Hb の酸素解離曲線を左方に偏位させ、組織レベルでの酸素の放出を障害して、著明な組織低酸素をもたらすことである。

遺伝性 MetHb はまれであり、被験者が異常 Hb（HbM）をもつか、シトクロム b5 還元酵素欠損症をもつことによる。メトヘモグロビン血症のほとんどの症例は通常、亜硝酸塩、硝酸塩、アニリン色素、アニリン誘導体（フェナセチン、ダプソン）、スルホンアミド、リドカインといった酸化性の化学物質や薬剤による。血液 1 dL あたりわずか 1.5〜2 g の MetHb（総 Hb の 10〜20%）でチアノーゼを引き起こしうる。貧血患者では、対応する MetHb の絶対値がより低くなるため、チアノーゼはより目立ちにくい。MetHb 値が 20〜45% になると頭痛、脱力、息切れ、意識状態の変化を生じうる。組織低酸素による代謝性アシドーシス、不整脈、心筋虚血も生じうる。MetHb 値が 50〜60% になるとしばしば致死的であり、血行動態不安定、全身痙攣、昏睡を呈する。

MetHb は O2Hb や HHb のいずれよりも多くの IR 光を吸収する（図2）。その赤色光の吸光度は HHb と類似しているため（図2）、有意なメトヘモグロビン血症の患者はチアノーゼを呈し、血液は非常に暗い色に見えうる。さらに、MetHb は赤色光と IR 光を等しくよく吸収するため（図2）、高い MetHb 値は R 値が 1 に近づく結果をもたらし、これはたまたま SpO2 80〜85% に相当する（文献 5, 10）。したがって、高い MetHb 値は SpO2 を 85% に向かわせ、真の低酸素血症が 85% 未満であるか正常酸素であるかに応じて、それぞれ SaO2 の過大評価あるいは過小評価をもたらす。MetHb 値はコオキシメータによって直接分析できる。メトヘモグロビン血症の治療には、原因物質の中止、支持療法、そして重症例ではメチレンブルーなどの還元剤の投与が含まれるが、メチレンブルーが偽性に低い SpO2 を引き起こしうることに留意すべきである。

スルフヘモグロビン血症

スルフヘモグロビン（SulfHb）は、Hb のポルフィリン環における Fe+2 の Fe+3 への不可逆的な酸化（MetHb と同様）によって形成されるが、加えて硫黄原子がポルフィリン環に組み込まれている。それは最も多くは、硫黄を含む場合と含まない場合のある酸化性薬剤によって引き起こされる。後者の場合には、とくに高度の便秘状態において、腸内細菌に由来する内因性の硫化水素（H2S）が硫黄の供給源になると考えられている（文献 42）。したがって SulfHb は、アニリン色素、アセトアニリド、フェナセチン、フェナゾピリジン、硝酸塩、スルホンアミド、メトクロプラミド（構造的にアニリン色素に類似）、フルタミド、ダプソン、ジメチルスルホキシド（DMSO）によって、あるいは種々の洗浄液に用いられるヒドロキシルアミン硫酸塩などの硫黄化合物への曝露によって形成されうる（文献 42–45）。SulfHb は酸素を運搬できない（文献 46）。

スルフヘモグロビン血症の主要な臨床症状はチアノーゼの存在である。SulfHb のわずか 0.5 g/dL（5 g/L）の平均毛細血管濃度で、検出可能なチアノーゼを呈するのに十分である（MetHb では 1.5 g/dL、HHb では 5 g/dL と比較して）。SulfHb は酸素輸送を著明に低下させる一方で、正常な Hb 酸素解離曲線を右方に偏位させ、組織での酸素放出を促進する。SulfHb によるこの正常 Hb 酸素解離曲線の右方偏位は、組織レベルでの O2 放出が障害されるメトヘモグロビン血症で見られるものとは逆であることに注意されたい。したがって、同じ濃度レベルでは、スルフヘモグロビン血症はメトヘモグロビン血症より有害な臨床的帰結が少ない。とはいえ、極端に高い SulfHb 値は最終的に O2Hb を減少させることによって酸素輸送を障害する。

SulfHb は HHb や MetHb より大きな赤色光（660 nm）吸光度をもつ（文献 43）。正確には分かっていないが、SulfHb はおそらく赤色光と近赤外光で同程度の吸光度をもつと考えられる。なぜなら、高度のスルフヘモグロビン血症の人の SpO2 が 〜85% であるという報告がいくつかあり、これは SulfHb で赤色光と近赤外光の吸光度が類似しており、（メトヘモグロビン血症で見られるように）R 値が 1 に近づくことの徴候だからである（文献 42, 43, 45）。ほとんどのコオキシメータは4波長をもち O2Hb、HHb、COHb、MetHb を区別できるが、SulfHb を特異的に同定することはできない。さらに、多くの分光光度計が MetHb と SulfHb を正確に区別できないため、著明に高い SulfHb 値がしばしば MetHb として誤って報告される。これらの機器では、SulfHb と MetHb を区別するために追加の生化学的検査が必要である。たとえば、血液検体にシアン化物を加えると SulfHb はそのまま残るが MetHb は消失する。しかしながら、新世代のコオキシメータは SulfHb と MetHb を区別できる。SulfHb 値の測定が利用できない施設では、当初メトヘモグロビン血症と推定された患者において、メチレンブルーへの無反応がスルフヘモグロビン血症の唯一の手がかりとなることがある。スルフヘモグロビン血症に対しては、原因物質への曝露を排除することと支持療法以外に特異的な治療（既知の解毒剤）はない。SulfHb の濃度は赤血球が破壊され置き換わるにつれて低下する。極度に症状の強い症例では、交換輸血が成功裏に行われている（文献 45）。

赤色光および／または IR 光の吸収低下をもたらすプローブ位置不良

プローブの位置が不良であると、放射された光が組織を迂回して光検出器に到達する光シャント（light shunting）が生じうる。透過する赤色光および／または IR 光の大部分が吸収されないと、R 値は 1 に近づきうる（上記の赤色：赤外変調の式を参照）。その結果、メトヘモグロビン血症で見られるのと同様に、SpO2 は SaO2 を過大評価することも過小評価することもありうる。

旧型のパルスオキシメータでは、環境光が光検出器に直接当たること、および／または組織を通過する光量を増加させることにより、SpO2 の測定を複雑にし、測定を信頼できないものにしていた。しかしながら、ほとんどの現代のパルスオキシメータは環境光の信号を「差し引く」ことができる。環境光の影響が依然として懸念される場合は、プローブを不透明な材料で遮蔽することが簡単な解決策である。

敗血症と敗血症性ショック

敗血症と敗血症性ショックの状況で SpO2 がどのようにバイアスを受けるかについては、相反する研究がある。Secker と Spiers（文献 18）は、敗血症性ショックの患者において 80 組の SpO2 と SaO2 の読み値を比較し、全身血管抵抗が低い者（肺動脈カテーテルで測定）においてのみ、SpO2 が SaO2 を平均 1.4% 過小評価することを示した。これは統計学的に有意ではあるが臨床的に重要である可能性は低いレベルであった。これらの結果は、ボランティアの片腕に充血を誘発すると対照側の腕より SpO2 が低くなったというヒト研究によって裏づけられている（文献 47）。この現象を説明する仮説は、敗血症による血管拡張が動静脈シャントの形成をもたらし、それが静脈拍動と、パルスオキシメータによる一部の静脈血の動脈血としての誤検出に至るというものである（文献 18, 47）（前述のとおり）。

対照的に、重症敗血症と敗血症性ショックの患者88名の後ろ向きレビューでは、低酸素血症（SaO2 < 90% と定義）を有する者において、SpO2 が SaO2 を 5% 近く有意に過大評価することが見出された（文献 48）。種々の急性疾患を有する重症患者を検討したいくつかの研究では、SpO2 が SaO2 を過小評価するとしたものもあれば、その逆を見出したものもある（文献 48 に総説されている）。敗血症患者のみを検討した研究においてさえ、SpO2 がバイアスを受ける方向の差を説明しうる因子には以下の差異が含まれる。(i) 輸液蘇生と組織灌流の程度、(ii) 敗血症誘発性の心機能不全、(iii) パルスオキシメータのプローブが対象とする部位、(iv) 使用されるパルスオキシメータとプローブの種類、(v) 血管収縮薬の使用、(vi) SpO2 値に予測不能な形で偽性の影響を及ぼしうる他の併存疾患の存在。したがって、重症敗血症と敗血症性ショックの患者に生じる多数の変数のために、SpO2 がどちらの方向にバイアスを受けるかを予測することは困難である。より決定的な研究が行われるまでは、少なくとも不安定な重症の心肺疾患患者においては、SpO2 が SaO2 および FO2Hb の測定値とどの程度相関するかを確認しておくことが賢明と思われる。

コオキシメータで測定される FO2Hb が偽性に低下する原因

ヘム代謝亢進（溶血）またはビリルビン代謝低下（肝疾患）による高度高ビリルビン血症（〜≥30 mg/dL）

ヘム分子1個の代謝により、ビリルビン1分子と CO 1分子が産生される。ビリルビン自体は赤色光と近赤外光をほとんどあるいはまったく吸収しないため、標準的なパルスオキシメータによる SpO2 測定への影響は最小である。標準的な2波長パルスオキシメータによる SpO2 測定は COHb の存在によって低下しないため、有意な溶血の存在下では SpO2 が FO2Hb を過大評価しうると推定できるであろう（鎌状赤血球貧血を参照）。しかしながら、非常に高いビリルビン値は、MetHb と COHb 値を人為的に上昇させることによって、コオキシメータによる FO2Hb 測定を偽性に低くしうる。したがって、高度の高ビリルビン血症の存在下では、パルスオキシメトリによる酸素飽和度の測定（SpO2）のほうが FO2Hb より実際には正確でありうる（文献 49, 50）。コオキシメータが FO2Hb を過小評価する程度は、コオキシメータによって異なる。異なるコオキシメータは異なる波長のセットを利用するからである。これに対し、SaO2 の規定因子は O2Hb と HHb のみであるため、SaO2 は高ビリルビン血症の影響を受けないはずである（Box 1 を参照）。

肝疾患による高ビリルビン血症では、ヘム代謝の亢進がないため CO の増加もない。上昇したビリルビンは依然としてコオキシメータ上の MetHb と COHb 値を人為的に上昇させるため、SpO2 の測定はコオキシメータによる FO2Hb 測定よりもさらに正確になる。しかしながら、高ビリルビン血症の患者のほとんどでは、FO2Hb の測定に有意な影響を及ぼすほどビリルビン値が高くはないことに留意することが重要である。

胎児 Hb（HbF）

HbF による赤色光と近赤外光の吸光度は本質的に HbA と同じであり、したがって SpO2 の測定は新生児においても成人と同様に信頼できる。しかしながら、HbF はコオキシメータによって COHb と誤読され、それによって FO2Hb を偽性に低下させうる（文献 51）。HbF が FO2Hb の読み値に影響を及ぼす程度は、使用される特定のコオキシメータに依存する。異なるコオキシメータのモデルはしばしば異なる波長のセットを利用するからである。加えて、HbA と HbF は（O2Hb と HHb の双方について）主として 450〜650 nm のスペクトル範囲で光吸光度が異なり、これはほとんどのコオキシメータが用いる波長と一致する（文献 52, 53）。架空の COHb 値を単に O2Hb に加えて FO2Hb を補正しようとすること（COHb の真の上昇を引き起こしうる溶血や CO 中毒の証拠がない場合に限る）は一部のシステムでは有効かもしれないが、一部のコオキシメータは HbF の存在下で読み値を補正できる。酸素解離曲線を用いて PaO2 から算出 SaO2 を導出することも1つの選択肢であるが、HbA と HbF の酸素解離曲線は SaO2 の全域にわたって有意に異なりうるため、これは不正確でありうる。より具体的には、SaO2 50% に対応する PaO2 と定義される p50 は、HbF では 19 mmHg、HbA では 27 mmHg である。したがって、HbF の存在下では、SpO2 はコオキシメータ由来の O2 飽和度と少なくとも同等に、あるいはそれ以上に正確である。HbF の存在下でコオキシメータが SaO2 をどのように評価するかにばらつきがあることを考えると、臨床医と血液ガス技師は、自らの施設においてコオキシメータの結果が HbF によってどのように影響されうるかについて、実用的かつ相互の理解をもつべきである。

まとめ

パルスオキシメトリは、O2Hb が HHb より多くの近赤外光を吸収し、HHb が O2Hb より多くの赤色光を吸収するという原理に基づいている。最適な条件下では、パルスオキシメータは静脈血（および他の静止組織）の SpO2 を算出せず、透過光の吸光度の経時的変化を判定することにより、動脈の SpO2 のみを算出する。すなわち、動脈血液量は心周期とともに変化するのに対し、非動脈組織における光吸収体の体積は比較的一定である。パルスオキシメータは SpO2 70〜100% の範囲で較正されているため、70% 未満の表示値は定性的にのみ正確とみなすべきであり、定量的にみなすべきではない。不正確な SpO2 の読み値は動脈血の灌流を低下させる状態で生じうる。SpO2 は、CO を多く含む血液において FO2Hb 含量を過大評価しうる。鎌状赤血球貧血に伴う血管閉塞性発作では、SpO2 は FO2Hb を過大評価しうるが（おそらく内因性 CO 産生の増加の存在による）、SaO2 は過小評価しうる（血管閉塞による灌流不足のため）。偽性に低い SpO2 は、静脈拍動、過度の体動、色素、および特定の異常ヘモグロビンで生じうる。高度の貧血それ自体は偽性に低い SpO2 を引き起こさないが、その存在は真の低酸素血症を有する者において SpO2 が SaO2 を過小評価する原因となりうる。SpO2 は、メトヘモグロビン血症、スルフヘモグロビン血症、プローブ位置不良において、SaO2 を過大評価することも過小評価することもありうる。スルフヘモグロビン血症は、臨床的にも SpO2 と SaO2 の測定においても、メトヘモグロビン血症を模倣しうる。最後に、患者とパルスオキシメータの接触や設定が最適であっても、肺胞気-動脈血酸素較差と PaCO2 はパルスオキシメトリでは測定されないため、まったく正常な SpO2 は肺のガス交換の問題や換気の適切性を否定するものではないことを強調することが重要である。

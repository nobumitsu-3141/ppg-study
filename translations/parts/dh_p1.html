要旨Abstract

光電容積脈波(PPG)は、心血管動態および関連する血行動態プロセスを評価するために広く使用されている非侵襲的光学技術である。しかしながら、従来のノイズ低減法は、信号のタイミングを変化させ、波形形態を歪めることがあり、それによって生理学的に関連するイベントの同定に影響を与えうる。ここでわれわれは、PPG信号から高調波を選択的に抽出するための、周波数領域ガウスフィルタリングフレームワークを提案する。本手法は、支配的なDC成分を抑制し、非拍動性ベースラインを低減し、緩徐な変調プロセスに関連する低周波寄与を減衰させるために、0 Hzを中心とするガウス帯域除去フィルタを組み合わせる。次いで、高調波成分を分離するために対称ガウスバンドパスフィルタが適用され、保持される帯域の数は所与の応用の要件に適合される。概念実証として、本フレームワークは、シミュレートされたPPG波形と実験的PPG記録の両方に適用された。フィルタの対称なゼロ位相特性のために、収縮期ピーク、拡張期減衰、重複切痕を含む主要なPPGイベントの時間的整列は、位相歪みを回避しつつ保存されうる。フィルタリングされた高調波からの再構成は、さらに、解析された信号において、低次高調波が観察可能な波形構造の多くを保持していることを示唆している。全体として、この高調波ベースのガウスフィルタリングは、PPG信号の解析のための有望なフレームワークを提供し、ベッドサイドモニタリングなど、高調波成分から生理学的に関連する情報を抽出するその可能性についてのさらなる研究を動機づけるものである。

キーワード: 光電容積脈波、高調波成分、波形形態、信号タイミング、ゼロ位相フィルタ、PPG、周波数領域、ガウスフィルタ、重複切痕、収縮期、拡張期

1. 緒言Introduction

光電容積脈波は、微小血管組織内の血液量変化をモニタリングするために使用される非侵襲的光学法である。それは、赤外光、赤色光、または緑色光で皮膚を照射し、その間に、組織を透過するかまたは組織から反射される光の強度の変動を光センサが測定することによって機能する。これらの変動は、心周期中の血流の変動に直接結びついている[1]。血液量、血圧、酸素化レベル、および微小血管組織の機械的特性は、光吸収の変動に影響を与える[2]。結果として得られるPPG波形は、3つの重要なイベント――収縮期、拡張期、および重複切痕(dicrotic notch)――を描出し、最後のものは収縮期終末の大動脈弁閉鎖に対応する[3]。

PPGは、心拍数、酸素飽和度、動脈スティフネス、血管コンプライアンスなど、貴重な心血管情報を提供する[4,5]。その単純さと低コストのために、持続的モニタリング、ウェアラブルデバイス、および診断応用において広く使用されている。PPGの波形特性は、測定部位[6]、光の波長[7]、被験者の年齢[8]などの生理学的および測定要因に対してきわめて敏感である。それは2つの成分から構成される: (a) 静的な組織特性(皮膚の色素沈着、厚さ、骨、筋)によって決定されるベースライン(DC)、および (b) 各心拍に伴う血液量変化によって引き起こされる拍動成分(AC)である[9]。

PPG信号の拍動成分は、典型的にはその全振幅の1–5%のみを構成し、そのため体動アーチファクト、環境光の変動、および電子的干渉によるノイズに対してきわめて脆弱である[10]。このようなノイズはSNRを劣化させ、生理学的パラメータ推定の精度を損なう[11,12]。したがって、清浄で臨床的に有用な拍動信号を分離するためには、効果的なフィルタリングが不可欠である。

ノイズを含む生のPPG信号は、Fourier解析を通じて正弦波の和に分解でき、各正弦波は特定の周波数、振幅、および位相(タイミングオフセット)によって特徴づけられる。波形形態と精密なタイミングの保存は、臨床応用およびウェアラブルデバイスにとって不可欠である[13]。特に、PPG信号の臨床的価値は、主要な脈波特徴の正確なタイミングに決定的に依存する。収縮期の立ち上がり、重複切痕、拡張期減衰などのイベントは、基礎にある生理学的機序――心室駆出、大動脈弁閉鎖、および動脈コンプライアンス――と密接に結びついており、心周期内の明確に定義された時点に生じる[14]。

再分極動態を評価するための心電図(ECG)における正確なQT間隔の重要性と同様に、PPG特徴の時間的忠実度は、脈波到達時間(pulse arrival time: PAT)[8]や脈波伝播時間(pulse transit time: PTT)[8,15]などの必須の指標を支えており、これらは非侵襲的血圧推定および動脈スティフネス評価に広く使用されている[16,17]。タイミングの精度は、PPG信号から頭蓋内圧(ICP)および脳血流速度(CBFV)を測定するためにも必要とされる[18–20]。さらに、一拍ごとのタイミング精度は、心拍変動(HRV)解析[9,16]および不整脈検出[4]にとって決定的に重要である。ECGと同期された場合、時間的に忠実なPPG信号は、頑健なマルチモーダル血行動態評価を可能にする[3]。したがって、いかなるノイズ除去または信号強調戦略も、波形のタイミング特性を保存するように注意深く設計されなければならない。時間的忠実度を保証することは、信号の生理学的関連性を損なうことなく、臨床的に意味のある心血管の洞察の信頼性のある抽出を可能にする[21]。

PPG信号における時間的忠実度の保存の決定的な重要性を踏まえると、フィルタリング操作が生理学的特徴のタイミングをどのように変化させうるかを検討することが不可欠となる。タイミング歪みの主要な原因の一つは、非線形位相シフトである[22]。位相歪みは、フィルタが異なる周波数成分にわたって不均一な遅延を導入し、構成正弦波が異なる時刻に到着して、最終的に波形形態を歪めるときに生じる。対照的に、線形位相を持つフィルタは、すべての周波数にわたって一定の群遅延を維持し、各周波数成分の相対的タイミングが無傷のまま保たれることを保証する[23]。この特性は、タイミング忠実度の保存が不可欠である、音声処理、レーダー、生体医用信号解析などの応用において極めて重要である。

PPGにおけるノイズ低減は、Butterworth、Chebyshev、楕円設計などの無限インパルス応答(IIR)フィルタを用いて実施されることが最も多い。ノイズの減衰には効果的であるものの、IIRフィルタの因果的実装は、波形形態を歪めイベントのタイミングをシフトさせる非線形位相応答を持つ[1,6,24]。IIRタイプの中でもBesselフィルタは最良の線形位相応答の一つを持つが、それでも完全に線形ではない[23]。IIRフィルタの前方-後方(forward-backward)実装は位相遅延を低減する。しかしながら、これはフィルタを非因果的にし、信号境界におけるエッジアーチファクトを悪化させ、二重通過適用を補償するためにフィルタ応答を再設計する必要がある[25]。対照的に、有限インパルス応答(FIR)フィルタは、線形位相を維持しタイミングを保存できるが、一般に高いフィルタ次数を必要とし、これは計算負荷を増加させ、また短い信号におけるノイズ抑制にはしばしば効果が低い[26]。

これらの限界は、時間-周波数領域処理および非線形アプローチを含む、代替戦略を動機づけてきた[27,28]。しかしながら、臨床採用は依然として限定的であり、その一因は、計算コストへの懸念、位相保存における透明性の欠如、および生理学的詳細の喪失にある[22,27]。

本研究では、PPG信号の高調波選択的再構成のための、周波数領域ガウスフィルタリングフレームワークを提案する。本手法は、波形形態と主要な特徴の相対的タイミングを保存しつつ、ノイズを抑制する。位相保存フィルタリングを高調波帯域再構成と組み合わせることにより、われわれのフレームワークは、個々のPPG高調波を分離し解析することを可能にする。概念実証として、合成および実験的PPG記録を用いて性能を評価し、結果を従来のIIRフィルタと比較する。

主要な貢献は、タイミングの保存を超えて広がる。具体的には、成分間の位相関係を保存しつつ、対象とする高調波帯域の抽出、選択、および再構成を可能にする、高調波選択的ガウスフィルタリングフレームワークを導入する。タイミングの保存は固有の特性であり、より広範な前進は、PPG高調波成分の柔軟な選択を可能にすることにある。

本原稿の残りの部分は以下のように構成される。2.1節は、PPG処理に一般的に使用されるFIRおよびIIRフィルタをレビューし、位相保存および波形忠実度に関するそれらの限界を明らかにする。2.2節は、Fourier領域におけるガウスフィルタの特性を提示し、提案する高調波ベースのフィルタリングフレームワークを記述する。2.3節は、PPG信号をシミュレートするために使用される経験的モデルを導入する。3節は、シミュレートされたPPGデータと実験的PPGデータの両方についてのわれわれの結果を報告する。これには、従来のIIRフィルタリングとの比較、および抽出された高調波成分に関連する生理学的情報の解析が含まれる。4節は、提案手法の利点と限界についてのわれわれの考察を提示する。最後に、5節はわれわれの結論を提示する。

2. 理論的背景Theoretical Background

2.1. PPG処理に一般的に使用されるフィルタFilters Commonly Used in PPG Processing

フィルタリングは、生体医用信号処理において――特に光電容積脈波において――生理学的に関連する情報を保存しつつノイズを抑制するための基本である。従来の時間領域FIRおよびIIRフィルタは、アーチファクトの減衰におけるその有効性のために、依然として広く使用されている。しかしながら、その内在的な限界、特に位相保存と波形忠実度に関するものは、代替のフィルタリング戦略の探究を動機づけてきた。

IIRフィルタは、その計算効率と強力な周波数選択性のために、生体医用信号処理において広く使用されている。その再帰的構造は、FIRフィルタよりも少ない係数を用いた複雑な伝達関数のコンパクトな実装を可能にする。しかしながら、この同じフィードバック機構は、周波数成分にわたって不均等な遅延を生じる非線形位相応答を導入し、この非線形性はフィルタ次数とともに増加する[29–31]。その結果、タイミング歪みが生じる可能性があり、精密なタイミング保存が決定的に重要な応用においては、IIRフィルタは最適とはいえない可能性がある。

IIR設計の中では、Butterworthフィルタ(次数2–20)が、その滑らかな通過帯域応答[32]と実装の単純さ[12,33–36]のために、最も頻繁に採用されている。しかしながら、その中程度のロールオフは、心臓由来と体動由来の周波数成分の精密な分離を必要とするシナリオにおいては、性能を制限しうる。Chebyshevタイプ I およびタイプ II フィルタ(次数4–20)ならびに楕円フィルタ(次数2–20)は、より急峻な遷移帯域を提供することによってこの限界に対処する[1,13,33,37–39]。光電容積脈波においては、PPG信号の処理に最も適していると考えられるフィルタは、4次のChebyshevタイプIIフィルタ、ならびにButterworthおよび楕円フィルタであり、後二者はいずれも2次フィルタである[22]。

FIRフィルタは、フィードバックを排除することによってこの問題を克服し、無条件の安定性と線形位相応答を保証する。PPG処理においては、時間的忠実度を保存しつつノイズ減衰を改善するために、64次までのFIR設計が実装されてきた[26,40,41]。しかしながら、多数の係数は計算コストと処理遅延を増加させ、リアルタイムまたは資源制約下の応用への適合性を制限する。加えて、ウィンドウベースのFIR設計(例: Hanning、Hamming、Blackman、Kaiser)は、Gibbs現象――急峻なスペクトル遷移を有限のFourier表現で近似することの帰結――によって引き起こされるリンギングアーチファクトを示す[30]。これらのアーチファクトは、PPG信号の波形形態を歪める。

その結果、タイミング歪み、波形忠実度、および計算効率の間のトレードオフは、臨床PPG応用における従来のフィルタリング戦略の主要な限界であり続けている。FIRおよびIIRフィルタは狭い帯域または複数の帯域を対象とするように設計できるものの、高調波固有の選択は典型的にはより直接的でなく、提案する周波数領域アプローチよりも高い設計の複雑さを必要としうる。これには2つの重要な含意がある。第一に、それは各高調波成分が担う生理学的情報の的を絞った解析を妨げる。第二に、通過帯域と阻止帯域の間の滑らかな遷移は、ノイズ減衰を改善するために設計者にフィルタ次数の増加を強いるが、そうすることは情報の喪失、タイミング歪み、および有害な形態学的効果をもたらしうる。したがって、ノイズ抑制と信号保存との間の適切なバランスの選択が、追加的な課題となる。

提案フレームワークの実用的な利点は、その直接的かつ適応的なパラメータ化である。基本周波数 f0 が同定され、高調波中心は ±kf0 として直接定義され、ガウス帯域幅は f0 に結びつけられる。したがって、フィルタバンクは主として単一の信号適応的パラメータ f0 によって支配される。これは設計を単純明快にし、支配的な心臓周波数が変化した際に、フィルタの中心と帯域幅が自動的に更新されることを可能にする。その計算コストは実装依存である。直接の固定ウィンドウFFT実装については、支配的な演算はFFTおよび逆FFTであり、K個の高調波マスクのための追加演算が必要となる。スライディングウィンドウ処理や再帰的スペクトル推定などの代替実装も可能であるが、本概念実証研究の範囲外である。

2.2. Fourier領域におけるガウスフィルタGaussian Filters in the Fourier Domain

本研究を通じて、われわれはPPG信号の時間的完全性を保存することの重要性を強調してきた。従来の時間領域フィルタの限界に対処するために、われわれは周波数領域におけるガウスフィルタリングの特性を利用し、信号の形態を変化させることも、その特徴の精密なタイミングに影響を与えることもなく、信号を処理し、その後時間領域で再構成することを可能にする。

周期的かつ連続な時間領域信号 x(t) = x(t + T) は、その三角関数Fourier級数表現を通じて表すことができる:

x(t) = a0 + Σn=1∞[an cos(n2πf0t) + bn sin(n2πf0t)] (1)

ここで、基本周波数は周期の逆数 f0 = 1/T であり、各高調波成分の寄与を記述する対応するFourier係数 a0, an, bn は、式(2)によって与えられる。

a0 = (2/T)∫t0t0+T x(t)dt,  an = (2/T)∫t0t0+T x(t)cos(ωnt)dt,  bn = (2/T)∫t0t0+T x(t)sin(ωnt)dt (2)

ここで、ωn = n2π/T である。式(1)をその複素表現へ再定式化し、周期 T を無限大に近づけることにより、信号をその正弦波成分に分解するFourier変換が得られる:

X(jω) = ∫−∞∞ x(t)e−jωtdt (3)

ここで、j = √−1、ω = 2πf である。Fourier領域において、PPG信号 S(f) は、基本周波数 f0 の整数倍に位置する高調波成分の集合として表現される。f0 は、生理学的心拍数範囲内の支配的なスペクトルピークから決定される。各高調波の振幅は、全体の波形形態へのその寄与を反映する。最初の数個の高調波が最も生理学的に関連する情報を含むと仮説されている一方で、この仮定を評価するために高次高調波も検討された。

このFourier領域表現に基づき、各高調波周波数 kf0 を中心とし、ガウス帯域幅 σ を持つ、ガウスフィルタの集合を定義する。式(4)を参照。各ガウスは、再構成中の位相情報の保存を保証するために、正と負の周波数成分に対称に適用される。複数の高調波帯域を分離するために、個々のガウスフィルタが加算され、関心のある高調波を選択的に保持する複合周波数領域フィルタを形成する。これらは式(5)によって表される。

G(f) = exp[−(f − f0)2/σ2] + exp[−(f + f0)2/σ2] (4)
H(f) = Σk=−NN exp[−(f + kf0)2/σ2],  k ≠ 0 (5)

ここで、k は高調波インデックスであり、k = 1 が基本周波数を表し、それに続く値はその整数倍に対応する。所望であれば、いくつかの帯域を省略することができる。

本研究では、ガウス帯域幅は、基本周波数に対する相対値として σ = αf0 と定義される。ここで α は無次元の帯域幅係数である。この定式化は、フィルタバンクを適応的かつスケール不変にする: f0 が変化すると、高調波中心 k·f0 と、それに対応するガウス帯域幅の両方が自動的に更新される。PPG信号のスペクトルは準周期的であり、主として生理学的変動(心拍変動を含む)のために、離散的なスペクトル線ではなく広がった高調波帯域を示すため、これはPPG信号にとって有用である。より小さな α はより鋭い高調波分離を提供し、一方、より大きな α は、より滑らかな再構成と、高調波の広がりに対するより大きな耐性を提供する。本概念実証実装では、α = 1/2 が使用され、これは σ = f0/2 に対応する。これは、高調波帯域エネルギーの保持と非高調波成分の制限との間の実用的な妥協である。したがって、値 f0/2 は普遍的な最適値として解釈されるべきではなく、より一般的な適応設計 σ = αf0 の一つの実装として解釈されるべきである。

0 HzにおけるDC成分は、スペクトル振幅を支配し、可視化において高調波構造をマスクしうる。これに対処するために、われわれはハイパス(または低域カット)

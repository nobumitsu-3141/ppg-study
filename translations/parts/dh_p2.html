すなわち、近傍の周波数を保存しつつ低周波の寄与を抑制するハイパス(または低域カット)フィルタを必要とする。そのようなフィルタは、0 Hzを中心とするガウス帯域除去フィルタとして容易に実装できる:

ξ(f) = 1 − exp[−(f − 0)2/σ2] (6)

ここでも、σ = f0/2 が実用的なデフォルト値であり続ける。一般に、カットオフ周波数が−3 dBで生じること、およびここで用いるガウスの定義: exp[−(f − f0)2/σ2] = 1/√2 を考慮する。f について解き、一般の適応関係 σ = αf0 を代入すると、flow,high = ±αf0 √(ln(√2)) を得る。このようにして、帯域幅は、所望のスペクトル広がり、ノイズレベル、および高調波選択性に応じて α を選択することによって、直接得ることができる。

低周波を除去した後、高調波成分は明瞭に識別可能となり、解析対象の帯域幅の系統的な選択が可能となる。

所望の高調波が指定されると、フィルタリングされたスペクトル Sfiltered(f) は、複合ガウスフィルタを、生のPPG信号のFourier変換を表す S(f) に乗じることによって得られる(式(7))。次いで、対応する時間領域信号 sfiltered(t) が逆Fourier変換によって復元され(式(8))、望ましくないスペクトル成分を減衰させつつ時間的整列を保存するPPG波形が得られる。

Sfiltered(f) = S(f) · H(f) (7)
sfiltered(t) = F−1{Sfiltered(f)} (8)

ゼロ位相挙動は、フィルタの構成から直接導かれる。実数値のPPG信号については、Fourierスペクトルは S(−f) = S*(f) を満たす。提案するガウスマスクは、実数値で、非負で、対称であり、H(−f) = H(f) を満たす。フィルタリング後も共役対称性は保存され、逆Fourier変換は実数値のままである。さらに、H(f) は周波数依存の位相項を導入しないため、保持された高調波成分の位相は保存される。したがって、提案するマスクは、位相遅れも群遅延も課さない。

このゼロ位相挙動は、理想的な連続かつ対称に中心化されたガウス関数について成立する[42]。実用的な離散実装においては、ガウスフィルタリングアプローチの内在的特性からではなく、サンプリング分解能、有限長効果、または数値近似のために、小さな逸脱が生じうる[42]。

ガウスフィルタリングアプローチは、いくつかの有利な数学的および信号処理的特性を示す。その指数プロファイルは、急激なスペクトル遷移を排除し鋭い周波数カットオフを回避することによって、滑らかさを保証する。矩形フィルタや鋭く打ち切られたフィルタとは異なり、ガウス関数の連続的な減衰は、再構成された時間領域信号における振動性アーチファクトを低減し、それによってGibbs現象を緩和する。加えて、ガウス関数は時間と周波数における最適な同時局在性を提供し、スペクトル漏れを最小化しつつ選択的な高調波分離を可能にする。フィルタは高調波周波数に対称に中心化されているものの、本手法はチューニングの変動に対する耐性を実証する。精密なチューニングは基本高調波についてより決定的に重要であり、一方、高次高調波は、再構成された波形に実質的な影響を与えることなく、より大きな柔軟性を許容する。

2.3. PPG波形の数学的モデルMathematical Model of the PPG Waveform

われわれのアプローチは、PPG信号をFourier領域で処理することに基づいており、そこでは、その拍動性内容を高調波成分の観点から明示的に表現することができる。これまでの研究は、PPG信号の生理学的に関連するスペクトル内容が主として0.5–10 Hzの範囲に集中していることを報告しており、この範囲は典型的には基本心臓周波数とその低次高調波を含む[34,35]。したがって、高調波成分は集合的にPPG信号の全体的形態を形作っており、それらの相対振幅または位相の変化は波形構造に影響を与えうる。この高調波構造は、現実的な取得条件を考慮しつつPPG信号の主要な拍動成分を表現する、コンパクトな経験的モデルの定式化を動機づける。

本研究では、高周波ノイズの寄与を最小化しつつ波形の主要な形態学的特徴を保存するために、支配的な低次高調波に焦点を当てる。

ベースラインDC成分は、皮膚の色素沈着、組織の厚さ、および骨と筋からの寄与を含む、組織固有および光学的特性を表す。このベースラインに重畳して、信号は、呼吸によって誘発される血液量および静脈還流の変動を表す低周波の呼吸エンベロープ Br(t) によって変調される。

心臓駆動性の血液量変化に関連する拍動(AC)成分は、高調波成分の和としてモデル化される。基本高調波は、振幅 a1、位相 φ1、および心周期に対応する基本周波数 f0(t) によって定義される。高次高調波は、この周波数の整数倍(2f0(t), 3f0(t))において生じ、対応する振幅 a2, a3 および位相オフセット φ2, φ3 を持つ。最後に、加法性ノイズ項 η(t) が、体動アーチファクトおよび測定関連の擾乱を考慮する。

完全な経験的モデルは式(9)で表される。

PPG(t) = DC + Br(t) + Σm=1N am cos[2πt · m f0(t) + φm] + η(t) (9)

ここで、m は高調波インデックス(m = 1, 2 ..., N)であり、m = 1 が基本心臓周波数に対応し、それに続く値はその整数倍に対応する。基本周波数 f0(t) は、生理学的な心拍変動を考慮するために時変関数としてモデル化され、高調波構造が心リズムの変化に動的に適応することを可能にする。

3. 結果Results

概念実証として、われわれのFourier領域フレームワークは、まずシミュレートされたPPG信号を用いて評価され、続いて実験的に取得された記録で検証された。性能は、Butterworth、Chebyshev、および楕円実装を含む従来のIIRフィルタに対して、SNR、時間的整列評価、および相互相関解析を比較することによって評価された。信号再構成は、ゼロ位相IIRフィルタリングのための前方-後方実装とも比較された。すべての数値シミュレーションおよび信号処理は、MATLAB R2024を用いて実施された。

3.1. 合成PPGSynthetic PPG

合成波形は、式(9)に記述された解析モデルを用いて生成された。Figure 1aは、清浄なPPG信号(ノイズ付加なし)を示しており、これは続いて、現実的な生理学的条件を模擬するために、白色ノイズ、呼吸関連の変調、および支配的なDCオフセットで汚染された(Figure 1b)。次いで、Fourierスペクトルの振幅が計算された。しかしながら、高調波構造は支配的なDC成分によって大きくマスクされ、高調波振幅はほとんど知覚できなかった。これに対処するために、式(6)で定義された帯域除去フィルタを用いてDC寄与が除去され(Figure 1cを参照)、結果として得られるスペクトルにおいて高調波成分の明瞭な可視化が可能となった(Figure 1d)。

比較のために、従来のIIRバンドパスフィルタが時間領域で適用された(Figure 2a)。IIR実装は、2次のButterworthおよび楕円フィルタ、ならびに4次のChebyshevタイプIIを含み、いずれも帯域幅は0.6–10 Hzであった。IIRフィルタは、顕著な形態学的変形とタイミングシフトを導入し、特に収縮期ピーク位置と重複切痕の視認性に影響を与えた。信号再構成は、さらに、filtfiltコマンドを通じてゼロ位相構成で実装された同一のIIRフィルタを用いて比較された。filtfiltは、フィルタを順方向と逆方向に適用し、それによってフィルタリング中に導入される位相シフトを打ち消す。ゼロ位相フィルタリングの下では時間的整列は保存されたものの、IIR処理後の波形形態は依然として歪んだままであった。対照的に、われわれの提案手法は、明らかな時間的変位も波形形態の歪みも示さなかった。

ガウスフィルタリングは、IIR実装よりも一貫して高いSNR値を達成し、生理学的に関連する時間特性を保存しつつ、より効果的なノイズ抑制を示した。SNR値は、解析されたすべての信号について、MATLAB R2024の標準snr関数を用いて計算された。この合成PPG信号については、提案手法の適用後、SNRは2.13 dBから50.36 dBへ増加した。比較として、Butterworth、Chebyshev、および楕円フィルタを用いて得られたSNR値は、それぞれ2.66 dB、4.68 dB、および−1.69 dBであった。しかしながら、Figure 2に示すとおり、ChebyshevタイプIIは波形形態の保存に失敗した。

これらの結果は、実験データセットにわたるノイズ除去と時間的忠実度のより詳細な評価を動機づけた。次節では、実PPG記録に対するガウスフィルタリングの性能を検討し、臨床的に関連する脈波特徴のタイミングを保存しつつ波形の明瞭さを高めるその能力を解析する。

3.2. 再構成戦略と予備的位相評価Reconstruction Strategy and Preliminary Phase Assessment

提案アプローチを実際の生理学的データで検証するために、PPG波形が取得され、記述されたFourier領域フレームワークを用いて処理された。この解析は、個々の高調波成分のスペクトル寄与を検討し、SNRと位相保存の観点からフィルタリング性能を評価した。

信号再構成は、最初の N 個の高調波帯域を用いて実施された。ここで N ∈ {3, 4, ..., 9, 10} であり、高次成分が追加の形態学的詳細を提供するかどうかを評価するためである。連続する再構成の間の比較は、5次を超える高調波帯域を保存しても認めうる差がないことを示した。したがって、SNRを改善するためには少数の高調波帯域が望ましいことから、以降の解析は N ∈ {3, 4, 5} を用いて実施された。

位相保存は、再構成された波形を真値PPG信号と時間領域で直接比較することによって評価された。再構成波形と元の波形の視覚的比較は、収縮期ピークや重複切痕などの主要な特徴の明らかな変位を示さなかった。この挙動は、提案するガウスフィルタリングアプローチの対称な周波数領域定式化と整合的である。

3.3. データ取得セットアップData Acquisition Setup

提案手法の概念実証検証のために、PPG記録が、典型的な実験条件下で――本質的に生理学的変動と測定ノイズの影響を受ける――透過照明(transillumination)構成を用いて、3名の独立した参加者から取得された。各信号は、サンプリング周波数43.6 Hzで30秒間連続的に記録された。タングステン光源が指先の背側表面を照明し、透過光は、200–1000 nmのスペクトル範囲をカバーする光ファイバ分光器に結合された光ファイバを通じて収集された。本研究で提示する解析については、600–1000 nmの波長帯のみが考慮された。実験セットアップをFigure 3に図示する。完全な処理パイプラインを例示するために、1つの代表的な記録について詳細な再構成結果を提示する。残りの取得データは、異なる被験者にわたる高調波抽出と波形保存の一貫性を実証するために、次の小節に含める。取得中、心拍数はおよそ80 bpmであり、被験者間の変動は小さかった。

3.4. ノイズ低減、タイミング保存、および波形忠実度Noise Reduction, Timing Preservation, and Waveform Fidelity

透過照明で取得されたPPG信号は相当なノイズを示し、それは重複切痕の正確な同定をマスクした(Figure 4a)。効果的なフィルタリングは、波形形態や時間特性を変化させることなくノイズを抑制しなければならないため、生理学的に意味のある高調波成分を広帯域ノイズから分離するために、信号はFourier領域で解析された。

PPG信号の高調波の明瞭な可視化は、ガウスフィルタを用いたその抽出を容易にし、生理学的に意味のある成分をノイズから分離することを可能にする。式(5)に従い、帯域外のスペクトル内容を減衰させつつ最初の5つの高調波帯域を分離するために、ガウスフィルタが基本周波数とそれに続く高調波に中心化された(Figure 4b)。ガウスフィルタの滑らかなスペクトル遷移は、Figure 4cに図示するとおり、Fourier領域において抽出された各高調波の固有の形状を保存する。

次いで、式(8)に記述されたとおり、フィルタリングされた高調波成分に逆Fourier変換を適用することによって、再構成信号が得られた。この再構成は、波形の明瞭さの顕著な向上を実証した。特に、重複切痕が明瞭に識別可能となり(Figure 4d)、これは合成信号解析からの観察と整合的である。時間的忠実度は、再構成された波形を真値PPG信号と時間領域で直接比較することによって評価された。収縮期ピークおよび重複切痕を含む特徴的な形態の整列は、観察可能な時間的変位の不在を示しており、提案する対称ガウスフィルタリングがタイミング情報を保存することを確認した。SNRは、元の信号における10.37 dBから、高調波分離後には22.30 dBへ増加した。この大きな増加は、生理学的に代表的な絶対SNR値というよりも、制御された高調波再構成の下での帯域外スペクトル成分の効果的な抑制を示すものである。
